# 009 | COLLECTING COOPER
Paul Cleave

只引來詫異的眼光,覺得你是傻瓜。我當然知道今天的日期。被扔進監獄那天我就在等這天來。
四個月前,我因酒駕肇事差點撞死一名少女而入獄。
今天是我出獄的日子。
上午九點,我換回自己的便服,走出基督城監獄厚重的大門。
熱浪迎面襲來,陽光刺眼無情。基督城正處於罕見的高溫酷暑中,柏油路面幾乎被曬得融化。
一輛深灰色的便衣警車停在路邊,卡爾·施羅德探長靠在車門旁等著我。
「泰特,」他朝我走過來,伸出手。
「卡爾,」我和他握了握手。他的手心滿是汗水。
「看起來瘦了一圈,」他說。
「監獄的伙食可不是米其林餐廳,」我回答。
「上車吧,我送你一程。」
