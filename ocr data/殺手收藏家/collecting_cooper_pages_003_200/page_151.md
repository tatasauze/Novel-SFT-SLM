# 151 | COLLECTING COOPER
Paul Cleave

她轉過電腦螢幕,我得越過桌子才能看清楚,更靠近她的香水了。她把照片一張張給我看。到了第三張,我要她停下來好看清楚一點。那雙眼睛看起來很熟悉。
「我記得她,」接待員說。
「你記得?」
「不是她本人,她爸媽。他們來這裡探消息。」
「什麼消息?」
「他們想找到她在哪裡。她失蹤了。噢,眞可怕,」她想到了。「你覺得艾瑪·格林跟她有同樣的遭遇嗎?」她敲敲螢幕。
我不認爲。我覺得這兩個女孩的命運大不相同。我覺得螢幕上的女孩可能就是那個攻擊基督城屠夫和殺死卡爾霍恩探員的女人。三年前萊利教授入院或許也是她幹的。她的面孔出現在報章新聞上,影像來自昨天我看過的DVD,但那張臉跟我現在看到的不一樣。很像,但不一樣,不同的髮型,不同的髮色,臉上少了點肉——但那雙眼睛。兩雙眼睛一模一樣,我很肯定。
庫柏·萊利應該也知道了。他應該看過新聞,也知道她其實是誰,但他一直沒去報警。
爲什麼呢?他還是很怕她?
還是想要隱瞞什麼?
