# 003 | COLLECTING COOPER
Paul Cleave

序言

艾瑪·格林希望老人只是睡著了。
今天星期一，咖啡店生意清淡，老闆不會讓員工提早下班，兩名顧客坐在角落，而且心裡都只想著咖啡，期待有時候即使生意不好，他這樣的心情也不會帶到臉上。
她走出咖啡店，穿過停車場。一輛老舊的車子停在垃圾箱旁邊，車內坐著一個禿頭老人，頭倒向一邊。
她走過去，敲了敲窗戶。老人動也不動。
萬一他死了呢？萬一他心臟病發作，停止跳動，而她卻錯過了救回他的機會？
她又敲了敲車窗。依然沒有動靜。
在基督城，死寂的空氣中泛著一股悶熱的氣息，這段時間以來城裡發生了太多壞事，每個人都變得疑神疑鬼。
她走到前座車門旁，猶豫著要不要把門拉開。
