# 061 | COLLECTING COOPER
Paul Cleave

「天啊,泰特,你連私家偵探的執照都沒了。」
「我說了,他沒雇用我。我不是以專業人士的身分幫他。」
「你什麼身分也沒有。」
「今天早上你倒要我幫你了。」
「那不一樣。」
「是嗎?你真這麼認爲?」我問。
「聽著,泰特,我們在調查她爲什麼失蹤。真的。我們已經問過她的老闆跟同事,現在開始搜查了。沒有人說她逃跑了。我們相信她碰到了壞人。大家都不知道是怎麼一回事。她就消失了。但基督城每天都有人失蹤。找不到的人已經累積了好幾箱的檔案,但我們會繼續找,真的。」
「一點線索也沒有?」
「如果有線索,她父親也不會這時候就去找你了。」
「那你覺得呢?你覺得她死了嗎?」
「希望還活著。」
「卡爾,你沒有回答我的問題。」
「別查了,泰特。」
「我不能不管。」
「爲什麼?因為你去年撞到她?你的債已經還清了,泰特,你不欠她,也不欠她父親。」
