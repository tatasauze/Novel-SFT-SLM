# 099 | COLLECTING COOPER
Paul Cleave

「常常就這麼開始了,」亞德里安點點頭。「書上有寫。」
「事情都會接二連三發生。」
亞德里安停住了搔臉上的疙瘩,看看自己的指頭。「你強暴她了嗎?」
「我說了,接二連三。」
「你呢?」
「唔………………」
「我記得。」
「你小時候宰過動物嗎?」亞德里安又開始搔臉。
「亞德里安,記得我們講好的嗎?你回答我的問題,我才回答你的問題。」
「狗?貓?」庫柏問。
「你怎麼知道?」
「但除了貓狗之外就沒有了吧?你從沒殺過人,對嗎?」
「沒有,沒殺過,」亞德里安垂下了眼瞼,庫柏看得出他在說謊。亞德里安殺過人。逃出去的機率又下滑了一點點。希望亞德里安殺掉的其他人不是他放在這裡的收藏品。
「告訴我殺動物的事情,」庫柏說。
「很久以前的事了,」亞德里安說。「在學校的時候,我常被人欺負。」
「我也是,」庫柏說,事實不然。他從來沒被欺負過,他也不會欺負人。他比較像個鬼魂—————別人對他視而不見。
