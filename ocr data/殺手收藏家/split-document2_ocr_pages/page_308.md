# 殺手收藏家 | 308

「抱歉。」
「糟透了。」
「什麼?聽著,放鬆就好。我一下子就回來,希望你到時候已經好點了。」
嘴巴裡有種咬過全生牛排的感覺,可能是金屬,也可能是血,就是亞德里安用來讓我昏迷的化學物。我閉上眼睛,一次把注意力放在一隻手或一隻腳上。我的手指跟腳趾可以動了,但其他地方仍然動不了。我又把意志集中在四肢上。我可以握拳了。我可以繃緊腳板。我繼續努力,直到手臂能夠彎起來,然後腿也能動了。我坐起來,又覺得頭暈目眩,馬上昏了過去。
等我再度甦醒,施羅德已經回來了。「感覺怎麼樣?」
「你看起來也糟透了。天啊,泰特,基督城裡還有哪個人沒被你惹毛?」
我認眞地想了一想,很有可能。我慢慢坐起來,不敢像剛才那麼快。我很暈,又餓又渴,也不記得上次如此精疲力竭是什麼時候了。頭好痛,一波波劇痛接踵而來,每一下都有腦袋咬住眼球後面的感覺。救護車裡面看起來很凌亂,醫護人員能記得什麼東西放在哪裡眞是奇蹟。我把雙腳擺下了輪床的邊緣,眼前的東西又模糊了幾秒,不過又變得清晰了。
「到底發生了什麼事?」施羅德問。
「我不知……我眞的不知道。」
「你在跟我講電話,有人攻擊你。」
「你打給我?」
「不,你打給我。」
