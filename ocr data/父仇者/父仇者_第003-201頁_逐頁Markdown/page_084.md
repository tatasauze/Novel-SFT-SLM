# 父仇者 | 084

「只有姊姊嗎？」
「妳這句話什麼意思？」
「只有我姊姊？」
「當然，就是梅蘭妮，」她這麼問，讓他開始擔心了。「凱蒂，妳不是只有姊姊嗎？」
「如果你是我爸爸的朋友，怎麼會不知道？」
「我離開一陣子了，凱蒂，妳告訴我是什麼意思好嗎？」
「還有妹妹。」
還有妹妹。天啊，他到底錯得有多離譜？沒有妻子，三個女兒，還有呢？
「凱蒂，家裡還有其他大人嗎？」
「沒有了。」
「沒有哥哥跟弟弟？」
她搖搖頭。「你看起來很像壞人。」她說。
「我不是壞人。」他說。
「你會傷害我們嗎？」
「不會，」他說。「我告訴妳，我說什麼，妳就做什麼，就不會有人遭殃。妳可以當我的特別助手。」
「我不想當你的特別助手。」她說。
「妳姊姊叫梅蘭妮。」他說。
「對。」
「妳妹妹呢？她幾歲了？」
