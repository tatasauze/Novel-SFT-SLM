# 父仇者 | 058

變成連續好幾個星期。他們過世的時候他不在。妻子自殺的時候他也不在。家人紛紛離世，只留下他，他現在只能把名字一個個劃掉。第一次看到妻子和女兒的墳墓，是在他出獄那天。他得問旁邊教堂裡的神父要怎麼走。
「對活著的人來說，總是比較難。」雅各神父說。
他站在墓園裡，冷風吹過樹梢，雨水打在身上。他看著墓碑上妻女的名字，心中的痛苦無以復加。
「我很抱歉，」他對著冰冷的石碑輕聲說道，「我來遲了……」
他知道死者聽不見他的話，但他必須說出來。十五年來積壓在胸口的愧疚與憤恨，如火山般在體內翻湧。
他從墓旁走開，鞋子吸了更多的水，迷宮讓他無法立即離開，過去的思緒讓他覺得身體好沉重，他步履維艱，穿過了濕淋淋的草地和花園，往停車場走去。
