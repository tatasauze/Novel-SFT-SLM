# 父仇者 | 024

了無線電話，電話又大又重，可能是第一代無線電話。電視的聲音關掉了，但氧氣機器跟冰箱一樣發出嗡嗡聲。他納悶這機器在運轉的時候亞伯特怎麼睡得著。
「你常跟他們見面嗎？」
「哈！別說笑了。來吧。」亞伯特把一杯咖啡推給迦勒。很燙。他拿起了杯子，兩人在客廳裡坐下，迦勒把咖啡放到啤酒旁邊。
「迦勒·寇爾。」亞伯特喝了一小口自己的咖啡，迦勒來之前就已經泡好了。
「沒錯。」迦勒拿起他那杯，對著杯子吹氣，想降低溫度。電視上的人反覆吟誦著什麼，對某人喊「快跳，快跳，快跳」。或許實境節目裡的人都站在屋頂上。客廳裡很熱。天花板上掛了電風扇，慢慢循環著悶熱的空氣。如果他心目中的未來可以實現，他不確定自己要不要住在這樣的地方。
「實在想不起來。」
「想遠一點，」迦勒說。「十七年前。」
亞伯特嘴角一撇，臉蛋似乎縮小了。「十七年？天啊，年輕人，我要能記得十七個鐘頭前的事情就好了。」
「跟你參與的法律案件有關。」
「案件？年輕人，你找錯人了。我不是律師。我以前是老師，很厲害的老師。你知道嗎，有些學生還會寫信給我。我都留下來了，厚厚一疊，大概有二十多個同學長大後幹得有聲有色。啊，該死，那就是我跟你認識的地方，對嗎？你以前是我的學生。哪一年啊？你幾歲了？」
