# 039 | THE LAUGHTERHOUSE
Paul Cleave

養老院送晚餐，不過他還是堅持要自己準備早餐跟午餐。所以他得早點回去吃晚餐。」
赫伯的晚餐快吃完了，表示送餐來的人已經走了，不過我們仍得找他們談話。
「你陪他走回去嗎？」
「陪他走？我幹嘛陪他走回去？」
「所以他五點鐘離開了，你就沒看過他？」
「對，一直到……你知道的，一直到我七點鐘發現他死了。」
「昨天跟今天，你有沒有發現任何人在附近閒晃？」
「什麼，可疑的人嗎？年輕人，很少有人在這閒晃。有事的話，大家都想躲得遠遠的。赫伯的孩子絕對不想來，跟我家的一樣。你什麼都給他們，他們就這麼報答你，把你塞進……」
「赫伯跟別人不和嗎？吵過架嗎？」
「上帝啊，要跟別人吵什麼架才會死得這麼慘？不論如何，大家都喜歡赫伯。每一個人。」
「並不是所有人。」我點出來了，伯納德緩緩點頭。
「我會好好想一想，」他說，「真的，但我發誓，真的沒有。我不知道為什麼有人要害赫伯，害得那麼慘。那裡的血好多，一開始我還看不出來是赫伯，但那頂假髮是他沒錯。你看到了嗎？」他不等我回答又繼續說下去。「掛在他頭上，好像被鬆開了。我常拿假髮開他的玩笑————看起來好蠢，大家都知道是假的。一看到假髮，我就知道是他了。一定是。世界這麼小，不可能有兩個人會選一樣難看的假髮。」他勉強擠出了一個微笑。
「你沒看到附近有人閒晃？」
他搖搖頭。「我說了，沒有人要陪老人消磨時間。」
