# 091 | THE LAUGHTERHOUSE
Paul Cleave

「然後呢？」
「他們最糟糕的也不過就是拿過幾張超速罰單。」
現場就留給鑑識小組。我們該去找布萊德·海沃德的老闆，約翰·摩根。已經四點了，施羅德給我一張紙條，上面有摩根的地址。我在警察學校認識他的時候，他寫字就很醜，過了這麼多年以後更難看了。字母糊成一團，他得重複一次自己說過的話。
「說這句話不知道有沒有幫助，」我們一同踏過了愈靠近樓梯愈模糊的血腳印，「我的感覺跟你一樣。」
「什麼感覺？」
「很無助。」他說。
「不是絕望？」
他聳聳肩。「隨你挑了。」他說。
離開前，我去跟妻子道別。進了她的房間，布莉姬站在窗前，窗簾拉開了。看到她站在那裡，我嚇了一跳，真的嚇到了，必須後退一步才能保持平衡。「布莉姬？」我等她回頭對我一笑，可是她沒回頭。我大步穿過房間，握住她的手，看著她的臉，可是她對我視而不見，沒有回握我的手，只是凝望著停車場裡的警車，紅色跟藍色的燈光照在她臉上。
我讓她轉向我，期待她的眼神聚焦在我臉上，不斷祈禱，可是她仍看不到我。周圍這麼亂糟糟，除了站起來，她跟平常沒什麼兩樣。她沒注意到我最近四個月沒來，因爲我去坐牢，也沒注意到我出獄了。窗外的媒體收集了資料，報導一名女性死亡的消息，布莉姬跟她只隔了一條走廊，但布莉姬不認識她。或許布莉姬看到了兇手。或許她看到他上了車離開。漢彌頓護士告訴
