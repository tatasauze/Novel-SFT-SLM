# 067 | THE LAUGHTERHOUSE
Paul Cleave

12

電話響起，我才發覺我在沙發上睡著了，仍穿著參加喪禮的西裝。我看看手錶，現在是兩點，我只睡了十分鐘。新聞播完了，換成電視購物節目，一定要買的新款健身器材，可以折起來滑進床底下，就不怕鄰居來拜訪時看到，讓你不好意思。展示器材的女人腹肌發達，比我體內的營養素還多。我看看誰打來的。施羅德。他打來告訴我我可以參加辦案，或者我不能參加。
「我跟大頭聊過了。」他說。
「然後呢？」
「然後我提醒他們，碰到連續殺人犯的時候，你總知道要從哪裡下手，只是有時候你下手的方法不太對。」
「然後呢？」
「然後他們提醒我，你的成功率總伴隨著殺人率。」
「第一個是意外，」我說，「第二個自殺了。」第一個也不完全是意外。第二個一樣半真半假。施羅德知道，但沒有證據，就算有證據，也不想把我揪出來。
「你可以加入我們，」他說。「不是以警察的身分，算是正式的顧問。」
「在這個時候，能這樣我也滿足了。」
「是啊。如果順利的話———媽的，或許你就有機會回來了。」
「嗯，搞砸了，我的機會就跟連死兩個人一樣。」
「三個。」他說。
