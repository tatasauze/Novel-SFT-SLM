# 095 | THE LAUGHTERHOUSE
Paul Cleave

要她安靜，她就停止咕噥了。他把嬰兒抱到樓下，手勢很溫柔。他已經把嬰兒座椅從史丹頓的車裡拿出來，放在他車子的副駕駛座上，轉了個方向，所以她會看到座椅，而不是擋風玻璃。他爲她蓋上毛毯，把邊緣都塞緊了。
車子發不動。
他不停轉動鑰匙，引擎嘎嘎作響，就是發不動，愈試愈沒有希望。他踩下油門，前後移動重心，彷彿把車子搖一搖就能發動了，可是都沒有用，過了三十秒，轉動鑰匙時，引擎只會輕輕噠一聲。
快到早上五點，鳥兒都要醒來了。
奧克塔維婭哭了起來。
「噓，」他慢慢搖搖她的座椅，但她不肯安靜，反而哭得更大聲了。「他媽的，」他說，「我叫妳安靜。」
後座的兩個女孩扭來扭去。他下了車，解開汽車座椅，把嬰兒跟座椅一起搬到走廊上，又把另外兩個女孩帶過去。
「她怎麼了？」他問。「肚子餓了嗎？」
女孩不回答。無法回答，因爲嘴巴被貼住了。
可惡。快沒時間了。他把女孩拉進客廳裡，免得她們看到父親，一分鐘後，他把醫生從行李廂裡拉出來，拖過了車庫。他把他塞進他自己的車裡。他讓女孩也上了車，然後從廚房拿了一罐嬰兒食品。
