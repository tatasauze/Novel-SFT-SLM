# 051 | THE LAUGHTERHOUSE
Paul Cleave

「就這樣嗎？『泰奧，多謝你開車載我？』」
他舉起了手。「讓我說完，」他說。「老闆要來了，」我幾年沒見到警司了，他叫多明尼克·史蒂文斯，我也知道施羅德接下來要說什麼。「他大概再過十五分鐘就要到了，如果他看到你在這裡……嗯，你或許就沒有機會回來了，我或許也沒有機會升官。你是老百姓，泰奧，他看到你在這裡會很不高興，現在不是時候，我會找機會跟他私底下解釋，不要讓他一來就看到你在做警察的工作。」
「好，當然，我懂。」我說。
「我知道你很氣。等我跟他報告了，一定能找事情給你做，要真有事給你做，你也要遵守規定。你不是警察，你是私家偵探，但你不能投機取巧，不然你就沒有機會回到警隊了。」
「我會乖乖的，」我告訴他。「我保證會守規矩。」
他沒有馬上回答，只瞪著我瞪了幾秒，讓我知道我也惹毛他了。
「好吧，回家休息吧。我會打電話給你。如果你能回來，我會告訴你。不然，明天早上再見了。還有，泰特，如果你要辦這件案子，你一定要幫我一個忙。我不是開玩笑，這次，你一定不能把人給殺了。」
