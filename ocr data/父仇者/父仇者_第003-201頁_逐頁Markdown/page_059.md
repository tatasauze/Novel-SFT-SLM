# 059 | THE LAUGHTERHOUSE
Paul Cleave

10

探視過女兒的墓後，我回到車旁，那裡不只我一個人。有個人坐在旁邊的車裡，努力發動車子。引擎似乎轉不起來，不過他還是一直試。他抬頭看看我，街上傳來的燈光很微弱，教堂裡完全沒有燈，所以我看不太清楚他的長相，不過模糊看來，似乎不太好。他臉上有疤痕，鼻子看起來斷了好幾次。他發現了我在看他，我沒辦法，只好主動問要不要幫忙，其實我寧可趕快上車，趕快離開這裡。然後我想，這個人會在晚上這個時候來到墓園，肯定也失去了心愛的人，說不定跟我一樣悲慘。
「要幫忙嗎？」我問。
「我不太懂車子，」他下了車。他一定有五十歲了，一頭濃密的白髮已經塌了下來。
「我也不太懂，」我坦承，「不過我有跳接電纜，說不定可以派上用場。」
我打開行李廂，撈出電纜。我們分別彈開了自己的引擎蓋。我想，如果要比賽誰的車子最爛，我們可以並列冠軍。我發動了車子，引擎幾乎轉不起來，有那麼一秒，我以為我們兩個都要被困在這裡了，還好通了，我踩了幾下油門。
我繞到車子後面，那人上了他的車。他試了兩次，引擎發動了。他催了幾下油門，然後下了車，在車燈照耀下，他的面孔也比較清楚。看起來他被狠狠揍過，不是最近，而是很久以前，還被揍了很多次。我們解開了電纜，我把纜線捲起來，丟回行李廂裡。
「真的很感謝。」他說。
「不客氣。」出於本能，接下來我發現自己伸出了手。
