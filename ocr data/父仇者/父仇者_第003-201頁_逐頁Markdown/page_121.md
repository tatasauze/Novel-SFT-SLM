# 121 | THE LAUGHTERHOUSE
Paul Cleave

「是的。讓兇手發怒的事情可能發生在十九年前。或者他那時才十九歲。」
「他的名單上可能有十九個人，」施羅德也發表了意見。
一想到十九名死者，大家不約而同抽了一口冷氣。有些人或許認爲，如果他殺了十九個就住手，算我們好運了。
「對，對，」史蒂文斯頻頻點頭。「或許他們害了他愛的人，對方才十九歲，或許那個人被害死了。」
「或者花了十九年的時間，」我說，「或許十九跟錢有關，因爲死者有會計師也有律師，」我想接著說律師和會計師其實死掉最好，但我忍住了。「或許他們害他損失了一萬九千塊，或十九萬，或坐牢十九年。」
「OK，或許沒意義，或許有意義，」史蒂文斯說。「施羅德探長，」他轉向卡爾，「我要你在會後盡快找到法醫，看看泰特的想法有沒有價值。」
然後史蒂文斯又轉頭對著大家，點了一下頭，看不出有什麼含意，然後他出了簡報室，換施羅德上台。施羅德摀著嘴咳了咳，看了我一秒，然後轉眼看著大家。太陽終於出來，跟我們共享清晨的夢魘，陽光照進了窗戶，灑在要開口說話的施羅德身上。另一名警探站起來，拉上了百葉窗。
施羅德分派好大家的工作。巡邏車上了街。自從第二具屍體出現，他們就開始巡街，尋找可疑的人事物。他們現在也只能這樣了，除非我們能找到什麼關聯。施羅德講解了細節，也講解了我們現在知道什麼，可惜我們知道的不多。他分派人手去不同的犯罪現場，尋找目擊證人。警探從律師那邊下手，兩個人去翻閱一號受害者過去的案件，兩個人去看四號受害者的案件。他們要取得搜查令。律師事務所不喜歡提供資訊。給他們看搜查令也不一定有用，因爲他們什麼都可以
