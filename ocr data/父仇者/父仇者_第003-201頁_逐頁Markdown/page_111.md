# 111 | THE LAUGHTERHOUSE
Paul Cleave

「詹姆士·惠特比？不記得，他到底是……」他住了口，迦勒知道他想起來了。「但是……他死了。」
「沒錯。」
「他……他被謀殺了。」史丹頓皺起了眉頭。
「快啊，你快說出答案了。」
「你是……他就是你殺的。你……你是迦勒……迦勒·寇爾？」
「答對了。」
「我——」
「噢，天啊，天啊，」他搖搖頭，血從鼻尖噴到了殘餘的夜色裡。他睜大了眼睛，滿臉驚惶，想起了過去，發現了他即將面對怎樣的未來。「那都不是我的錯，」他的聲音很高亢。「我只是做好了我的工作，我盡量利用能拿到的資源來判斷。我沒有騙你，他做的事——我很抱歉，我眞的很抱歉。」
「抱歉？」迦勒很驚訝他居然道歉了。「抱歉？你只有這句話要說嗎？你很抱歉？我坐牢坐了十五年，你怎麼不來道歉？」
「給我閉嘴。」他使盡全身的力氣，一拳打在醫生的肚子上，衝擊的力量讓兩人都彎下了腰，史丹頓呼出一大口氣，迦勒把手攏進了懷裡。恢復了以後，他拿出膠帶，啪的一聲貼在醫生嘴上。史丹頓受傷的鼻子發出刺耳的呼吸聲。迦勒很想在膠帶上割個小洞來幫他呼吸，不過他很氣，他會把刀子一直往下戳，然後就只剩下三個無用的孩子跟一個死掉的醫生。他一把抓住醫生的頭髮，把他拖進了屠宰場。
所以一天不夠，要兩天。沒關係。就跟他之前想的一樣，有時間去想該拿艾瑞兒·錢瑟勒怎
