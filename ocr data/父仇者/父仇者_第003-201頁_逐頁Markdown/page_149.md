# 149 | THE LAUGHTERHOUSE
Paul Cleave

「但妳記得她，」我指向維多利亞·布朗。「她已經昏迷七年了。那表示妳七年前看過她。之前妳找過律師嗎？」
「當然找過，但從來請不起。」
有道理。
「這個男人，他不是妳的老師嗎？」我指著麥克法蘭。
「什麼？我不知道。我不記得我的老師。」
「他在帕帕努伊高中教過書，妳念過那所學校嗎？」
「當然沒有。你一定覺得我爸媽很恨我，才把我送去那裡。」
「妳知道她是律師，」我又敲了敲維多利亞的照片。「妳一定在哪裡見過她。」
「天啊，不要再提律師了，好嗎？我不知道我怎麼會認識這個人。」她打了個哈欠，連摀住嘴巴也懶，然後喝乾了酒。「或許我看過她上電視。或許她接了大案子所以上了新聞。你沒想到嗯？」
「看到什麼可疑的事情嗎？」我問她。「有沒有人跟著妳？有沒有人一直看著妳？」
「什麼？什麼時候，昨天晚上嗎？」
「對，昨天晚上，或隨便哪個晚上。」
她聳聳肩。「沒有啊。」
「昨天晚上妳接了其他客人嗎？他們長什麼樣子？」
「那個，我已經告訴你了，」她對著咖啡桌上那三張照片旁邊海沃德的照片點點頭。「你拿照片給我看，我就可以告訴你誰洗了澡，誰沒洗澡，沒別的了。」
我謝過她的幫忙，撈起相片，換把我的名片放在桌上。
