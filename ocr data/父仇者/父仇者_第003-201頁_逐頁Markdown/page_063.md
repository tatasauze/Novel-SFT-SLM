# 063 | THE LAUGHTERHOUSE
Paul Cleave

看，彷彿在解讀他的心思，他希望不需要付貓咪的費用。窗邊的花瓶插滿了正在燃燒的香。
他第一次來這裡，不過是第四次看靈媒。前面三個靈媒都在家裡算命，穿著同樣的深色服裝，不過顏色不一樣，書架上擺了同樣的書，燈光也一樣幽暗。他們接觸死者的方法都差不多。他希望這個女人比較靈驗。
「把手給我。」她說。
到目前為止都一樣。他把雙手伸過桌子，被她爪子般的手握住的時候，他很想把左手抽回來。
「你很痛苦，」她說，不過不需要召喚靈魂來告訴她，從他的臉和那些疤就能看出來。「我感覺到，」她稍微歪了歪頭，閉上眼睛，他可以看出她正努力聆聽。他看著她，希望這一切都是真的。「我感覺到你失去了很親近的人，」她說。「對不對？」
他點點頭，又發覺她閉著眼睛。「對。」他說。
「你太太？」
「對，」他又說了一次，希望她不是亂猜。
她把眼睛閉得更緊了。其他的靈媒猜到這裡就結束了，沒發覺他的孩子也死了。這個女人正在集中注意力……集中……
「我感覺到還有更多痛苦，」她說。「你很愛你的太太。還有……還有其他人嗎？」
開放式的問題，不過他很想相信，就回答了。「對。」
「我感覺到一個年紀小很多的人，」他沒答腔，她更握緊了他的手，左手的力氣比爪子更大，又想了幾秒鐘。「年輕很多的人。」
「我女兒。」他覺得自己很笨，不該告訴她。他太著急了。
