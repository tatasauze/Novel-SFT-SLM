# 父仇者 | 180

「我知道你女兒也在這裡。」雅各神父說。
我不知道該怎麼回答，只能繼續前行。
「失去孩子的苦痛實在難當。」他說。
「再不快點，有人要失去三個女兒了，」我們兩個跑了起來，越過一排排死者，兩分鐘後我們找到了墳墓，我已經氣喘吁吁，整個背都汗濕了。雅各起碼比我老二十歲，倒沒有我這麼喘。
「就是這裡。」雅各停在兩座看起來很像的墳墓前。只是看起來跟其他的墳墓都不像。
「耶穌啊。」我說。
「泰奧。」神父瞪了我一眼。
墓前沒有花，墓石底部的雜草也該剪了。我仔細看銘文。旁邊有塊空地，可能是留給妻子的丈夫和女兒的父親。
留給迦勒·寇爾。
這樣就說得過去了。
十五年前流的那些血……
我拔腿就跑。
「她們是什麼人？」雅各神父對我大喊。
我沒回答，他已經在我身後十公尺的地方了，每過一秒，我就拉開更長的距離，跑過墓園，雙腳重擊地面，從其他墳墓的邊緣上踩過去。我拿出手機打給施羅德，但還沒撥號前我的手機就響起來，施羅德打過來了。
「我找到了！」他的口氣聽起來很興奮。
