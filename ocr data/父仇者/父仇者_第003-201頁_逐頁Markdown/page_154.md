# 父仇者 | 154

「是啊，就是那樣。後來更可怕了。重點是，我眞的死了。我的頭埋在水裡，我好恐慌，不知道是他媽的誰說過，溺死是很平靜的死法，看來他一定沒淹死過，沒有被人把手反銬在背後，然後推進裝滿水的浴缸裡。吸進去的是水，不是空氣，眞的是全世界最糟糕的感覺。整個人都燒起來了，只看到一片漆黑，然後什麼都沒了。我死了。幾分鐘後，杭特把我從浴缸拉出來。他幫我做人工呼吸，按我胸口，直到我把肺裡的水咳出來。我躺在浴室地板上，不知道他媽的我怎麼了。我只記得我氣死了，居然有人把我的頭壓到水裡，我也記得我很怕，因爲在那死去的三四分鐘內，我什麼都不記得。我們這麼努力，想讓這個世界變得更好，我不知道……我是說，我不怎麼相信上帝，但我眞希望有上帝，你懂嗎？那四分鐘是我這一生最接近上帝的時候，可是我什麼也沒得到。或許我老婆說得沒錯，或許我該換個跑道了。」
「你要我跟你吵架嗎？你要我告訴你，你走了警局的損失有多大嗎？還有市民呢？」
「下次要是沒人幫我做人工呼吸，損失才慘重。」他說。
「你這話什麼意思？」
「卡爾……」
他仰望天空，用手抹抹臉。「沒什麼意思，」他說。「我累了，就是累了。累了，瘋了，就是……就是一文不值。你抓到了重點，十九刀，」他開始往前走，但是他錯了——猜到的人是強納斯，不是我，我們要不了多久也會聽到消息；崔西會發現這個巧合。怪的是強納斯怎麼知道？就連崔西都還不知道，不會有人告訴他。
「聽我說，泰特，我沒事。專心辦案吧。你跟艾瑞兒·錢瑟勒見過了，順利嗎？」
「很有趣。」我告訴他會面的經過。
