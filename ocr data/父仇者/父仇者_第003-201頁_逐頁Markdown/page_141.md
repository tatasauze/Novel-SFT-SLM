# 141 | THE LAUGHTERHOUSE
Paul Cleave

「什麼？你幹嘛問這個？」
爲什麼？他不知道。他也不需要知道，或者該說，他最好不要知道。不過在這一刻，他很想知道。「告訴我。」他說。
「小貓咪和小喵喵，」他說。「小貓咪梅蘭和凱蒂小喵喵。」
「奧克塔維婭呢？」
「什麼？」
「奧克塔維婭。」
史丹頓搖頭。「她沒有外號。」
「爲什麼？」
「別傷害她們。」史丹頓說。
迦勒搖了搖頭。該死的。該繼續計畫了。他幹嘛擔心誰叫什麼名字？「來不及了。」
「不，不，還來得及。不可能來不及。你還沒動她們一根寒毛，你也不需要，你要拿我怎麼樣都沒關係，但不需要傷害她們。拜託，我求你了。」
「求我。我女兒也求說她不要死，」他知道她會哀求。她會求那個人，哭泣著呼喊爸媽。「我們以前也叫她小貓咪，」他說，史丹頓的臉龐抽搐了一下，迦勒知道爲什麼——突然之間這一切都更有人性了。突然之間史丹頓想到了失去女兒會是什麼樣子。很好，他也不需要想像太久。「我會讓你決定哪一個女兒先死，」迦勒說。——我倒沒有選擇。」太陽照進了辦公室，突顯出空氣中的一束灰塵。他知道女孩子沒聽到他說什麼，如果聽到了，現在就不光是哭而已，她們會哭到眼睛都腫了，還會一直尖叫。「她們死的時候，你會在旁邊看，」迦勒繼續說。「我女兒死的時候，身邊沒有其他人，只有那個害死她的男人。」自從她死後，那幅景象每天都會浮
