# 父仇者 | 046

差的區域，在郊區裡織出他的路網。
去她家要二十分鐘。開車就像騎腳踏車————坐到方向盤後就知道該怎麼辦。他的駕照過期好多年了，不過要被警察攔下來才會有問題。現在駕駛人的德性絕對差多了，駕駛人口也比以前多了一倍。大家都不知道怎麼走圓環，也沒有人記得為什麼要打方向燈。
他不怎麼喜歡她住的這一區。以前他跟家人住的地方還不錯，鄰居很友善，房子也很漂亮。他自己的房子有四間臥室和兩層樓，如果要游泳池的話，後院也有空間。他眼前這棟房子看起來客廳地板上應該要出現游泳池了。屋頂少了幾塊瓦，用防水布胡亂蓋住。或許監獄還比這個地方好，有可能吧。他把車子停在街燈下，不過燈壞了。他把手放到門把上，但沒開門。只坐在車裡看著那棟房子。他很緊張。死人居然還能這麼緊張。他不確定對裡面那女人開口的時候要說什麼。
或許他應該帶啤酒給她，啤酒還在車子裡。
他仍在跟自己辯論要怎麼處理她的時候，一台計程車停了下來，短促地按了兩下喇叭。過了一會兒，艾瑞兒·錢瑟勒出來了，快步走向計程車時看了一下手錶，她的洋裝很短，她上車時他不得不轉開視線。她關上了車門，跟司機講話。他們講了一分鐘，車子才開動，應該在討論車資吧。
可惡，他錯過機會了。他應該昨晚就來，或出獄後就找個時間來。
他發動了車子，跟在計程車後面。
