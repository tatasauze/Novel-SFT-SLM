# 127 | THE LAUGHTERHOUSE
Paul Cleave

剝落了許多，掉在門廊上的水灘裡。我敲敲門，還以爲自己的手會穿進去，以爲那扇門已經腐壞了，只是被白蟻的分泌物黏在一起。
來應門的女人對著陽光瞇著眼，把手遮在臉前。她的膚色蒼白，嘴巴旁邊生了皰瘡。我花了幾秒才決定她應該是艾瑞兒，因爲這個版本跟照片不一樣。她看起來比較老，也比較瘦，可能六個小時前才吸過毒，因爲她的手臂上有針孔。她抓著一個杯子，盛了一半的金色液體和冰塊。她的頭髮染成了黑色，只有以前的一半長，垂到脖子最上面的地方。
我舉高了警徽。「妳是艾瑞兒·錢瑟勒嗎？」
從她的五官看得出來，在生活壓垮她之前，艾瑞兒·錢瑟勒非常有吸引力。
她的聲音粗嘎，彷彿喉嚨裡塞了菸蒂。「你是誰？要幹什麼？」
「我是泰特探長，」我介紹了自己，感覺很好，而且不像上一次是硬著頭皮說謊。
她的眼神突然有了焦點。「你看起來不像條子。」她把頭髮撩到了耳後。
「不像？」
「不像。條子都穿便宜的西裝。你的連便宜都稱不上。」
「妳認得這個男人嗎？」我拿出了布萊德·海沃德的照片。
「不認得。」她看也不看就回答。她想把門關上，我按住了門阻止她。
「妳要不要再想一想？」
「不用了，不要。你快滾好嗎？」
「我們在他車上找到了妳的指紋。」
「我的指紋總有方法到很多人的車上，」她說。「他說我偷了他的東西嗎？那是他在騙人。花錢買女人的男人都不能相信。」
