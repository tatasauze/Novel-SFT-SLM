# 007 | THE LAUGHTERHOUSE
Paul Cleave

1
十五年後

喪禮這天天氣很糟。星期一一大早，基督城的太陽就讓位給雨滴，萬里無雲的天空現在只有一片灰，看不見一點藍，這分鐘雨密密打下，下一分鐘又變成惱人的毛毛雨，雨刷再怎麼快都趕不上。我這台車不怎麼樣————車齡二十多年，等於人類的七十歲，應該要退休了。早上起來，有時候發得動，有時候發不動，不過很便宜，事實是我只能勉強買一台便宜的車。
今天早上不冷，還沒那麼冷。三月的時候氣溫通常還算溫和，只是每天早上總比前一天冷，一天天邁進七月和八月，也就是南半球最冷的時候。真到那時，我的車子一定不能開了。或許我那時也要失業了，不是每份工作都有錢拿，有錢的工作少之又少。最近接到的私家偵探工作是從卡爾·施羅德探長那邊來的，不值得警方費神的小案子，主要是因爲現在警方太忙了，忙著防止基督城的好人變成地下的冤魂。
只是，三月已經過了。四月十小時前開始了，而四月的天氣更嚴峻。我大概睡了五個小時，其餘五個小時我從這家汽車旅館開車到那家，揣著露西·桑德斯的照片，拿給櫃檯後的接待員看。露西·桑德斯外向和善，還不到二十五歲，充滿魅力熱情，全身的特質都很適合當個騙子。就是因爲這樣，她才惹上麻煩被捕。棄保潛逃後，兩個星期不見人影，讓她亡命天涯的那兩萬元仍沒找到。這已經不是私家偵探的工作了，比較像賞金獵人，但這樣就有錢付帳單了。起碼我希望能拿到錢——露西·桑德斯是我的第一筆賞金。
