# 父仇者 | 172

26

一點三十分，我跟裂唇警官在離目標住所兩條街的地方跟武裝應變小組會合。如果唐納德·史拉格斯綁架了醫生和他的女兒，此人非常危險，所以我們才招來武裝備援，免得有無謂的傷亡，因爲大家都不需要在此喪命。他們正要進去的時候，施羅德打電話來了。
「收到了艾琳·史丹頓的新消息，」他說。「讓她離家的男人叫作布萊恩·韋斯特。他是玩音樂的，已經結婚，有兩個小孩，離家的時間也差不多。他們兩個月前搬去澳洲，好跟一些老朋友組團演奏。他們現在還在那裡，所以不太可能涉案。也沒有牽連的理由。他們今天就搭飛機回來。等小組進去了，立刻打給我。」他說完就掛了電話。
應變小組的組長一身黑，穿了防彈衣，要是我做他的職務，肯定沒辦法像他這麼鎭定。我在車旁晃來晃去，小組則不斷前進。不到一分鐘，他們就進了門，立刻把整棟房子清查一次，又用了兩分鐘確認沒有問題。我也準備進去。史拉格斯家是棟屋齡約四十年的磚房，鐵皮屋頂很低，配上大大的窗戶。車道裂開了幾條縫，縫裡生出了雜草，不過在滴了機油的地方野草就活不下去了。我穿過房子，一切看起來都很正常。一棟家庭住宅，地毯很醜，但家具不錯。有幾扇門不太容易拉開。地板上有玩具，冰箱上貼了紙條。牆上有照片，不過墓地裡的那個男人都不在裡面。
我走向客廳。沙發扶手上躺了無線電話，上面有數位顯示螢幕。我捲動電話簿，一條是瑪莉公司，另一條則是唐公司，我撥了唐的公司號碼。響了四聲後有人接起來了。
「你好，我是傑夫。」
「是，嗨，傑夫，唐納德在嗎？」
