# 父仇者 | 140

「你害他們覺得很丟臉。」
「不對，我給了他們名譽。我讓他們活在這裡，」他碰了碰自己的頭，「和這裡，」又碰了碰自己的心。「只有我在乎他們的名譽。全世界的人都繼續自己的生活，你也一樣。你繼續當醫生，繼續治療病人。如果你有一點點內疚，你就會變成不一樣的人，十五年前，看到你做的這些事，你就會放棄工作。不過你什麼感覺也沒有，除了現在。現在你會自責，只是因爲我來懲罰你了。史丹頓，你的生命也走到了這一刻，你做過的壞事會報應在你身上。這就是你該負起責任的時候。」
「你錯了。你們家發生的事，我從來沒有忘記過。我利用這次教訓讓其他人變得更好。求求你——」
「梅蘭妮，去跟妳妹妹坐在一起。」迦勒說。
「不要，我不要離開爸爸。」
「沒事的，小貓咪，」史丹頓給女兒取的暱稱讓迦勒的心抖了一下。他給女兒取過同樣的綽號。小貓咪。小瓜瓜。小公主。有時候則是小貓咪公主或小瓜瓜公主。
梅蘭妮哭了起來。
「照他的話去做，」史丹頓哀求。「妳們三個，去那一邊。」
她們照做了，凱蒂和梅蘭妮把奧克塔維婭夾在兩人中間。迦勒靠了過去，蹲在醫生前面，低聲說，「我保證，會給你不一樣的待遇。」
「拜託，拜託，別傷害我的孩子，」史丹頓也放低了聲音。「她們沒對你怎樣。要我做什麼都可以，不要傷害她們。」
「你給她們取了什麼暱稱？」迦勒問。
