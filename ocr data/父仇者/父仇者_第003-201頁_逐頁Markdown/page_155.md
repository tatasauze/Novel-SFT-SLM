# 155 | THE LAUGHTERHOUSE
Paul Cleave

因爲旁邊的電鑽開始轟轟亂響。
「那就是我說的。她可能在電視上看過她。我們要調到她有沒有接過很出名的案子。如果有的話，或許錢瑟勒因此看過她。如果有的話，或許那件案子跟我們現在的有關。如果沒有的話，錢瑟勒可能在別的地方看過她。不過她幫不上什麼忙，她不知道嗑了什麼，還沒清醒，手裡也有酒，跟她講愈久，她記得的事情愈少。看來海沃德只是在回家路上隨便挑個妓女，她跟案情可能無關。」
「我們馬上就會拿到搜查令，可以去看布朗的案件資料，」施羅德說，「不過我可以告訴你，我們已經查過新聞資料庫，沒找到她的名字。那不表示她接過的案子沒上過新聞，因爲很有可能媒體只報了嫌犯和受害人的名字，沒提到律師。我們正在調查法庭紀錄，但是跟其他政府部門一樣，沒有人懂得什麼是效率。查了雙方的紀錄後，我們今天下班前應該會有點線索，不過太令人沮喪了——你會以爲大家都會很努力，很想抓到那個畜生。」
「晚點等錢瑟勒比較清醒的時候，我再去找她。犯罪紀錄裡撈到了什麼嗎？」
「最近出獄的人，都沒有坐過十九年的牢。」他說。
「十九個月呢？」
「我們查到了——光是今年，出獄的就有上百人。但有沒有坐過牢，說不定沒有關係，」他說。
「這一切都是爲了報仇。這些年這傢伙在哪裡？爲什麼不早點把這些人殺了？過去七年來，維多利亞·布朗不可能惹到他，不在牢裡，會在哪裡？」
「醫院？國外？軍隊？」
「應該是監獄。」我說，施羅德點點頭。
