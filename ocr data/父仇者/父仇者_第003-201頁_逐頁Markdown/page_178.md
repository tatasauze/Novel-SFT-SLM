# 父仇者 | 178

他微微一笑。「坐下來談好嗎？」他對著前排座位揮揮手。
「抱歉，但我在趕時間。」
「趕到沒時間坐下來？好吧，告訴我，我可以幫什麼忙？」
「我在找一個人。我昨天晚上在這裡碰到他，他或許常趁晚上的時候過來。我覺得他可以幫我們調查一件案子。」
「來這裡的人不止一個，」他的微笑消失了，皺眉取而代之，「對我說的話，都必須保密，泰奧，你知道吧，大家都知道。」
「別擔心，我不會逼你洩露祕密。我只是要你告訴我你認不認識他。」
「嗯，我不知道。聽起來很有可能會逼我洩露教徒的祕密。」
「我說了，我不想問他告解了什麼。但這件事情很重要。昨天晚上有三個小女孩被綁架，我們認爲是他幹的。」
「噢，噢，太糟了，」他的總結一點也不糟，挺正確的。「他叫什麼名字？」
「我不確定，可能叫詹姆士。」
「就叫詹姆士？」
「他昨天晚上來過。」
「昨天晚上我睡著了，」雅各神父說。
「他大概一百八十三公分，八十六七公斤，五十歲左右……」
「說了等於沒說。」雅各說。
「他臉上有疤，多年的傷疤，感覺他被狠狠揍過。」
