# 055 | THE LAUGHTERHOUSE
Paul Cleave

8

你一定不能把人給殺了。
離開養老院的時候，施羅德的話還在我耳邊迴響。他這麼說，好像我必須面對什麼職業危害。
天空一片漆黑，掛了幾朵雲，城裡的燈光和生活照亮了天空。我往妻子住的療養院開去。穿過了正門，進了門廳，溫暖的顏色和溫暖的空氣包圍住我。十一點了，接待處的護士對我微笑，問我好不好。我說還不錯。探訪時間三個小時前就結束了，不過護士都認識我，只要不礙事，我隨時都可以進去。
我走到了妻子的房間，邊走邊找她的護士，總希望有一天她來迎接我的時候，會告訴我好消息。實際上，消息每次都一樣———————沒有新消息。妻子的狀況沒有變化，永遠不變。當她不在睡覺的時候，眼睛直勾勾看著前方，被餵食的時候，腦子裡有足夠的突觸要她咀嚼，但不足以讓她的眼睛聚焦，沒有足夠的活動突觸能讓她對我微笑和握住我的手，她永遠像棵植物，除非奇蹟出現，除非科技進展，兩者都是我祈禱的目標。
我沒看到漢彌頓護士，就直接進了布莉姬的房間。她睡著了。床邊的桌燈散發出柔和的燈光，窗簾已經拉上了。
