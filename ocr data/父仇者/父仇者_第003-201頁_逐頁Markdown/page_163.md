# 163 | THE LAUGHTERHOUSE
Paul Cleave

24

在屠宰場外的車子裡，迦勒猛然一抖，醒了過來，收音機還開著。可惡。他本來只打算把眼睛閉個幾秒，最多五分鐘吧，一看手錶，他在駕駛座上已經睡了三個小時。陽光暖暖的，他又精疲力竭，一下子就不省人事。他在椅子上伸伸懶腰，睡著的角度把脖子壓得好痛。收音機正在播放午間新聞。有很多報導，但內容都很簡略。看似記者還沒挖到什麼內幕，但還是要先報出來。他想用手機，但信號太弱了，不能連上網路。
他下了車，靠在車上。太陽仍被藍天包圍，但靠近市中心的地方似乎出現了雲層。太陽照不到的地面仍有點濕濕的。附近有幾隻鳥。他彎下腰，撿起石頭，丟高了再接住，就比頭高一點而已，接住了再丟上去。第一次來這裡，是十五年前，壓著詹姆士‧惠特比來。那天有人死了。第一個死的是警察。他並沒有計畫要害死他。他知道那就是爲什麼警察告訴獄友他強姦謀殺了自己的女兒。他們要他受苦，他也受了很多年的苦，結果警察就高興了，說眞的，他也不能怪他們。
十五年前。天啊，真不敢相信已經那麼多年了。幾乎佔了他人生的三分之一。他女兒死去的日子已經超過活著的日子。眞的嗎？
十五年了。好古怪。那天他來的時候，外面還拉了犯罪現場的警戒線。他一下子就找到了女兒死去的那間房。看到血跡就知道了。整個地方冷到令人難受，才從車子走到門口，他就以爲腳上的大拇趾凍掉了。他搶先了警察一步，不過他確定他們能查出誰帶走了惠特比，跑到哪裡去，也知道他們調查出要對付誰後一定會來這裡。一切都講究對稱。不過那時候，他也是逼不得已——聽說，惠特比不會因爲自己做過的事而受到懲罰，因爲他被刑求後才認罪——他絕不能讓
