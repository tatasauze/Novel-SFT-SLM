# 147 | THE LAUGHTERHOUSE
Paul Cleave

「有關係，因爲有人殺了他，我要找出兇手是誰。」
「那關我屁事？」
「當然，有人被殺了，你怎麼能不關心。」
她聳聳肩。「隨便啦。我不知道。五分鐘。可能十分鐘。我知道的都告訴你了。我累了。」
我也累了。「再問兩個問題。兩分鐘，我就走人。」
她嘆口氣，好像我剛告訴她下個週末她得幫我搬家。
「快點說。」她說。
「妳跟他在一起多久？」我又問了一次。
「五分鐘。」
「妳認得這些人嗎？」我把另外三個受害者的照片給她看。都是事發前的照片——不需要用血淋淋的屍體照片來嚇目擊證人。我把三張照片并排放在咖啡桌上。
「不認得。」
「妳要不要再看仔細一點？」
「不用了。」
「他們都沒找過你？」
「我不接女客。」
「另外兩個呢？」
「我不接那些看起來做到一半可能會死掉的人。我不想惹那種麻煩。」
我唸出他們的名字，她一直搖頭。「我不知道。或許吧。他們很有名嗎？」
「不是名人。」我撿起了照片。
