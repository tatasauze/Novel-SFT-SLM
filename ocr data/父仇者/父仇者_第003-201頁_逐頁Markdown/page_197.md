# 197 | THE LAUGHTERHOUSE
Paul Cleave

「維多利亞·布朗。」他說。
「另一個呢？」
「我們不知道赫伯特·普爾和亞伯特·麥克法蘭跟案子有什麼關係，」他說。「我還記得那件案子的一些細節，」他補了一句，我也記得，不過他還是說明了那些細節。「我記得，惠特比兩年後出院了，沒過多久，他就害死了寇爾的女兒。」
「你有寇爾的紀錄嗎？」
他遞過來一個資料夾，我翻開封面。一打開就看到迦勒·寇爾的照片。十五年了，他看起來不怎麼像昨天晚上我在墓地看到的男人，卻跟我今天早上看到的一個人一模一樣。
「可惡。」我瞪著照片。
「怎麼了？」
「有沒有寇爾女兒的照片？」
「你要幹嘛？」
我猛然起身，椅子被我往後一推，差點翻倒。「上午我去過艾瑞兒·錢瑟勒家，牆上有很多照片，」我說話的速度變得很快。「迦勒也在裡面，這個迦勒，」我敲敲檔案照片，示意他看。「這個人，在這一連串事件開始前。」
「證據都在倉庫裡，現在和潔西卡·寇爾謀殺案有關的東西都拿出來了，」施羅德的口氣跟我一樣興奮。「裡面有照片，但我記得媒體的報導也很廣泛，網路上應該找得到照片。」
「哪裡可以馬上找到電腦？」
我們進了施羅德的辦公室。他移了移滑鼠，電腦活了過來。他坐到辦公桌後，我站到他後面，看他用鍵盤跟滑鼠，不到一分鐘，就找到了我們要的報導。
