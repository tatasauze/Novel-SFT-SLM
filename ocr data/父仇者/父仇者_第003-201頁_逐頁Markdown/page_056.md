# 父仇者 | 056

任，到最後我帶了鏟子跟槍，把他押到杳無人煙的地方，讓他苦苦哀求我原諒他，但我無法原諒。我把椅子拉到布莉姬旁邊，握住她的手，一坐就坐了三十分鐘。
離開的時候，我突然覺得很疲倦，這才想起我早上五點就起床了，開車到各大旅館尋找露西·桑德斯。除了累以外——————我沒在開車時睡著，一頭撞上燈柱，也是因爲我餓到胃都痛了，好餓，餓到彷彿飢餓生出了爪子，要從我的胃裡挖一條路出來。或許我現在回家也是好事，我最後向飢餓投降了，把車開進速食餐廳的得來速。前面排了好幾台車，我努力保持清醒來消磨時間。最後輪到我點餐了，把食物遞給我的人看起來消磨時間的方法是每天下班的時候把沒賣掉的漢堡吃掉。我把車開到公園裡，坐在黑暗中，今天結束，明天開始。公園裡只有我的車。我的宵夜還沒來得及入口，就已經碎掉了，漢堡也吸收了小紙盒的氣味。我很快就吃完，飲料也喝了————這十塊錢花得值得，我覺得自己比較清醒。我坐在車裡想著那兩個死人，都退休了，肯定有什麼關聯。或許只有這兩名受害人，或許會有更多。更多受害者，可能也都退休了，過去的某件事把他們拉在一起。點已經出現了，但不夠清楚，無法連起來。
我離開公園的時候，另一台車開了進來。它關了燈，直接對我衝過來。我雖然閃開了，卻差點撞上樹。或許駕駛人也是個來這裡吃漢堡的私家偵探，或許只是一對胡搞瞎搞的青少年。
我回到濕漉漉的街上，在晚上這個時候，我常常會想起妻子，然後想到女兒，心情愈來愈陰鬱。雖然已經過了三年，有時候我就這麼哭了起來。我不覺得累，也不覺得餓——有時候，像現在在這個時候，我什麼感覺也沒有。我用手指擦過眼睛，趁著眼淚還沒流下來以前就擦掉，我突然克制不了了，我一定要去看我的女兒，確保她很安全。我把車開到墓地，停在教堂旁邊，旁邊還有另一台車。在迷濛的雨中，我朝著女兒的墓走過去，想到那兩名死者，不知道他們有什麼共通點，還是都認識某個人。
