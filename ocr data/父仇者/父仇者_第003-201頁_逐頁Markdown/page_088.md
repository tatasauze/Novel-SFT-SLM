# 父仇者 | 088

「一樣。」我告訴他。
「很好。」他轉過身，我跟著他走，療養院的另一側我沒來過，不過看起來跟其他地方一樣———走廊上擺了塑膠盆栽風景畫，從窗戶可以看到花園。一路上經過了許多房間，病患的狀態跟我妻子差不多，有些比較好，我們經過的時候會轉過頭來看，有些比較差，身上連了大大小小的管子來延續無意識的生命。
「維多利亞·布朗，」施羅德說。「四十九歲，已婚，沒有小孩。七年前，她在購物中心的廁所遭人攻擊，就住進來了。她的頭被砸到水槽上，從此就沒醒來，」他說。「犯案的是誰也沒查到。」他補了一句。
「好多血。」我在房門外停下了腳步，探頭看看裡面。
「他砍了很多刀，跟一號二號一樣。」
「所以，惹惱兇手的事至少發生在七年前。」我說。
「一定是。我不認爲她進來後還能惹惱誰。兇手一定很氣她，」他說。「她完全不反抗，他還是這麼用力捅刀。」
「她以前做什麼的？被攻擊以前？」
「這就有意思了。她是刑事律師。」
「串通了什麼？」
我覺得背脊一陣發涼，有關聯了。「那就是兩個律師、一個老師、一個會計師。他留下訊息了嗎？」
「在額頭上。跟其他人一樣。妳跟他們串通了。」
「串通了一號受害者不夠關心和二號受害者不值得做的事情。」
