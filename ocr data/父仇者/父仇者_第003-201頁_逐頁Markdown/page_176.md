# 父仇者 | 176

「有幾百個檔案，」施羅德說，「其中一定能找到關聯。」
「史拉格斯說他把車賣給一個叫詹姆士的人。詹姆士顯然還沒去登記過戶，」我說。個人買賣車輛時，買主跟賣主都要填寫持有人轉讓申請書。「史拉格斯已經登記了。那我們可以找到他姓什麼，假設他用了眞名，不過我不覺得他會用眞名。」
「我來打電話查查看。」
「沒看到檔案裡有人叫詹姆士？」
「我會查，不過那或許根本不是那人的眞名。車子已經送到警局來了。看來他擦過車子，到處都找不到指紋。」
「可惡，應該有啊。」
「嗯，都找不到。」
「等等，等一下。檢查引擎蓋下面。」
「什麼？」
我告訴他我幫那人發動車子的經過。「電瓶旁邊可能有指紋，不然引擎蓋鎖附近應該也有。」
「我來安排。你現在要去哪裡？」
「回警局，」我說，「不過我要先去查出嫌犯的眞實姓名。」
