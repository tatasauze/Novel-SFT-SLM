# 父仇者 | 182

「史丹頓扮演什麼角色？」
「他作證說惠特比需要接受協助，犯罪不是他的錯，而是在養育過程中遭到虐待的結果。」
在我來到墓園後，又有其他人來了，我跑過去的時候，有些人瞪著我看。汗珠從我的額頭上滴下來，那些人往我背後看，想知道誰在追我，但我背後就那兩座揭開了祕密的墳墓，告訴我到底發生了什麼鳥事。
「所以寇爾認爲是史丹頓的錯，」因爲惠特比無罪釋放後不到一個禮拜，他就害死了潔西卡·寇爾。「其他人呢？」
「我不知道，不過他們都跟這件案子有關係吧，」施羅德說。「其中一個人可能是惠特比的律師。你就在那裡等我吧，你可能比我還近。」
「離哪裡近？」
「等等。我再打給你。」
他掛了電話。我已經跑到車子旁邊了。我很想跳上車衝出去，但我不知道要去哪裡。我用手指敲著車頂。雅各神父就這麼被我丟在很遠的地方。我瞪著手機，等它響起來。我開始對手機講話了，反覆唸著來啊來啊。
過了四分鐘，我的咒語依然無效，到了第五分鐘，來了。我想，以後我就知道要唸多久了。
「六個星期前，迦勒·寇爾出獄了，」施羅德說。「我剛才打電話給他的觀護人。寇爾每次都準時赴約。甚至在布萊頓那家大輪胎廠找到了工作。我們打電話去了，但……」
「等一下，等一下，」我說。「六個星期前？」
「對。他今天沒去上班。我拿到了他的住址，我要你過去看一看。武裝小組會在那裡跟你碰面。沒問題吧？我起碼要二十分鐘才能到，」他給了我地址，我抄下來。
