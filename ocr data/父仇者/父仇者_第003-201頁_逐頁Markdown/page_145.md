# 145 | THE LAUGHTERHOUSE
Paul Cleave

牆上有幾張照片、白老虎的圖片，跑車和馬的海報，壁爐架上有個花瓶，裡面的玫瑰應該死很久了。電視上的按鈕和旋鈕告訴我它有多大年紀，如果看看背後的序號，說不定只有兩碼。照片中的友人面無表情，但還有其他的照片——她小時候，滿臉純眞的樣子，合照的應該是家人或朋友，還有看似父親或叔伯的人，家人的照片看起來就是正常的一家人，擺出正常的微笑，不知道他們現在在哪裡，不知道他們做錯了什麼，讓他們的女兒願意走上這條路。
「你很納悶我爲什麼會這樣？」她問。
我轉頭看著她。
「對。」
「你在想我怎麼變成現在這個樣子。」她說。
「對。」
「我被大宇宙惡搞了，」她對我說，「而且搞我還免費。問我你要問的問題吧，讓我把酒喝完，就可以去睡覺了。」
我拿出布萊德·海沃德的相片，兩個月前拍的，照片上本來有他太太，被剪掉了。他看起來很開心，有可能是因爲他的暑假過得很愉快，也有可能因爲他拿到了集點卡，跟十個妓女做過後，第十一個就不用錢。
「妳昨晚看過他。」
「對。」
「妳以前看過他嗎？」
她聳聳肩。「他們看起來都一個樣，」她說。「我比較記得誰會洗澡，誰不會洗澡。這個男人——他事前沒洗。話說回來，我也沒洗。」她直視著我的眼睛。
「妳昨天晚上什麼時候看到他的？」我希望她只要告訴我事實就好。
