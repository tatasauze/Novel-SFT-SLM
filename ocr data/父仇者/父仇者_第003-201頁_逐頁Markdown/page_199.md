# 199 | THE LAUGHTERHOUSE
Paul Cleave

程序，惠特比沒有機會說出發生了什麼事。他告訴了他的律師，這次不是維多利亞‧布朗，但惠特比死後，律師並未公開消息。他有小孩。他知道他的委託人入土後，大家都能好過點。他反而來了警局，說除非揍過惠特比的人丟了飯碗，不然媒體就會聽到一個大消息。那名警探沒等到被開除就辭職了，律師很滿意，從此封口。
我從未見過迦勒·寇爾。他被帶去陳屍間認女兒屍體的時候我不在。他站在警局大廳裡嘶吼著要報仇時我也不在。一天後，惠特比從警局的牢房前往法庭時，被迦勒·寇爾跟大舅子借來的搬家公司卡車撞到了，我那時也不在場。卡車撞上移送犯人的車子後，駕車的警官當場死亡，車裡另一名警官雙臂骨折，一隻眼睛從此失明。惠特比逃過了車禍，逃不過接下來的禍事。迦勒把他從殘骸裡拉出來，拖上自己停在附近的車，然後前往屠宰場。
迦勒·寇爾把詹姆士·惠特比砍得體無完膚。
他用了一把廚房刀。每次把刀戳進他的身體裡，他把刀子上下拖拉，製造出來的傷口把惠特比撕碎了。我沒看過現場。被徵召到現場幫忙的警官裡沒有我，我深感幸運。聽說惠特比的血肉鋪滿了地板，被割爛的器官從他體內掉了出來。聽說他們得用水桶收集遺體。聽說糟糕到法醫也無法判斷惠特比在車禍中是否受傷，因爲沒有部位完整到可以用來判斷。
我也知道，如果算算傷口的數目，總共是十九刀，這則要歸功給法醫。
惠特比死後，迦勒·寇爾開車回家。他渾身是血。他妻子認不出他是誰。他走進門後她放聲尖叫，鄰居報了案。她說，他看起來就像用血洗過澡。她說，他好像剛從一部恐怖電影出來。寇爾什麼都沒說，逕自去洗澡，等他出來的時候，妻子坐在沙發上，知道他剛才幹了什麼。他們擁住彼此，警察幾分鐘後就到了。他束手就縛，所有的罪都認了，四天後，他的妻子自殺了。星期一，女兒死了，到了週末，什麼都沒了。她沒留下遺言。寇爾被判刑十五年。入獄的第一個星
