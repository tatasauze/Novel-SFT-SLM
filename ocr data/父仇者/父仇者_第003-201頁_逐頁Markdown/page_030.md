# 父仇者 | 030

「丟飯碗後也會清醒。你最好告訴那些同事，現在馬上回到計程車，他媽的快滾吧。」
「我就告訴你，我們會想出辦法來。」
這時，警探似乎都知道該怎麼辦了。他們從樹後回到計程車旁，靠在車上，沒有人離開。肯特警探也在。他們明白了，這裡有條界線，如果越線了，可能會遭到訓斥，更糟糕的話則被炒魷魚。透出電視光芒和餐廳燈光的窗戶旁站了老人家，往外看發生了什麼事，他們都希望這群人裡有自己的訪客。
「老天爺啊，太噁了，」施羅德看著另一名警探衝到樹後。「不過總比在前面的草地上撒尿好。」他補了一句，追過去仿效他。穿著制服的警員不知道該怎麼辦。該叫長官回家？還是讓他們污染犯罪現場？他們進退兩難了。住戶和員工也一樣不置可否，很有可能再過幾分鐘記者就會來了。到時候施羅德會死得很難看，喝醉的警察也逃不過一劫。如果大家都清醒，就會知道他們不該來這裡，不過喝醉的人就有這個問題———做出錯誤的決定。沒喝醉的人都知道不該酒後駕駛，喝醉以後卻覺得開車也沒關係。我去年就是因為這樣而入獄。
養老院的單位很多，看起來像一棟一棟小房子，但並不獨立，屋頂都是黑色，牆壁則是小鹿斑比的顏色。整個社區的設計創意或許來自樂高積木。到處都是花，應該有幾百萬朵，正符合老年人的喜好，不過花都快謝了，天氣一冷就要殞落。植物和老人總分不開————一到六十歲，就應該喜歡玫瑰花和杜鵑花。在我看來，唯一能防止竊賊入侵的理由只是這裡沒什麼好偷，只有他們收藏的唱片和回憶，以及曾有一度很流行但現在看起來很古董的衣服。
「長官？」一名警員走過來。他看起來很年輕，也很緊張，或許第一次看到犯罪現場吧，就算不是第一次，他也很希望自己來這裡是爲了其他的理由。「看起來警探中只有你沒喝醉了。」
我不假思索地點點頭。「告訴我找到了什麼。」
