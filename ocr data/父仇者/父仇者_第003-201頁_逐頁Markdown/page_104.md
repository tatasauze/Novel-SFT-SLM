# 父仇者 | 104

「眞的嗎？眞的像他們說的嗎？」他向我靠過來，似乎要聽我講祕密。「有人敲開他的門，當著他太太的面把他殺了？」
「在這個階段，我不能討論案情。」我說。
「天啊，我覺得……天啊，」他說。「明天我們……」他搖搖頭。「他怎麼就死了？」他問。
「沒道理啊。」
「向來都沒道理，」其實不然，有時候真的很有道理。「你可以多聊聊布萊德嗎？他喜歡在事務所上班嗎？有很多朋友嗎？大家喜歡他還是討厭他？他會不會偷拿公司的文具？會不會趁抽菸的時候溜班？」
「會。」
約翰·摩根靠回椅背上，接下來我們聊了布萊德·海沃德的生平，他說的話很有悼詞的感覺，在約翰的總結裡只有好話。我覺得他說的應該都是眞的。說不定另有一個人講到布萊德·海沃德，就全部都是壞話。我用心聆聽，做了筆記，如果海沃德眞的有外遇，我想了解是不是外遇害他有今晚的結局。
談完了，他領我走到門口。
「你們會抓到兇手嗎？」
「會。」
「跟爺爺開膛手有關係嗎？」
我無法給他答案。
「可能有。」我說，心裡納悶媒體可能已經知道了。
「你來之前，我聽廣播說又死了一個。那就是四個了，」他說。「到底怎麼了？」
我回到車旁，住在這條街上的人都安安穩穩睡在被窩裡，在自己安全的小天地裡。氣溫差不多都是涼爽的八九度。夜晚會一直這麼涼爽，然後落到零下一度，接著變得更冷，就進入冬天了。不論有多冷，到時候應該了結了——就算沒把這個人關起來，他應該也把人都殺光了。我掏出手機，打電話給施羅德，告訴他我跟摩根談完了，他給了我獎賞，告訴我沒有其他人被殺——起碼我們還沒聽說。我把頭靠在頭枕上，闔上眼睛，又很快睜開，免得眼睛一閉就睡了六七個小時。我一隻手把手機靠在耳朵上，另一隻手擦了擦臉，手掌感覺到鬍碴刺刺的。往鏡子看了一眼，我一臉頹喪。最近我似乎就走這個風格。
「我幫你準備了點東西。」他說。
「是嗎？」
「早餐。再不吃的話我就沒力氣了。小青蛙見。」
