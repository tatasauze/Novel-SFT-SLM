# 049 | THE LAUGHTERHOUSE
Paul Cleave

慣爬上了莖幹，不知道為什麼迷了路，或許很奇怪怎麼到了晚上這個時候天色還這麼亮。
我從臥室開始搜查。到處都有指紋。鑑識小組的動作很快。或許他們很想回家，或很想去另一處現場，或許他們覺得今晚會出現更多屍體。床鋪得很整齊，非常普通，就那種鰥居長輩會用的花朵圖案被套。書櫃裡的書什麼類型都有。兩本盆栽植物，一本風景繪畫，看不出有什麼東西能讓它們的主人惹惱別人到把他砍了這麼多刀。五斗櫃上放了照片，死者跟小孩，或孫輩，他每天晚上睡前可能都要看一下這些照片。照片裡沒看到他的妻子。
我戴上剛才那雙手套，只是反過來戴。我翻了抽屜和櫃子。幾分鐘後施羅德也加入了，他身上的啤酒味散了一點。
「你怎麼想？」他問。
「一號受害者是律師，」我回答。「不知道惹了誰。」
「他不當律師已經十年了，」他說。「為什麼要等這麼久？」
「或許被他惹到的人去坐牢了，」我說，「才剛出獄。」
「有可能，但受害者不是刑事律師，他專辦離婚。」
「有些人可能因此更希望他死掉吧，」我告訴他。
「二號受害者七十八歲，」他說，「但在高中教了四十年書。十三年前退休了。」
「家人呢？」
「離婚了，兩個小孩。」
「難怪照片裡沒有太太，」我說。「你查過他的離婚律師是誰了嗎？」
「現在已經有人去查了。」
