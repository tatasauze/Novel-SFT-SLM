# 005 | THE LAUGHTERHOUSE
Paul Cleave

「天啊，我的手他媽凍僵了，能不能點菸還不知道呢。」
「那表示你該戒了。」泰特說。
「誰說的？上帝說的嗎？看看這裡，他趕快去做別的事情吧，不要管我，」藍德里回答。
「你看到地板了嗎？」
泰特點點頭，看到了，也不會忘記。
藍德里繼續說下去。「看起來好可怕。你要是死前就看到這王八蛋地板，是什麼感覺？」他用力吸了一口菸，菸頭燒得猩紅。他看看建築物上的大字。「尸宰場，」他說。「要噁心的笑話嗎？」
泰特沒答腔，只把手插在口袋裡，輕輕跳動了幾下。
「可憐的小女孩。」藍德里說。
「她叫潔西卡。」泰特說。
藍德里搖搖頭。「不行，不能給她安上名字。」
泰特看看他，低下了頭。
「聽我說，泰奧，」他把香菸從嘴裡拿出來。「我知道她有名字，好嗎？可是你不行那樣。以後還有很多悲慘的故事，你只能把受害人當成案件，僅此而已，不然這份工作你做不久的。」
另一名警探從屠宰場出來，手裡拿著亮紅色的書包，上面畫了一道彩虹。他伸直了手臂把書包拿在前面，彷彿拿著貓咪剛送進屋裡的死老鼠。
藍德里又抽了一口菸。「你聽到他招供的內容了，對吧？」
泰特點點頭，他聽說了。
