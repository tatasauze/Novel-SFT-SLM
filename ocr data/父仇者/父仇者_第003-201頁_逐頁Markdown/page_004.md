# 父仇者 | 004

「那個混帳……」
藍德里警探從口袋裡掏出一包菸，手指凍得發抖。他看著眼前的景象，臉色蒼白如紙。
「聽說他招供了，」泰特站在旁邊，雙手插在外套口袋裡，冷空氣像刀子一樣割著他的臉頰。
「是啊，招供了，」藍德里咬牙切齒地說。「但他不會坐牢。他的律師已經開始運作，說他精神失常，沒有行為能力。二十四小時前他把那個小女孩帶到這裡，像宰羊一樣把她切碎，現在他卻可能只要去醫院住一陣子就能脫身。」
「這不公平。」
「世界上本來就沒有公平這回事，泰奧，」藍德里深深吸了一口菸，菸頭在寒冷潮濕的空氣中微弱地燃燒著。「這座城市的壞人愈來愈多，而我們能做的卻愈來愈少。那個小女孩的父母親……你根本無法想像他們有多崩潰。那個王八蛋甚至還偷走了她的一隻鞋子當作紀念品。」
兩名警探默默地站在風雪中，看著鑑識小組將小女孩的遺體抬上靈車。雪花落在黑色裝屍袋上，隨即融化成冰冷的水滴。
