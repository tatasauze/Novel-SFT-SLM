# 父仇者 | 196

「好一點點，」他說。「那個王八蛋清潔工以前都會在裡面吐口水。」
我拿起咖啡杯，正要喝進肚子裡的時候卻改變了主意。「反正我也該戒了，」我說。「發現了受害者之間的關係嗎？」
「快要有線索了，」他喝了一小口自己的咖啡，「不要一小時，法庭紀錄就會送來。你看完了嗎？」他指指我手裡的檔案。
「快看完了。可憐的王八蛋，一輩子碰壁。」
「也看了母親的檔案嗎？」
「沒。」
「她眞的很棘手。你見過她嗎？」
我點點頭。
「我碰過她。幾年前，她被控順手牽羊，我負責去抓她。她靠著技術細節脫罪。她把超市裡的啤酒都喝掉了，技術上來說她沒離開營業場所，所以技術上她什麼也沒偷，我們帶她出去，她才算離開，也就是說她並非自願離開。她讓我印象最深刻的是那嘴口臭——我敢打賭她絕對好幾年沒碰過牙刷了。這女人……她讓人不寒而慄，」他說。
「這一切，都是因爲她。」我說。
一開始他還搖頭，後來他也點頭了。「或許吧，可以那麼說，」他說。「那麼，史丹頓就是站上證人席的醫生，說惠特比有機會得救，我們也找到了另一個關聯。」
「其他的受害者？」
他點頭。「要不要猜猜看誰負責幫惠特比辯護？」
「一定是其中一個死掉的律師。」
