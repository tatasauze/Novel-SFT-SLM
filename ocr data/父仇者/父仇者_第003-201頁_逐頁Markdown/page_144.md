# 父仇者 | 144

22

艾瑞兒•錢瑟勒家泛出潮濕貓咪和狗的味道，我盡量遠離牆壁，免得衣服也濕了。我低頭看看鞋子，深怕鞋子壓進了地毯，就會踩出水來。我們穿過了客廳，天花板上有大塊的污漬，灰泥和油漆已經斑駁脫落，屋頂上聚集的雨水往下壓，把天花板中央壓得向外彎，地板上放了個水桶接雨滴。電燈裡沒有燈泡，裝了也可能會發生火災，因爲這裡實在太潮濕了。艾瑞兒沒問我要不要喝茶或咖啡，也沒拿出海洛因來請我。她坐到沙發上，整個人立刻陷了下去，一口一口喝著飲料，一下子喝了一半。我沒坐下，只想快點走人，希望離開前能從她口中聽到有用的資訊。
「你上次喝是什麼時候？」她問我。
「幾個小時前。」
「呵，說得好，」她說。「眞好笑。」
「妳做這行多久了？」我環顧整間客廳。
「哪一行？」她問。「爲了錢跟男人搞，還是指我一事無成？」
「都有吧。」
「從十三歲開始。」
「天啊。」我說。
「你好像很同情我。」她點了一根菸，又示意問我要不要，我眞的覺得她很可憐，誰會不同情她呢？我對著遞過來的香菸搖搖頭。「這就是人生，對不對？」她盯著菸頭看了幾秒。「或許看起來很糟糕，但我也認識過得更糟糕的人。」
