# 父仇者 | 148

「最後那個，她不是律師嗎？」
我的手停在照片上不動。我把維多利亞·布朗的照片滑了出來，放回桌上。「妳認得她？」
「照片是什麼時候拍的？」她問。
「十年前。」似乎有種關聯正在成形，我心中有一絲絲興奮。
「天啊，十年前的事我都不記得了。三年前，我用了一些藥，惹了麻煩，你應該知道是什麼，付了罰款後，我只好住在這個鬼地方，而不是以前住的那個比較好的鬼地方。我覺得她是我的律師。」
我沒那麼興奮了。「三年前她已經昏迷了。」
「難怪她沒幫我擺脫麻煩。」
「妳一定在別的地方看過她。再看清楚一點。」我敲了敲照片。
「你剛才說再兩分鐘就好了。」
「拜託妳了。」
「我不知道。」她又開始迷迷糊糊了。
「另外這兩個人呢？」我問。「這個，他以前也是律師。」我又把第一張相片拿給她看。
「從沒看過這個人。」她說。
「妳確定嗎？」
「不確定，我當然不確定。我出門去買東西，買衣服跟食物。或許在超市裡，在街上，曾經碰過他。我怎麼可能知道？」
「這個呢？」我又回到二號受害者。
「我不記得。」
