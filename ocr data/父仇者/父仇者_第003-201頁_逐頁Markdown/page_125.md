# 125 | THE LAUGHTERHOUSE
Paul Cleave

20

我們一起下樓，走樓梯，不搭電梯，可說是爲了節約能源，全世界的人都該節能減碳，也可說是爲了運動。我們到了底層。施羅德穿過通往停車場的門，我走向大廳，下了台階走到街上。那兒有群記者圍成了半圓，史蒂文斯警司站在中間，他的光頭在陽光下閃閃發亮。大家都盯著他，但強納斯·瓊斯除外，他離開了那群人。我沒停下來聽警司的說法和記者的問題。瓊斯跟在我後面。我覺得我可以想辦法甩掉他，但他有特殊能力，早就知道我把車停在哪裡了。
我的車停在半條街外，有人倒車時撞到我的車，左側的頭燈被打爛了，地上有碎玻璃，沒有留下字條。我用腳把玻璃掃到路邊。車子從這頭堵到那頭，大家都湧進城準備上班了。
「讓我猜猜看，」我轉向強納斯，「今天早上起床，你就知道有人會弄壞我的車？」
「太好笑了，警探。我說對了吧？你現在又恢復探長職位了？」
「你說呢？」
「我可以幫你，警探。我幫你，你幫我。我有特殊能力，你不肯承認就是在浪費時間。」
「眞難相信世界上有你這種人，」我說。「一早已經兩次了。你一定很著急。」
「泰奧多，不要趕我走。有一個機會，我們兩人都能做好事。」
「然後你會寫一本書嗎？」
「你也有功勞，也會拿到錢，看看你的車，我覺得你可能不習慣拿到酬勞吧。」
「不用了，謝謝。」我告訴他。
「我可以幫你，泰奧多。」
