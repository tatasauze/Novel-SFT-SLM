# 135 | THE LAUGHTERHOUSE
Paul Cleave

他帶她走回屠宰場。她跟凱蒂剛才一樣，到父親旁邊用雙臂圍著他。迦勒靠在牆上喝柳橙汁，瞪著他們看。他記得自己的女兒也曾這樣抱著他。
「夠了，」她的反應跟凱蒂不一樣，立刻放開了手。「奧克塔維婭該換尿布了。」
「是嗎？那你爲什麼不幫她換？」
「因爲我叫妳換。妳妹妹可以幫忙。」
她們讓奧克塔維婭躺在毛毯上。凱蒂開始哼歌。他聽不出是什麼曲調，不過聽起來應該是她自己發明的，不知道花了多久才編成。醫生哭了。眞可悲。
「束手無策是什麼感覺？」他問，但史丹頓當然無法回答。女孩子們都看著他，但不說一句話。
「不太像個男人嘛，對不對，」迦勒說。
史丹頓直直瞪著他。他含糊不清地說了更多次幹你媽，努力想掙脫塑膠繩，但說眞的，掙脫了又能怎樣？
「我們弄好了，」梅蘭妮說。
凱蒂停止哼歌，唱了起來。「A、b、c、d、g、f、g……g、f、g，」她反覆唸誦。
他發覺她唱歌的聲音很好聽，但他沒興趣聽。「閉嘴，」但她唱得更大聲了。
「我說。住。嘴。」
「她停不下來，」梅蘭妮說。「她眞的很難過的時候，就會這樣唱歌。」
「爲什麼？」
「因爲她覺得難過，我說了，你沒聽到嗎？她以前不會這樣。」
「A、b、c、g、f、g……」
