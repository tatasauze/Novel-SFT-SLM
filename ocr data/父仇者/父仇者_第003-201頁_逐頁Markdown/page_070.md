# 父仇者 | 070

「三號受害者名叫布萊德·海沃德，」他說。「四十一歲，會計師，有妻子跟兩個小孩，事發時他們都在家。」
「小孩看到了什麼嗎？」
「他們已經睡了。」
「所以，因為房子裡有人，兇手不敢逗留，沒時間確定受害人死了沒。」
「理論上是這樣，」施羅德說。「到目前為止，查不出他跟其他受害者有什麼關係。」
「所以一個老師、一個會計師、一個律師——」
「一起走進了酒吧，」施羅德說完搖搖頭。「聽起來真的很像安排好的，」他補了一句。
海沃德的太太本來一直盯著門，現在卻看著我們，對朋友低聲說了幾句話，站起來，走了過來。她抓住外套的下擺往下拉，拉平了外套，然後拍掉前襟上的眼淚。施羅德介紹了我是誰，但沒提我的職稱。她點點頭表示知道了，沒打算跟我握手。我覺得自己好多餘。
「有什麼消息嗎？」她對著我們兩人問。
「我們大致上掌握了案發的過程，」施羅德說。
「是嚴厲開膛手嗎？」
「什麼？」
「爺爺開膛手。」
「爺爺開膛手。」施羅德糾正她。
「爺爺？」
「爸爸的爸爸。」
「可愛。」她說，但語氣跟「可愛」完全沾不上邊。
