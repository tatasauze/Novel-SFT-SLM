# 父仇者 | 068

「什麼？」
「所以我現在打電話給你，沒等到早上再打，那就是為什麼我們需要所有的人手。第三名受害者出現了。」
「你不是開玩笑吧。」
「基督城醫院。他快死了，不知道撐不撐得住。五分鐘前進了醫院。」
路上的車子很少，百分之九十是計程車，運送喝醉的人。醫院附近的車子比較多，主要入口處發生了車禍，飆車族開上了人行道，撞到了街燈柱，把人困在車子裡。停車場空空如也，我也懶得投錢。我走到急診室，裡面滿滿都是喝醉跌倒受傷的人。我打電話給施羅德，他穿過安全門出來找我。
「鞋子很不錯嘛。」他低頭看看我的慢跑鞋。
「你的也不錯，」我低頭看他的慢跑鞋，或許他跟我一樣，只有這雙鞋沒弄濕。他也換了一件上衣。「我們可以當慢跑鞋兄弟。那麼，當顧問有薪水嗎？」
施羅德聳了聳肩。「有，不要問我多少錢，幹，說不定比我的薪水還高。」
我們穿過他走出來的門。經過一連串錯綜交雜的走廊，可能有人在這裡光找路就找到死了。醫生和護士快步來去，病人躺在布簾後的小隔間裡，笑聲和哭聲此起彼落。
我們沿著走廊，走進小小的休息廳，有兩個女人坐在椅子上，一個負責哭，一個負責安慰。哭的是他老婆，安慰的是鄰居或朋友。到了離她們約莫十公尺的地方，我們停下了腳步，免得被她們聽見我們在說什麼。
