# 父仇者 | 112

麼辦。現在，他只需要考慮怎麼睡才舒服。這裡只有水泥地板和少數的破爛家具，不太適合好好睡一覺。
他把史丹頓摜到他女兒旁邊，然後綁住了他的腳，再把幾條毛毯堆在牆邊躺了下來。他感覺到寒意從水泥地慢慢湧上來。女孩子看著他，他可以聽到她們哭哭啼啼，還有在地板上動來動去的聲音。十五年來，他一直要忍耐其他人發出的聲音，打鼾、哭泣、辱罵。現在，除非坦克從前門開進來，否則什麼聲音都無法阻止他入眠。
他想把燈關了，不過爲了孩子還是開著，她們已經飽受驚嚇，不需要讓她們更害怕。史丹頓也瞪著他。眼神中除了不解，還有恐懼，以及濃烈的怒氣和恨意。很好，等迦勒讓這個王八蛋選擇哪一個小女孩要先喪命的時候，就看哪種情緒會最先投射出來。
