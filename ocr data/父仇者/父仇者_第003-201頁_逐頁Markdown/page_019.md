# 019 | THE LAUGHTERHOUSE
Paul Cleave

「從警校畢業就離開了，」她說。「十年前，我被分發到奧克蘭，就一直想辦法要回來。」
「對了，我想到了，」施羅德轉臉看我。「艾瑪·格林已經申請到警校的就讀許可。」
「我聽說她要申請。」我說。
「艾瑪·格林。我不知道從哪裡聽過這個名字？」蕾貝卡問。
「她就是前一陣子被綁架的女孩，」他說。「泰特找到她了。」
「喔，對了，」她說。「那個女孩也被你………………」她說到一半就打住了。
去年我喝醉了酒，撞傷了艾瑪·格林，也因此入獄。
「對不起，」她說。「我太蠢了。我喝了三杯琴湯尼，喝太多了，」她搖晃著空杯子底部的冰塊。
「不是妳的錯，去年幹蠢事的是我，」我對她說，不知道我對艾瑪來當警察有什麼想法。
「好啦，事情都過去了。」施羅德說。
他又喝了一口啤酒，對話內容也變了。蕾貝卡再拿了一杯琴湯尼回來。我們開始聊施羅德的家人。他拉出皮夾，給我看他女兒的照片，還有六個月大的兒子。我從來沒看過他兒子；見過他女兒很多次，不過也很多年沒見了。蕾貝卡笑瞇瞇看著照片，告訴施羅德他的小孩很可愛，她說她沒有小孩，卻有兩隻貓，然後笑著說她明白他一定很辛苦。
他才開始說他兒子把東西塞進耳朵裡的事，手機就響了。他亂拍身上的口袋，開始找手機，還掏錯了地方。他接起來的時候，我聽到另一支手機響了。然後又一支響了。滿屋子的警探都在翻口袋，異口同聲報上姓名，肯特也不例外。大家聽著另一頭的訊息，沒有人說話。施羅德用一隻手撐著吧檯，穩住身子。他看看自己的啤酒，然後慢慢推開。蕾貝卡也把剛拿來——————一口也沒喝的飲料放回吧檯上。大家陸續掛了電話，然後又一輪手機響起，另一組警探接到召喚。消息從
