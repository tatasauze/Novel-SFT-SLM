# 父仇者 | 090

「護士在巡房的時候發現的。她看到血腳印，以為病人發生了意外。跟著血腳印走過來，開始尖叫。吵醒了其他病人，其他員工也趕快跑過來。這顯然不是臨時起意，」他說。「隨機殺人的話，不會去兩間養老院和一間療養院。兇手有份名單。問題是，上面有幾個人？」
問得好。這間房間的風景跟我妻子那間很像，她們兩人眼中的風景或許也差不多。擺設也一樣，床放在中間，旁邊留空間給護士走動。花瓶裡放滿了花，但連昏迷的病人都能看出是假的。房間裡向來感覺不到什麼情緒，等到有個瘋子來過，才充滿了狂怒。
「三號受害者跟其他人不符，」我說。「兇手費了不少功夫才溜進來，捅了很多刀後留下訊息，在布萊德·海沃德身上也可以下同樣的工夫。他可以開著車在城裡等他，或在路口把車停到他旁邊，或等他太太睡著了再下手。他甚至可以溜到他辦公室裡。」
法醫崔西・華特進來了，站在我們後面。她一臉倦容，一整天都在驗屍，現在一整晚要切開好多屍體。
「來吧，把這個完成，」她這句話就算是打招呼了。她把手提箱放在地板上，取出裝了探針的溫度計。她把探針插入女人的身體，那邊應該是肝臟，我轉過了頭，回頭時她已經在檢查溫度了。她又看了看房間，彷彿這樣就能測出室溫。她做了筆記，似乎算了一下數學，然後走過來。
「初步猜測，死亡時間是九十分鐘前，」她看看手錶，「大約是兩點半。」
「我十一點半來過，也可能差十五分鐘就十二點了。」要是我晚一點來，或兇手早一點來，情況就不一樣了。他走的時候或許我正好要停車，或者他來的時候我正好要把車開走。我說不定會看到他，說不定會感覺到發生了什麼事，說不定維多利亞·布朗的軀殼還能活下來。
「屍體可以搬走了。」崔西說完，就回到走廊上，朝著樓梯走去。
「我們查過了受害者的背景。」施羅德說。
