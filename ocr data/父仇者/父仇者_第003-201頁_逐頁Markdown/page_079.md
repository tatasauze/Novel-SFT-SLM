# 079 | THE LAUGHTERHOUSE
Paul Cleave

14

殺了這麼多人，迦勒累了。這一晚注定很漫長。他得集中注意力。保持體力。保持樂觀。下一個比較難，會比較費力氣，因爲不止一個人，而是四個———————醫生跟他的妻子，還有兩個小孩。有點棘手。昏迷的那個就很簡單。不費吹灰之力——她連他來了都不知道。但是醫生——他是關鍵。他為醫生訂了計畫，他要接受的懲罰絕非人類能夠承受。
他渾身是血，沒有衣服可以換了，不過他應該馬上就能找到乾淨的衣服。
醫生住的地段很貴，每天早上都會看到女僕和園丁來來去去，還有全職媽媽開著過大的車子送小孩上學。窗戶裡的燈幾乎都熄了。已經過了凌晨三點，他覺得好累，筋疲力盡，只想找個地方爬進洞裡睡一覺，累到他原本要花一個晚上做的事情可能要改成兩個晚上，但能一晚就結束的話，警察就沒時間查出來到底是怎麼一回事。目標就是一個晚上。只是他錯了，剛才不該跟著那個王八蛋回家。除了費時還費力，也有可能被抓。太蠢了。
他把車停在房子前面。有好幾個方法可以進去，不過有一個方法比其他的都簡單。他按著門鈴，直到走廊上的燈亮起來。
「誰啊？」男人的聲音，聽起來很累。
迦勒希望他太太沒跟著下床。「史丹頓醫生？」
「是我，詹姆士，我住在另一頭，」迦勒裝出焦急的口氣。「我女兒有事，我們出意外了。拜託，拜託，拜託你幫幫忙，」他還沒說完，就聽到鎖扭開的聲音。
