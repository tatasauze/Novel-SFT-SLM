# 071 | THE LAUGHTERHOUSE
Paul Cleave

「我們還不確定是不是他，不過很有可能，」施羅德說。
「妳丈夫在哪家公司工作？」我問。
「古德溫、德弗羅和巴克禮，」她說。
「他們有合作的律師嗎？」我問。
她聳聳肩。「你得問他們，應該有吧。」
「妳聽過赫伯特·普爾和亞伯特·麥克法蘭這兩個名字嗎？」我問。
「你搭檔問過我了，」她說，「我沒聽過。他們是今天被殺的那兩個人？」
「妳可以說一些妳丈夫的事情嗎？」我問。「別人喜不喜歡他？有沒有碰過問題？有沒有奇怪的電話？常常開會到很晚？」
「布萊德人很好，」她對我皺皺眉。「沒有奇怪的事情，大家都喜歡他。每個人都喜歡他。我希望你能問比較像樣的問題。」
「他通常幾點下班？」我問。
「不一定。他希望能在六點結束，但多半他要到七八點才能把事情做完。有時候就像今天晚上，要更晚下班。半夜以後才回到家也不算很奇怪。」
「他會先打電話告訴妳？」
「他五點左右打來，告訴我他可能要十一點才能回到家。手邊的工作很多。他有個同事因爲謀殺被捕，現在在坐牢，」她說，「所以布萊德的工作量也增加了。」
「所以最近才會加班到很晚。」我說。
