# 父仇者 | 106

他面前有盤培根蛋和蘑菇，旁邊還有一盤一模一樣的給我。我已經三年沒來這裡了。他幫我們兩個都點了咖啡，兩杯看起來都熱滾滾的，要不是這麼燙，我早把咖啡一口喝下去。我坐到他旁邊。後面有個快餐師傅正在吃自己的早餐。一名女服務生把客人點的東西端出來，另一個則在擦櫃檯。端菜的服務生穿著緊身T恤，很合她的身材，正面寫了5×5=25，下面寫歡樂時光。她發現我盯著她看，不知道我是在算乘法，還是盯著她的胸脯，不知道歡樂時光是什麼意思。她轉過身，背後寫了4×4=15和悲慘時光。
「摩根說了什麼？」施羅德說。
「海沃德是模範員工。他大約十點半離開辦公室。在晚上這個時候，開車回家大概最多十五到二十分鐘。太太十一點三十二分報警。她猜在她過去看之前，他已經到家十分鐘了。所以他有足足三十分鐘行蹤不明。」
「也不算行蹤不明，」施羅德滿嘴培根，聲音也柔和了些。「我剛跟法醫講過話。我告訴她你的理論。她先看了看屍體，在受害人的陰莖上找到了口紅的痕跡。」
「所以他要不是有外遇，」我說，「只能花三十分鐘見面，不然就是去召妓了。」
「或許他眞的眞的很喜歡口紅。」施羅德說。
「該說的就說了吧？」我問他。
他笑了。「就算去召妓，也不算違法。」
「算，如果她沒繳稅的話。」
「對啊，說不定海沃德用會計諮詢交換她的服務。」
