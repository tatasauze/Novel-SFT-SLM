# 025 | THE LAUGHTERHOUSE
Paul Cleave

「五十歲，」寇爾說。「我去年就滿五十歲了。」
「五十歲！好吧，你不可能是我孫子，我也不認爲我教過你，」他說。「你找錯老師了。你說你是做什麼的？律師嗎？什麼樣的律師？」
「不，我以前也是老師。」
「你是老師？教法律的嗎？」
「我是高中老師，以前是，十五年前就離開了。」
「啊，我也是，教書教了四十多年。我開始教書的時候，你才十歲，除非我算錯了，也就是說————啊，對了，你可能被我教過。所以你才會認識我嗎？」
迦勒搖搖頭。「不是。」他繼續把咖啡吹涼。「你參加了一樁案件，」他說，「十七年前。你參加了審判，你是品格證人。」
「十七年前。」
「我知道。」
「證人？噢，好久以前的事了。我好多年沒想到了。什麼時候？二十年前？」
「十七年前？好吧，如果你覺得是。很慘的案子，」他說。「我第一次上法庭，也就這一次。我再也不想去了，但我能怎麼辦？一定得去。那個小女孩好可憐，」他說，「被綁架了……還……還被他……她很幸運，能活下來。那個男孩，他很特別。真嚇壞了。但不是他的錯，你知道嗎？我就說了。他以前也是我的學生。」
