# 父仇者 | 164

他無罪釋放。犯下那樣的大錯，怎麼能不怪警察？不過警方刑求惠特比，也是爲了能安然無恙找回潔西卡。所以，迦勒只好代他們伸張正義。
上次來這裡的時候，把失去意識的詹姆士‧惠特比放在後座。迦勒閉上眼睛，仍能感受到那一刻，仍記得起那一天。他記得前一個晚上好漫長，他一夜無眠，摟著妻子，淚水和憤怒持續燃燒到早晨，但天亮了也不見好轉。一大早就下了雨，沖刷地上的積雪。沒有藍天，也沒有太陽。他跟妻子道別，再見到她的時候，已經殺了兩個人。
把惠特比帶到屠宰場的時候，他連引擎都沒熄火。他覺得最多只要幾分鐘，警察就會到了，他不想浪費時間。結果，時間其實沒那麼短。警察到他家逮捕他以後，才知道惠特比在哪裡。
他把惠特比拖過融雪，進了屠宰場。他把他拖進同一個房間裡，讓他躺在他女兒的血跡上，然後掌摑他，一直打到他醒來。迦勒竭力保持冷靜，他想問惠特比爲什麼要害死他的寶貝女兒，但他冷靜不了也問不了。他控制不了自己。
他馬上就動刀了。不能把女兒帶回來，但不會有其他小女孩死在這個人手裡。因此，迦勒願意坐十五年的牢。他的妻子願意自殺，把未出世的孩子一起帶走，因此，詹姆士·惠特比不需要其他的懲罰。
他把石頭擲向屠宰場，對準了一扇窗戶，一扇這麼多年來居然還沒破的窗戶，可是沒丟中——石頭打中了窗戶下方的牆壁，彈回野草叢裡。
再過五六個小時天才會黑，他要等天黑再行動，免得破壞計畫。他要去找艾瑞兒·錢瑟勒。先前離開這裡的時候，他本來就要去找她。他依然不知道看見她的時候要說什麼。也不知道該做什麼。首先，他要去找另一個靈媒。他有一整天可以殺人，反正現在閒得很。
