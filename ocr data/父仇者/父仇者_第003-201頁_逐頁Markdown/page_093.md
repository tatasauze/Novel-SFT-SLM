# 093 | THE LAUGHTERHOUSE
Paul Cleave

16

醫生的房子很不錯，如果可以的話，迦勒想住下來。他真希望能出去殺掉名單上最後幾個人之後，再回來舒舒服服地處理好心的醫生和他的家人。他可以睡在這裡，早上起來吃頓豐盛的早餐。在樓下寬大柔軟的沙發裡躺下，看看電視。只是醫生家並不是他已經規劃好的終點。
他蓋下行李廂，把史丹頓醫生關在裡面，眼皮變得好沉重，然後他走到駕駛座。身體好痠痛，都是被打的關係。坐牢讓他傷痕累累。這些年來他的左腿斷了四次，右腿只斷了一次，彷彿那些欺負他的人早知道他們討厭對稱。他的左臂斷了兩次，右臂沒斷過。指頭幾乎都被壓碎或折斷過，右手要很費力才能握成拳頭。坐牢前，他本來是數學老師。他很熟統計學。就統計學來說，人體內有兩百零八塊骨頭，他斷過十八塊。
在牢裡被打，因爲獄友聽說他姦殺了自己的女兒。條子說的。那是因爲迦勒殺了個警察。他默默承受，被打愈多次，他愈覺得心死，可是他也不反抗。他們剝掉了他的人性，當人性被奪離，人生反而有無限可能。
他在車上放了好多條毯子，從冰箱和食物櫃裝了一袋食物。他花了幾分鐘用手機讀網路上的新聞，看看人家寫了他什麼，不過他還不是真正的主角。媒體叫他爺爺開膛手，因爲一號二號受害者都老了。他們也提到三號受害者，可是沒有名字。四號受害者還沒上新聞。
三號受害者。迦勒沒照著名單走，他錯了。要是那人旁邊有人呢？要是有小孩呢？要是有小孩進了車庫怎麼辦？他能跑得掉嗎？
他上了樓。凱蒂和梅蘭妮在同一間臥室裡，他要她們在那裡等，當然也用上了膠帶和塑膠
