# 父仇者 | 128

「所以他是妳的客戶。」
「如果你要這麼稱呼那些人也可以。」
「他昨天晚上遭人謀殺。」
「怎樣，我該關心嗎？如果我死在暗巷裡，你覺得你們這些人會在乎嗎？」
「他有妻子跟兩個小孩。」
「少了他，他們會過得更好。」她放開了門，勉強自己跟我談下去。她伸手到口袋裡掏出一包香菸。
「妳錯了。」我對她說。
「我錯了？你有水晶球嗎？或許他會變成壞爸爸，醉鬼，愛打小孩的人。」
「拜託。他被殺的時候，小孩就在旁邊。」我告訴她，雖然不是事實，也差不了多遠。
她點了一根菸，把那包菸對我遞過來，我搖搖頭。「沒有他，他們會更快樂，」她說。「只是他們不知道。」
「或許妳說得沒錯。」我懷疑她說中了事實。
「我說對了。我很懂得看男人，警探，這是我的工作。」
「至少幫他們結案，跟我談一談吧。」
她抬頭看看天空，對著耀眼的光線瞇瞇眼，看了大約五秒鐘，彷彿答案就在那裡。「要下雨了，」她說。「下雨天生意就會不好。」她回眼看著我。「五十塊，」她說。「給我五十塊，我就跟你談。」
她看看我的車。
「我沒有五十塊。」我想起了昨天在汽車旅館裡帶著球棒的人。
「我也不覺得你有五十塊。」她說。
