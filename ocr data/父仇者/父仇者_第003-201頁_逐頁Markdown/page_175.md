# 175 | THE LAUGHTERHOUSE
Paul Cleave

「只有名字，詹姆士什麼的。我記不太清楚了，但我已經繳交文件了。都有紀錄。」
「詹姆士長什麼樣子？」
「什麼？天啊，怎麼說。應該說很可怕吧。」
「怎麼可怕？」
突然之間，他又充滿了活力，很想幫忙，很想趕快脫掉手銬。「噢，媽的，眞的很可怕。看起來他好像被揍慘了，而且常常被揍。我讓他先開看看車子，但我不敢跟他一起坐在車裡。」
「他怎麼付款？」
「現金，才五百塊。」他說話的速度跟連珠炮一樣。
「你問這幹嘛？」
「我們可以採指紋。」
「沒，都花光了。五百塊又不能花很久。」
這一點他倒說對了。
警官幫他解開了手銬，他摩擦著手腕。「這傢伙幹了什麼好事？」他問。「殺了人嗎？」
「謝謝你跟警方合作，唐納德。」我說完就走了，留下他靠在自己的車子旁邊。我聽到他開始發牢騷，只是周圍都沒有人願意聽他說話，他只好把嗓門拉得愈來愈高。我找到讓我搭便車過來的警官，說服他把車子借給我，我告訴他，他可以搭別人的便車回警局。他似乎不太樂意，但也沒跟我討價還價。
我打電話給施羅德。我把電話夾在肩膀跟耳朵中間，小心翼翼把車開過正在慢慢拆除的路障。媒體採訪車也來了，不過已經沒什麼好戲可看了。
