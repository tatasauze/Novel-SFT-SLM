# 父仇者 | 064

「對，對，」她說，「我感覺到一個年輕女孩。很漂亮。你的女兒。」
他點點頭，知道她看不見，還是點了頭。「對。」他不會提他兒子了。
「有一段時間了，」她說。「對不對？」
「對，」他回答，依然很想知道，但現在更懷疑了。她講話的方法很像在跟活人要資料，而不是問死者。
「你來找我，因爲你想跟她們對話，」她說。
他點了點頭。
她睜開眼睛，看著他。「很痛苦，」她說，「每個人都很痛苦。是不是？」
「對。」
「你來這裡，是爲了什麼？」她問。「跟她們講話？告訴她們你很想念她們？」
「我想告訴她們我有多抱歉，」他說。「我辜負了她們。你可以告訴她們嗎？」
她微微一笑。「你可以自己跟她們說，」她說。「有人來了。」她的眼光越過他的肩膀。感覺好像真的，他也回頭看看，不過只有那張沙發、那隻貓和通往走廊的門。
女人又閉上了眼睛。「對，我確實可以感覺到有人來了，」她說。她現在把頭歪到另外一邊了，他不確定真有靈魂的話，會在房間的哪邊。
「有個女的來了，」她說。「我……我看不太清楚。很漂亮。你的太太。她……她很難過她離開了你。很突然，你太太跟女兒都突然去世。」
「可以說是意外。」
「某種意外，」她說。「我不能……我沒辦法分辨出來。」
「很痛苦。」
