# 061 | THE LAUGHTERHOUSE
Paul Cleave

我在網路上搜尋赫伯特·普爾的名字，跳出了幾條舊新聞。
赫伯特·普爾曾是一名執業律師，十年前退休。十幾年前他曾參與過幾樁轟動一時的刑事審判，擔任陪審團主席。
我又輸入亞伯特·麥克法蘭的名字。
麥克法蘭退休前在高中任教，他也曾出現在某些法庭報導中，以品格證人的身分出庭。
巧合嗎？兩名受害者都在十幾年前參與過同一起案件？
這時，電視新聞插播了一則緊急報導。
「……警方證實，今晚在基督城發生了第三起兇殺案。死者為一名四十多歲的男子，在自家的車庫內遭到刺殺……」
我盯著螢幕，心跳漏了一拍。
兇手根本沒有停手，他在這座城市裡展開了瘋狂的殺戮。
