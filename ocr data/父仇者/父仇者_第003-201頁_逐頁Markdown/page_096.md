# 父仇者 | 096

算聽到了，也不明白。他用另一隻手固定住她的頭，把湯匙塞進她嘴裡。她吸了吸食物，嚼了幾下之後吞下去，然後又哭了起來。他看看膠帶，說不定用膠帶可以馬上讓她閉嘴，決定要試試看。他撕了一段膠帶，不過就在此刻，嬰兒打了個嗝，安靜了。她臉上浮現了微笑，閉上眼睛，不到十秒就睡著了。
他讓她在醫生的車裡安睡，然後回到自己的車上。他探頭進去，放開了手煞車。要把車子推下車道很簡單，但到了平路上就難推了。他站在駕駛座的車門內，轉動方向盤，使盡力氣推，膝蓋跟髖關節痛得要命，肩膀好痠，但他仍用力推，一定要做到。車子開始動了。很慢，但很穩，他把車子推過了一棟房子，再一棟，動力凝聚起來，兩分鐘後，他的車子跟醫生的住所已經隔了五六棟房子。他沒力氣繼續了。有兩棟房子裡面的燈亮著，不過街上只有他一個人。他擦拭了碰過的地方。雖然沒進過後座，他也擦了一下。他要警察找到他，不過時候未到，他的車子就這樣壞了，只讓情況更複雜。
他走回車庫，按下開門按鈕，載著除了母親以外都塞在車子後半部的一家人離開了。天啊，已經五點多了，他現在明白了，有些事一個晚上不夠，要兩個晚上才能做完。他揉揉膝蓋，左邊比右邊痛，按摩的時候，手也痛了起來。街道比剛才更模糊。眼前的東西都失去了清晰的邊緣，兩條車道似乎合成了一條，他揉了揉眼睛，似乎沒什麼幫助。他朝著法官家前進。殺了他，然後殺了惠特比太太，再回到屠宰場了斷一切。
他把車停下來，打了個哈欠。他把眼睛閉了幾秒，把前額靠在方向盤上。一個晚上要完成所有工作總是不容易。簡直是不可能。十年前他還有精力，現在不行了。真令人失望，不過他知道他說不定會成功。最終的結果依然不變，那就是為什麼他選擇這樣的殺人順序。警察找不出關聯。他花了好長的時間在Google上搜尋受害者，做了萬全的準備，現在他殺了三個很重要的人，
