# 父仇者 | 132

奧克塔維婭的水杯掉了，滾過了地面，她伸手去抓，可是拿不到，便哭了起來。他想到了四腳朝天的烏龜，這一定就是烏龜的感覺吧。凱蒂撿起杯子還給她，哭聲停了。
「拿去吧。」凱蒂說。
「貓。」奧克塔維婭說。
奧克塔維婭繼續喝水，凱蒂摩挲著她的手臂。迦勒喝了點柳橙汁，沖掉嘴裡的穀片。
「我想上廁所。」凱蒂說。
「OK，」他也想上廁所了。她把奧克塔維婭放回座椅上，然後他領著她走到外面。「就那棵樹。」她跑到樹後，身影消失了。他走到車旁，尿在引擎蓋上。
天已經全亮了，屠宰場依舊給人毛骨悚然的感覺。不過就是一棟廢棄的建築物，應該對人無害，就幾面被野生植物蓋滿的牆，但事實不然。在這棟建築物裡，他心愛的女兒死了，裡面有鬼魂。陰暗的房間放了巨大的肉鉤。裡面有夢魘。全世界的不幸，都聚集到這座屠宰場裡。
他站在那裡，讓陽光照在臉上。他的衣服感覺有點濕，但在外面站個十五分鐘就不成問題了。天空是藍色的，一片雲也沒有。美好的一天，或許一整天都這麼美好，或許一場雨打下來，整座城濕淋淋。他閉上眼睛，有那麼一刻，很短暫的一刻，他問自己能不能放下這一切。他不需要再回到屠宰場，不需要對付醫生和他的孩子，不需要殺人。他可以就這麼走開，找到一處海灘，坐在秋日的陽光下，盡情享受那氣氛，結局也就會不一樣。他會游泳，就選個方向去吧。看在他精疲力竭前能去到多遠。他以前泳技很棒。曾有一度，他能來回一直游，一點也不覺得疲憊，呼吸平穩，雙臂輕鬆地劃開水面。婚前他習慣一個禮拜游三次，通常每次游一小時。那是他唯一會做的運動。他會在上班前去游泳，泳池裡的人都跟他一樣熱愛游泳。婚後空閒時間少了，等女兒出生後，游泳變成那種你要等到老了卸下責任後才有時間做的事。
