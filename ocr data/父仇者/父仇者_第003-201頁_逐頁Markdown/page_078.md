# 父仇者 | 078

「新的受害者是誰？」
「她的名字叫維多利亞·布朗，」他說。「她是律師，幹，聽我說，」他搖搖頭，讓我知道真的很糟糕，「她已經陷入昏迷七年了。」
「什麼？你是說—————」
「昏迷。對，我知道，太可怕了。聽著，我現在就過去，我要你去找布萊德·海沃德的老闆，看能問出什麼。」
「你不要我跟你一起去嗎？」
「這就是問題所在。泰特，聽我說，我不希望你反應太激烈，好嗎？」我覺得嘴裡發乾了。
「我不想讓你跟我一起去，因爲你會反應很激烈。不過你太太沒事。」
我真的搖起頭來了，只搖了一下，因爲我又馬上恢復了。「我太太？怎麼了？」
「第四名受害者跟你太太住同一家療養院，泰特，但布莉姬沒事。完全沒事。」
我向前踏了一步。「你他媽的在說什麼？有人想要害她？」
「泰特……」
「沒有，並沒有。她只是剛好跟受害者在同一家療養院。」
「我現在過去。」
我已經穿過他身邊，往我的車子跑去。
