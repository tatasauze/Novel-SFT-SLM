# 父仇者 | 092

我，有時候她們會發現布莉姬半夜起床，坐在椅子上。有時候則發現她站在走廊上，手裡抓著女兒的照片。我聽了都希望這是好轉的徵兆。
「布莉姬，」我握住她的手，牽她回到窗邊。我跟她一起坐下來。我需要坐一下，因爲看到她站在那裡，我一時無法承受，興奮到雙腿似乎都要發軟。我跟她在那裡坐了十五分鐘，下樓前我拉上了窗簾，離開時我告訴漢彌頓護士我看到了什麼。她緩緩點頭，臉上的微笑有點哀傷，而我的微笑卻出自興奮。「我第一次看到她站在房間外面的時候，差點心臟病發，」她說。「不過，我從來沒看過她站在窗前。」
「或許她想看看發生了什麼事。」我說。
哀傷的微笑仍在，而我覺得我的笑容快要消失了。「可能吧，」她說。「腦部受傷後，什麼都很難說。」
可是，她確實知道，我也知道，走出療養院的時候，我腦袋裡出現了無數個可能的結果，布莉姬可能會轉過來，對著我微笑，醫生可能會搔搔頭，說一定是奇蹟出現，腦部受傷的「什麼都很難說」有了定論。
到了車旁，我回頭看看她的窗戶，有點希望能看到我的妻子，但我知道應該看不到，所以當我一看到窗簾被拉起來，她的面孔出現在窗前的時候，我差點跳了起來。她蒼白的五官和白色的睡衣映照著巡邏車的紅光和藍光，她仍舊凝視著警車。我拉住了門把，但沒打開車門，只看著她，希望她能動一動。漢彌頓護士出現在旁邊，用手臂環住布莉姬的肩膀，看著樓下的動靜，不過她也沒看見我。然後她帶著我妻子走開了。
去找約翰·摩根的路上，我的手抖個不停，不知道爲什麼。不知道是希望帶來的興奮，還是看到布莉姬跟鬼魂一樣凝望窗外時的詭異感覺，或許我該喝杯咖啡，或許這件案子太棘手。抵達
