# 185 | THE LAUGHTERHOUSE
Paul Cleave

他的孩子已經失蹤了。記者說，現場有掙扎的痕跡跟血跡。同一條街上的車子引起了警方的興趣，然後車子又上了畫面，接著被裝上了卡車。
他已經想到他們今天會發現史丹頓失蹤。他也想過警方可能會找到他的車子——只是不覺得有可能會找到。起碼沒這麼快。這樣，計畫又要變了。
女人送他到門口，還想推銷服務，她說，再來一次的話，她可以給他折扣。他一直背對著她，迅速走到醫生的車子旁邊，她跟到人行道的邊緣就放棄了。他突然想到，如果警方還沒發布醫生的車子長什麼樣子，應該也快了，各大媒體都會報導這台車的外型跟車號。靈媒看得到嗎？他轉頭一看，她已經朝著房子走回去了。
他昨天晚上已經把他那台車擦了一次。如果留下了痕跡，警方一定能找到。房子也一樣——他把他碰過的地方都擦過了。DNA的檢驗要花好幾個星期，他倒不擔心，但指紋一下子就有結果。如果他們找到了指紋，幾小時內就能發現他是誰。
他們找不到的，他很小心。
幹他媽的，昨天晚上他爲什麼不能更專心一點呢？如果不分神的話，全部的事情都能做完。指紋就讓警察找到吧，因爲一切都已經結束了。
他不認爲警方能採到指紋，如果眞的找到了，也找出他的姓名，他們一定會先去找觀護人，問出他的地址。他們會發現他不見了，他們會打電話去工廠，然後才會去屠宰場。既然醫生跟小孩失蹤了，他們可能會先去屠宰場看看。都是因爲車上那顆王八蛋電池。那些笨蛋靈媒，怎麼都看不到他的未來呢？
車子的電池。啊，可惡！昨天晚上發動車子的時候，他摸遍了車頭。警察會掃那邊的指紋嗎？不會吧，他不覺得他們會查得這麼徹底。他們當然只會看方向盤跟車門，還有車子裡面。可
