# 099 | THE LAUGHTERHOUSE
Paul Cleave

「我不要睡在地上。」
「沒有別的地方可以睡了。」
「有。我們家。帶我們回去，」她皺皺眉頭。「你的臉怎麼了，為什麼那麼噁心？」
「我告訴妳啊，梅蘭，我可以叫妳梅蘭嗎？」他問完就拿出刀子。「我知道妳很勇敢，我想妳也明白，妳跟妳家人目前的情況不太妙。我知道妳想表現得很堅強，我也很佩服妳。不過，妳要是不住嘴，我就用刀子伺候凱蒂。明白嗎？」
梅蘭妮的眉頭鬆開了，嘴角下垂。
「你不會的。」她的語氣沒那麼有把握了。
迦勒點點頭。「我當然會，」他覺得她很討厭，「而且都是妳的錯。地板，」他說，「去睡吧。」
她躺下了，他用塑膠繩綁住她，再用膠帶貼住她的嘴。他回到車上放了凱蒂。他對她說了同樣的話，她也問了同樣的問題，他們也達成同樣的共識，只是她哭得臉花了。她去了同一棵樹後，花了差不多長的時間，回來的時候臉上沾了一片片泥土。他把泰迪熊遞給她，撕下新的膠帶貼在她嘴上。她眼睛瞪得大大的，兩姊妹都滿臉懼色，但人性已經泯滅，只有對潔西卡的回憶，他的女兒，滿身是血，渾身是傷，躺在這兩個女孩現在躺著的地方。
「別想逃走，」他告訴她們。「不然結果會更糟糕。」
她們不能回答，只能默默流淚。他留下了一盞用電池的露營燈，燈光調得很弱，弱到房間四周仍籠罩在黑暗中。
他到車上抱起奧克塔維婭。他轉過臉，伸長了手把她舉得遠遠的，帶她到裡面去。她醒來了，滿面笑容。
