# 105 | THE LAUGHTERHOUSE
Paul Cleave

我開車進了城，不時瞥瞥副駕駛座上的手機，等著鈴聲響起，等施羅德告訴我計畫改變了，因爲五號和六號受害者剛剛出現。進了城，電話依然沒來，我到了希爾佛德街的小青蛙餐館，過兩個街口就是警局。
小青蛙餐館才開五年，卻感覺像家老店了。才開沒幾天，就變成局裡每個警察流連忘返的地方，大多數人一個禮拜至少來混五個小時。早上七點到九點間向來一位難求。小青蛙的風格就是老派的路邊餐館，長長的塑膠貼皮櫃檯前有高腳凳，窗旁一排紅色塑膠皮的雅座，牆上掛了老紐約市的海報。牆角的點唱機可以播放CD 和MP3，清晨的太陽斜斜照進來，在塑膠和玻璃罩上反射出完整的光譜。進門的時候，門一開，鈴鐺就會響一聲。我想，早上六點，應該只有施羅德一個人吧，但他並不孤單——座位滿了四分之一，都是像施羅德一樣疲倦的警察，看起來跟我一樣頹廢。肯特警探坐在雅座裡，桌上有杯咖啡，她眼睛看著窗外，口氣熱烈地對著手機說話。我看她看了幾秒，她轉過頭來發現了，對我微微一笑。我也對她一笑，與她四目交接了兩秒，然後去找坐在櫃檯前的施羅德。
