# 189 | THE LAUGHTERHOUSE
Paul Cleave

那個人根本治不好。出院後不到一個星期，他就用折磨塔比莎的方法對付我女兒，只是這次警察不知道要從哪裡查起，因爲詹姆士把她帶到這裡來，」他雙臂一展，表示就是這裡，這個房間，這整棟建築。「他把潔西卡關在這裡，她叫潔西卡，他把她關在這裡，折磨她，警察知道犯人是誰，但不知道要怎麼查，等他們查到了，也來不及了。他折磨潔西卡後，拿了一把像這樣的刀子，」他轉動刀子，讓大家都能看得很清楚，「然後他刺了她十九刀，」他告訴他們，「她的命，她所有的血，她的未來，就這麼流到妳們坐著的地板上。」
梅蘭妮睡著了。凱蒂的下巴也碰到了胸口。要說這個故事好難，迦勒覺得好不舒服。十五年來，女兒死去的情景不斷在他腦海中重複上演。他想過那之前宛若地獄的六個小時，綁架，恐懼。看到什麼，他都會想到女兒，眼前的景物或聽到的消息，不要幾個步驟，就會讓他聯想到潔西卡。就像六度分隔的理論。吃晚餐的時候，看到刀子，就想到女兒。在電視上或街上看到小孩。看到報紙上廣告的兒童衣物。吃牛排的時候則想到屠宰場。冰冷的天氣、警察、電視節目、高速行進的車子、虐待成性的老婦人——都會讓那場夢魘立刻浮現，沒有辦法關閉。女兒赤裸裸死在地上，雖然他從未親眼看見，卻甩不掉這幅景象。她最後看到的東西——也一直留在他的腦海裡。
「妳們的爸爸，」他的聲音更低了，「他可以阻止這一切。就是他告訴大家詹姆士可以治得好。就是他害我的女兒被殺了。死掉的不只我女兒。我的妻子因爲太傷心，也死了，我們的兒子也死了，他還很小，還在我妻子的肚子裡。妳們的爸爸奪走我的家庭，所以，」他看著醫生，「他對我怎麼樣，我也要對他怎麼樣。」
杯子從凱蒂的手中落下，在地上砸得粉碎。史丹頓嚇了一跳，奧克塔維婭醒來了。梅蘭妮和凱蒂沉睡不醒。奧克塔維婭看看父親，看看姊姊，笑了一笑又皺皺眉頭，然後哭了起來。
