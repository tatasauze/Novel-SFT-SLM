# 父仇者 | 142

現在他的腦海裡，重播一千次。一直不停地重播，他無法擺脫，那幅景象綁住了他。「他用刀刺死她，強姦她，那時候正是嚴冬。這裡只有他媽的零下一度，他倒不減興致。在她胸口和肚子上戳了一刀又一刀。在那之前他把她脫個精光，把她的小身體壓在跟冰塊一樣的水泥地上，那時候你正在溫暖的辦公室裡喝咖啡，給別人一堆狗屁建議，你根本他媽的不知道那些人什麼時候會發作。」
「你害死了她，你個王八蛋！」他怒吼，然後孩子們的哭聲響起來了，還發出了短短一聲尖叫，他的情緒排山倒海而來，如果他不想辦法克制，他就會當場把醫生開膛破肚，破壞整個計畫，而醫生呢，每個字都讓他更加畏懼，彷彿每個字都像打在他身上的拳頭。「你，就是你，還有你他媽的對世界的看法，你跟你的自大，你的虛榮，你跟你那種自以爲是的態度，因爲你就是要當老大，對不對？你就是要當那個他媽的什麼都懂的王八蛋！你只想到你的事業，你只想要出名。」
「我……」
凱蒂小喵喵和小貓咪梅蘭放聲大哭，抓緊了兩人中間的泰迪熊。她們半躺在地上，所以也能抓緊奧克塔維婭。他看看三個孩子，看得出來她們很害怕，可是她們不懂什麼叫作恐懼——除非他脫掉她們的衣服，把她們壓在地上，不然她們永遠不會懂。
在失控邊緣，他控制住自己。他搖搖頭，放低聲音。「詹姆士·惠特比，他控制不了自己。他的人格受損，他是壞人，但他就是那樣。你說你只是爲了做好自己的工作，但其他人也一樣。你做得太多了——是你說惠特比有救。他的律師用你的話來跟法官爭辯。十七年前，是你站上證人席，說服那十二個人，說詹姆士·惠特比能頂天立地，他——」
「我從來沒說過那種話！」
