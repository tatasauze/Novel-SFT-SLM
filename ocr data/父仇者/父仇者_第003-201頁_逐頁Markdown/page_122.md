# 父仇者 | 122

爭論。每一個細節都要很確切。如果答案在這兩名律師處理過的客戶檔案裡，一定很難取得。或許根本拿不到，因爲律師有特權爲客戶保守祕密。警方一整天都要問話，挖掘這些人的過去，找出他們的關聯。警探要翻查亞伯特·麥克法蘭的學生資料，和犯罪紀錄交叉比對。簡報室裡的每個人都急著接收任務。施羅德沒有分派工作給我。結束後，大家都站起來，往門口走去，但施羅德往回走的時候，大家又停下來了。
「還有一件事，」他說。「聽說今天晚上城裡會有飆車族聚集，」眾人哀嘆了一聲。「表示街上會塞滿車子。巡警的回應可能變慢，從甲地到乙地要更長的時間。估計會有兩千多個飆車族，」他說。「兩千多台車，故意找麻煩，搞那種青少年才懂的玩意。看在上帝的份上，別開槍打死他們，」沒有人知道他是不是在說笑。「別忘了我的話，」他說，「好好考慮一下。」
大家又往外走了。有人拍拍我，有人對我點點頭。我站起來，靠近死亡之牆，看著上面的照片。
史蒂文斯瞪了我幾秒鐘，然後走過來。我覺得他要開口警告我，「別搞砸」，接下來則是「你不應該在這裡」。
「泰奧，還好嗎？」他伸出了手。我遲疑著，也伸出了手，很擔心他會把手縮回去，也撤銷答應給我的東西。我跟他握了握手。「聽著，我很感激你昨天幫的忙。」
「謝謝。」我告訴他。
