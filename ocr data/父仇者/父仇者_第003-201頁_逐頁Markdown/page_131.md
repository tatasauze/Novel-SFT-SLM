# 131 | THE LAUGHTERHOUSE
Paul Cleave

「妳不太會講話，對不對？」
「餓餓餓餓餓。」
「妳會其他的字嗎？」
「貓。」她說。
「貓，」他跟著學舌。「還挺有用的。」
醫生瞪著他看。他使勁拉住塑膠繩，發現迦勒看著他的時候，就停止了掙扎。迦勒打開放補給品的袋子，找出另一罐嬰兒食品。另外兩個女孩都醒了。他放開凱蒂，把食物遞給她。
「餵她吃。」他對著嬰兒點點頭。
凱蒂沒照做，反而衝向父親，用雙臂環著他。她哭了起來，史丹頓也哭了。史丹頓雖然被蒙住了嘴巴，仍然喃喃說了幾句。聽不出他說什麼，但他的語調傳達出清楚的訊息。他告訴她他們不會有事。他告訴她不要擔心。迦勒向他們邁了一步，準備抓住女孩的衣領，把她拖開，又決定讓他們獨處一下子。畢竟，這些人未來也過不了什麼好日子了，就讓他們享受這一刻吧——過了三十秒，感覺他們已經分不開了，他又改變了主意。
「來吧，」凱蒂不肯放手。「來吧，」他又說了一次，「不然你們全部都會餓肚子。」
凱蒂放開了手。她吸了吸鼻子，再用外套袖子擦了臉。「好。」她伸手接過了食物。
她把奧克塔維婭從座椅上抱起來，放在自己的雙腿中間，像環抱父親一樣抱住她，然後靠著座椅，打開了罐子，一匙接一匙，奧克塔維婭狼吞虎嚥。她在吃東西的時候，迦勒撕開了一包早餐穀片。他吃了一把，看看盒裝牛奶，不知道是否該再喝點牛奶下去。不過，他接下來改吃麵包了。凱蒂餵完了食物，給奧克塔維婭裝了水的塑膠杯。她喝水時還盯著自己的姊姊看，臉上到處都是嬰兒食品，或許她的尿布又滿了，他根本不想去面對。
