# 父仇者 | 134

「這次妳錯了。我以前有個女兒。」
「她人呢？你也把她綁起來，帶到這裡來嗎？」
「沒有，是另一人幹的。他殺了她。」
「喔，」她張開嘴巴，彷彿還有話要說，他耐心等候，知道她不知道該說什麼了，情況也確實如此。「喔。」她又喔了一聲，然後看著地面。
「廁所在那邊，」他指指那些樹。「別想逃跑。我發誓，你們都不會有事，」他說，「只要你們聽我的話就對了。妳只需要信任我，但是，如果妳敢逃跑，」他猛然吸了一口氣，皺起臉龐，「嗯，要告訴妳會發生什麼事嗎？」
她搖搖頭。
「很好，快點去。」他說。
他站在屠宰場外面，喝著柳橙汁，她跑到樹後，幾分鐘以後就回來了。樹木大多只剩下樹幹跟樹枝，少數幾棵還抓著幾片葉子，穿過樹枝的陽光看起來好冷。昨晚下了雨後，地面變得軟軟的，建築物和車子間有一排來回走動的泥足印，史丹頓倒下的地方則有一組手印。車身上黏了十多片濕濕的樹葉，擋風玻璃和窗戶則佈滿了水氣。
「你知道警察在找我們，」梅蘭妮說。「警察能找到人，他們懂得怎麼找人。」
「妳說的是電視上的警察，」他告訴她，「但我們不是在演電視劇。」
「不，不光在電視上，」她說。「我們學校裡有個女生逃家了。警察一天就找到她。還有另一個女生——」
「梅蘭妮，」他說，「我不想再聽妳講話了，好嗎？我也不想傷害妳，眞的，但是妳讓我覺
得很想拿刀子出來。」
