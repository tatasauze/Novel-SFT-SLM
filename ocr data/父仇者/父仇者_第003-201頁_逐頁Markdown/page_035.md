# 035 | THE LAUGHTERHOUSE
Paul Cleave

我回到走廊上。臥房裡有更多照片，他們會非常震驚，他們會聽說一個認識的人就這麼離開了。我看了一張又一張照片，隨便亂看，腦袋裡天馬行空，或許其中一個人就是兇手。
我拉開了抽屜隨意翻找，最上面的抽屜只放了一包包沒拆封的內衣和折疊整齊的手帕，下面全是戰役勳章，可能是死者的，可能是他家人的。衣櫃裡有一套灰西裝，很多老年人的襯衫、老年人的鞋子和老年人的領帶。我翻了一些收據。普爾最近買了一些爵士CD、新拖鞋、兩本平裝書。醫院寫信來追蹤他的檢查結果——————赫伯特·普爾的健康狀況不佳。他的腎和肝都快停工了，照信上看來，他被謀殺也只不過比自然死亡早了兩個月。有人就是等不及。那表示重點不是看到赫伯特·普爾死掉，重點在於一定要親眼看到他死。
我漫步走回客廳。普爾的表情依然很空洞，彷彿他不敢相信自己把大家搞得這麼大驚小怪。你不夠關心。關心什麼？還是關心誰？
施羅德在講手機，空著的手在臉上亂揉。來了更多巡邏車，還有幾台休旅車。計程車都消失了，搭計程車來的人也走了百分之九十。鑑識小組的技術人員正朝著門廊走來。他們穿著白色的尼龍衣，就不會像我們一樣把現場弄得亂七八糟。另一台休旅車來了，法醫崔西·華特下了車。她站在休旅車旁，把黑髮緊緊綁成馬尾。我站在廚房裡聽施羅德講手機，讓新來的人接手犯罪現場。沒有人跟我講話，沒有人注意到我。十分鐘前還沒有的權威感出現了。鑑識小組拿著裝滿工具的鋁質手提箱進來。他們搭起了更多光源，明亮的鹵素燈照遍了每一個角落。一下子這間客廳就變得能從外太空看見。崔西很小心地走近屍體，彷彿很怕死人會跳起來，逃離她冰冷的雙手。
