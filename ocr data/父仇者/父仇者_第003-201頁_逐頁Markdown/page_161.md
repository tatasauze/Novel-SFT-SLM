# 161 | THE LAUGHTERHOUSE
Paul Cleave

出打鼓的姿態。
我進了會議室，找到施羅德，他正盯著白板看。他旁邊的桌上堆了一疊又一疊的資料夾，應該有幾百份。
「今年出獄的人，」他把手放在資料夾上。「這一疊，」他敲敲最高的那疊，起碼有第二高的兩倍，「都是有暴力犯罪紀錄的人。」
「你開始看了嗎？」
「開始了。大概看了百分之一吧。」他說。
當警察呢，少有機會在街上狂奔救人性命，或舉槍對著嫌疑犯。警察工作其實很平凡無趣。翻閱檔案。記錄閱讀目擊證人的證詞。交叉比對，找出關聯。
「資料眞多。」我說。
「你不是想回來當警察嗎？當警察就是這樣。這就是你一心一意想要再來一次的生活。」
兩名警探走進會議室，手中都拿著咖啡，雖然剛剛才補充過，我又想再來一杯。我們四個坐在那裡翻檔案。翻過的堆得愈來愈高。大家鮮少開口，認真工作，想把資料翻完。很多檔案裡的資料都差不多。暴力的人，暴力的故事。毒品罪名，強姦罪名，持械搶劫，偶爾也有一些凶殺案。也難怪紐西蘭人會對死刑議題這麼有興趣。
「我們需要那些他媽的律師檔案。」我說。
「如果法律事務所可以按時跟我們收費，就會更願意幫忙。」施羅德說。
面前一堆堆的資料有兩種可能。犯案的人，絕對不會犯案的人，但問題是這些在資料夾裡的人碰到情勢所逼，都可能會殺人。沒有特別吸引我們注意的東西。過了一個小時，我們才翻了三分之一，我找到的東西跟剛開始的時候差不多。
