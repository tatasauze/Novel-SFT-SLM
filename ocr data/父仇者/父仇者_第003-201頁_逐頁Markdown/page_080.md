# 父仇者 | 080

門一下子拉開了。
他從未見過史丹頓醫生，不過他看過十七年前審判時的照片，史丹頓醫生站上了他的表演台，說並非所有人都能對自己的行為負責。他錯了。他胖了，頭髮也全白了，髮線後退了許多，不知道為什麼，迦勒看了覺得很高興。
史丹頓打量了他幾下，看到了血，似乎嚇到了。「她人呢？」他問。
「你不認得我了吧，對不對？」迦勒問。
史丹頓一隻腳已經踏出了門，又停下了腳步。他看得出醫生覺得不對勁，精神科醫生的雷達響了，危險就在眼前，不過現在才響已經太遲了。
「她人在哪裡？」
「她死了。」
「認得你？不，我不認得，」他變得有點遲疑。「你……你有女兒嗎？」下一個問題證明他知道出了差錯。
「有。」
史丹頓閉口不語，然後往後退了一小步。他伸出手抓住門把。「你剛剛說你叫什麼名字？」
「我說我叫詹姆士，」他說，「不過那不是我的名字。」
「聽著，詹姆士，」史丹頓沒理會他的解釋，又退了一步，「我不知道你在玩什麼遊戲……」
他沒說完，接下來的話音都變形了，因爲迦勒一拳打在他的鼻子上。然後他倒進了家裡，用雙手捧著臉。
