# 父仇者 | 034

特的小說，在相片裡的人會大喊出聲，告訴我們今晚這個房間裡發生了什麼事。咖啡桌上有喝了一半的啤酒和餐盤，除了血之外，整間房看起來非常整潔。赫伯特·普爾很愛乾淨。
「他有兩個小孩，」施羅德說，「經理告訴我了。他妻子十年前因為腦部腫瘤去世。我們會找他的孩子談話。不曉得，或許有個小孩很討厭這個老爸。」
我們沉默了幾秒，慢慢適應赫伯特·普爾和他家人的悲劇。
「少了什麼嗎？」我問。
「天啊，泰特，我自己也還沒全搞清楚。」
赫伯特·普爾的頭往後仰，落在沙發的扶手上，一隻手臂壓在背後，一隻放在大腿上，身體幾乎是側躺著。他的臉朝著牆，上面有張照片，應該是他跟他太太四十年前的樣子，凝視著我們的世界，不過照片裡的五官跟死人不太一樣。當赫伯特·普爾的生命逐漸消逝，或許看著這張照片能帶來一些安慰。
「有什麼想法？」施羅德問。
「血腳印從門口過來，然後又回去，」我看著地毯上的血漬。「兇手在房子裡亂晃，找什麼東西。」
「戴上吧，」他遞給我一雙乳膠手套。
我踩過了客廳，很小心地避開血跡，進了走廊。足跡通往浴室。淋浴間濕濕的，長褲和襯衫揉成一團丟在地上，旁邊還有濕毛巾。兇手進來洗了個澡，把血洗掉，然後換了衣服，但沒換鞋子。那或許表示他要馬上去另一個地方，而不是回家。鑑識小組會從衣服上取下毛髮。他們會找到很多DNA—————如果兇手有前科，就能找到。問題在於DNA要花好幾個星期才有結果。如果兇手沒有前科，又是另一個問題。
