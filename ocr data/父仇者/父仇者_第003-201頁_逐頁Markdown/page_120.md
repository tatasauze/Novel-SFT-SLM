# 父仇者 | 120

論，如果有人上班前在停車場把他揍個半死，我就會過得好一點。我還有一個理論，如果他下班後才被揍，我也會過得好一點點。
「刀傷。」我說，插進口袋裡的手搓揉著強納斯的兩半名片。表演魔術的時候到了。
如果強納斯想得到，我也可以。
「刀傷怎麼了？」
「一號二號受害者——他們被捅的次數如果一樣呢？」
史蒂文斯看看施羅德，然後又看著我。「你想說什麼？」
「我們要問法醫，二號跟四號受害者到底被刺了多少次。」
「因爲？」
因為靈媒知道前兩名的刀傷一樣多，還猜到了最後一個也是。
「因爲至少十多次也有可能是十九次，那麼三名受害者的傷口數目就一模一樣。」
「但有一個沒有。」他說。
「那就是你剛才說的，三號受害者的模式不一樣。同一個兇手，不同的殺人理由。他不屬於這個模式。」
「繼續說。」
「嗯，」大家仍盯著我，我的腦袋瘋狂亂轉，「嗯，如果其中三個受害者都身中十九刀，一定有什麼含意。」
沒有人說話。我看得出來大家都很認眞在聽。
「什麼含意？」史蒂文斯問。「比方說某年？某個人？你是這個意思嗎？」他開始跟我一搭一唱了。
