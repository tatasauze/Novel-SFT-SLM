# 153 | THE LAUGHTERHOUSE
Paul Cleave

比。總要過了幾分鐘，才能揮去陰冷的感受。工人喝完咖啡了，工地和道路工程的塵土在停車場把我們圍住，工人扯著嗓門彼此喊叫，想壓過設備敲打的巨響和引擎的噪音。醫生和護士離開去玩醫院家家酒了。天氣晴朗，我摀住嘴巴打了個哈欠，對施羅德說了幾句話，又打了個哈欠，這次換了隻手。我做人很公平。施羅德也開始打哈欠了，他伸手到口袋裡，拿出小小的白色紙盒，上面印了橘色的起床兩個字。
「咖啡因錠，」他丟了一顆到嘴裡。「要來一顆嗎？」
我很想要，但我不想要上癮。我現在只對咖啡上癮……那個我也想戒掉。我搖搖頭。我們走到車子旁邊。施羅德看看我車子剛被砸爛的車頭燈，似乎想說這樣看起來比較有個性，或其他的俏皮話，不過他什麼也說不出口。
「去年我碰上了一件事，」他說，「有可能把我帶來這裡，」他回頭看看醫院的門。「把我送進太平間。知道的人不多。我是說，得找醫生幫我檢查，不過沒什麼大礙。」
我很想問到底是什麼事，不過我還是耐心等他自己開口。
「你覺得又要下雨了嗎？」他看看空中的雲朵。
我聳聳肩。「可能吧。艾瑞兒·錢瑟勒覺得一定會下。」
「是啊，我也覺得會。」他的思緒依然飄忽不定。
「你要告訴我你在想什麼嗎？」
「不怎麼想說，」他說。「就在耶誕節前，我剛去監獄找過你，要你幫我調查杭特的案子。我去了一間房子，嫌犯從背後偷偷過來。我以爲他會開槍打我。我以爲我死前會看到胸口的血肉都噴在浴室的牆上。不管怎樣，他沒開槍，但他逼杭特把我推進裝滿水的浴缸裡，把我淹死。」
「老天啊！」
