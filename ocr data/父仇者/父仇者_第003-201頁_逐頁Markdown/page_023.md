# 023 | THE LAUGHTERHOUSE
Paul Cleave

「啊，好，太好了，年輕人，不過我還是想不起來你是誰，我現在也不喝啤酒了，醫生規定的。但是隨便啦，我也沒什麼事情好做，好啊，進來吧。」
亞伯特站開讓迦勒進來，迦勒順手帶上了門。亞伯特的衣服掛在身上，形狀跟洗好的衣服掛在晾衣繩上一樣，他瞇起眼睛，彷彿希望視力能穿透讓他視線模糊的白內障。他看起來不太健康。迦勒看過癌症患者，亞伯特看起來像是得了癌症。
「坐吧，」亞伯特說。「我泡杯咖啡給你好嗎？」
「好，謝謝，」迦勒把啤酒放在咖啡桌上，心中暗想，既然亞伯特不喝，他要記得把啤酒帶走。他跟著亞伯特進了廚房，也沒走幾步，因為廚房基本上就在客廳邊上。氧氣管很長，應該夠繞好幾圈把人吊起來。
「我才剛燒了開水，」亞伯特伸手到櫃子裡拿杯子。「你喜歡哪種咖啡？」
「濃一點，」迦勒說。「不要糖，也不要奶。」
「好，應該沒問題。」
房子很小。從廚房和客廳之間的空隙，他可以看到走廊的另一頭。配置並不複雜。臥房、廁所、浴室，就這樣。感覺住在這裡很寂寞，他想，人到了這個年紀就是這樣。人不會到老了還在街上跳舞。可惡，沒人看到他進來，走的時候一定也沒人看到。住在這裡的人只能看個十公尺遠，記得起五十年前的事而已。
「你說你叫什麼名字啊？」亞伯特問。
「迦勒·寇爾。」他說。
「我們認識？」亞伯特說。
