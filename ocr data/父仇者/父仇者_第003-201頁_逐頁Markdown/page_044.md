# 父仇者 | 044

牆壁薄到你能聽見鄰居小便的聲音。和之前的住所比起來，已經算是豪宅了，聽別人小便的聲音，總比看別人小便好。跟他待了十五年的監獄一比，這裡簡直是美夢成真。
臥室、廚房跟客廳沒隔開。唯一隔開的房間則是浴室，向外面突出去。有一扇窗戶，看到的景物跟其他幾棟公寓一樣，就是丟滿了廢棄汽車零件的後院。
他踏進淋浴間，洗掉老人的血。已經洗第二次了。剛才他在第一名老人家洗了一次，他必須先清理乾淨，再開車去找第二名老人。他不能渾身是血出現在亞伯特的門前，還拿著半打啤酒。他甚至拿了一件老人的襯衫穿上。從第二個老人住的地方離開後，他直接回家，又全身是血，不過天已經黑了，沒人注意到。他在身上塗滿了肥皂，頭髮裡也有血，他用洗髮精搓洗，泡沫都變成了紅色。
十五年前，殺人的感覺好棒。今晚，他一點感覺也沒有。開車過去的時候，很激動很緊張，然後————就沒有感覺了。多年來他一直夢想這一刻到來，想到那些血會帶回他失去的東西，結果他錯了。他站在第一個老人家門前，覺得心已死，刀鋒完成任務後，他依然無動於衷。到了第二個地方，還是一樣。這不是復仇，跟情緒無關，這是懲罰。
不過他揮了好多次刀。揮刀的時候他忘了自己是誰，十五年來的憤怒和痛苦浮現出來，控制住他，他只記得第一刀，其他都忘了。等他發現自己腳下的屍體，發現自己臉上滴著血，才開始回想，他來多久了？他的手臂上下起落了幾次？眼前的死人告訴他，很多次。他以爲之後人性也會浮現，錯過了派對，但依然會來，讓他深深懊悔。但人性始終不來，連門都沒敲。
這些人都該為他們的錯誤付出代價，就像他也付出了代價。今天晚上這兩個，好不容易才讓他們想起來他是誰。其他人應該記得比較清楚，他們都比較年輕。警方當然會發現其中的關聯。不過他很謹慎地排定了順序，等他們發現，黑夜已經結束，一切都太遲了。
