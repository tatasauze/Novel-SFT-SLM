# 033 | THE LAUGHTERHOUSE
Paul Cleave

「你應該叫他們回家，卡爾，你也該回家去。」
「我知道，但是接下來呢？明天再來，希望有完美的結局？泰特，總得有人在這裡。」
「留下來的人都有可能會被開除。」
「你不該留下來。」
「是啊，然後警隊就只好雇用你了，對不對？起碼要有人來接電話。」
「如果有人發現你喝醉了，你找到的東西在法庭上都不成立，」我說。
「我沒喝醉，不趕快處理的話，不到二十四小時，這件案子就會跟我最後喝的那杯啤酒一樣，沒氣了。」
「你也不該留下來。泰特，不過我這人很實際，現在我知道我可以讓你幫忙。」
「光這句話，就證明你醉了。」我說。
他蹲到沙發旁邊，好好看了看死人的臉。「赫伯特·普爾，普通的普，在這裡住了八年，」他聽起來確實還算清醒。在外面，遠遠地幾名警探上了廂型計程車，肯特警探也上去了。可能他們要負責去買咖啡和甜甜圈吧。「朋友很多，沒有敵人，就算這裡有人不喜歡他，似乎也看不出來。他們比較有可能偷剪他的玫瑰，或把助行器弄得高低不平。」
赫伯特頭上寫了你不夠關心。每個字都寫對了。「有可能是前妻嗎？」我問。
「他沒有前妻，他老婆早死了。」
「前女友呢？跟他處不來的兒子？說不定有上百種意思。」
