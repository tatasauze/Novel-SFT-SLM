# 011 | THE LAUGHTERHOUSE
Paul Cleave

「我沒事。」我告訴他。
「你該去看醫生。」
「我的申請怎麼樣了？」我問。
「泰特，絕對不容易，過去你的名字跟太多壞事連在一起。」
「每天都有人棄守，」我說。「不到一年，這裡就沒有警察了。我不懂為什麼我不能回去，接下藍德里的空缺。」
「真的嗎？你不明白為什麼不行？」
「只是舉個例子罷了，」我知道警官死了無法遞補。「但警隊裡的好警察很少，不論如何，卡爾，我以前幹得也不錯。」
他嘆口氣。「你是不錯，然後你搞砸了，變成壞警察。聽我說，我在幫你打關係了，好嗎？我能做的都做了。我確實覺得你回來跟我們站在同一邊，總比跟我們對抗好。此外，我也覺得治安會變得比較好一點，不過申請需要時間，就算過了，還有不少規定。有一條就是體能測試，天啊，泰特，我看著你就覺得沒希望了。你這個星期吃過東西了嗎？」
「卡爾，我需要工作。」
「工作到處都是。」
「沒有，才沒有。我需要這份工作。別的事我做不來。」
他對我點點頭，然後下了車回到雨中，他的表情很像以前我們看到的毒蟲。
「去看醫生吧，」他說完就關上了車門。
