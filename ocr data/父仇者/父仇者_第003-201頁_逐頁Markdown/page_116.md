# 父仇者 | 116

角放了盆栽，牆上也有兩幅風景畫，現在都不見了。現在有幅全城的大型空照圖，去年拍的，在相機快門彈開的時候，可能也拍到了數百件罪行，都小到看不見。
從窗戶俯瞰基督城，遠遠從東方冒出了金光，太陽快出來了。我看到艾文河沿著杜蘭街蜿蜒前行，河岸依舊碧綠，浸潤在街燈的光芒下。有幾個人在河邊慢跑，重重呼出的氣息在空氣中凝成了白霧。非常靜默的早晨，沒什麼活動跡象，連鳥叫聲也聽不見。
在簡報室的主牆上有張地圖，用大頭針標出犯罪現場的位置。牆上也有受害者的照片跟犯罪現場的照片。不到二十四小時，整面牆都快貼滿了。明天或許要叫更多包工來，把房間再擴大一倍，乾脆擴建到突出在整棟樓外面好了。簡報室裡的椅子排成棋盤狀，都朝著前面。我到後面坐下，施羅德選了前面的位子。大家陸陸續續進來。很多人在打呵欠。很多人拿著咖啡，不是局裡提供的。不少人認出我來，對我打量了兩眼。
七點過了，簡報還沒開始。我們都留在座位上，知道再過幾分鐘就會開始了。外面的天空愈來愈亮，城市的光輝愈發強烈。七點一刻，多明尼克·史蒂文斯警司走了進來。他臉上的倦色遠不如其他人。大家安靜了下來，我們看著他走到前面就定位。六十多歲的史蒂文斯看起來比實際年齡老，而且聽施羅德說，最近他戒菸了以後，更容易發脾氣。他的頭剃得光溜溜，年代久遠的痘疤損壞了他的皮膚。他的聲音凝重，一身制服熨得筆挺。
「四名受害者，」這就是他道的早安，「不用說，你們都知道，每個人都要全力投入。要有人再敢到了犯罪現場還一身酒氣，我發誓我會立刻收回你的警徽，」他口氣平穩冷靜，聽起來他的威脅絕對不是開玩笑。「如果不是急需人手的時候，」他說，「我現在就要開除幾個人，讓你們知道我有多火大。在這裡的每個人都一樣。」他牢牢盯了施羅德幾秒，然後才轉眼看著其他人。
