# 193 | THE LAUGHTERHOUSE
Paul Cleave

「住在這地方簡直像找全城最醜的妓女來上，」負責指揮的組長說。「只花幾分鐘就完事，但要洗掉進到裡面的感覺卻起碼要花一個小時。」
「他說得沒錯，」他走後，肯特說。「他形容得算好了，但確實是那種感覺。」
廚房裡有抽屜，工作台上一堆空的披薩盒，除此之外什麼都沒有。臥室裡沒有抽屜，貯藏空間很少。
「很難相信這種地方也有人住。」肯特說。
「我看過更糟糕的住處。」
「我也看過，」她說，「但仍然很難講得通。」
我檢查天花板上的人孔，肯特則檢查地板上的人孔。我檢查完了，發現她從臥房的地板下爬出來，手掌和膝蓋都積了厚厚一層灰。她在牛仔褲上抹手。
「什麼都沒有？」我問。
「脖子好痠，你呢？」
「肩膀好麼。」我說。
「或許我們應該雇用隨行按摩師，」她說。「對了，這件案子結束後，不知道你想不想……」她才開口，我的手機就響了。
我從口袋裡抓出手機，示意她先把話說完，但她卻點點頭，說，「先接電話吧。」
施羅德打來的，我早料到了，因爲會打來的也只有施羅德。我報告最新的情況，肯特進了廚房。我看著她檢查了冰箱裡面和後面。什麼也沒有。寇爾走了，不打算回來，也沒有理由把什麼藏起來。我都說給施羅德聽，要他派兩名警官過來站崗，雖然寇爾不太可能回來，總要預防萬一。從鄰居對我們的反應看來，我告訴施羅德派來的人必須配槍。
