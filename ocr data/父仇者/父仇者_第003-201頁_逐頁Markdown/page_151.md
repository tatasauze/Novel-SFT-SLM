「我覺得情況會好轉，」我說，不過我覺得我連自己都無法說服。
「是啊，唉……幹。」他猛戳電梯按鈕，我們搭著電梯進入醫院的深處。在生命中，或許只有一種感覺不會變——進了太平間，永遠只有一種感覺。衆人來來去去——醫院員工、法醫、清潔工、受害人——年復一年，設備不斷更新，或許都是從業務代表送來醫院的型錄中精心挑選出來，變化卻非常細微。但裡面的氣氛無法升級——陰陰冷冷，令人沮喪，每次搭電梯下來，都像下降到最不幸的谷底。
太平間滿是閃亮的平面，冰冰冷冷，反射出刺眼的白光，消過毒的空間更給人清潔無菌的感覺。擔架上躺了屍體——其中四具我認得，另外兩具我不認得，他們臉上的表情都一模一樣。
通常這裡會有兩名法醫，不過謝爾登不在。他女兒在斐濟舉行海灘婚禮，所以他跟家人去曬太陽喝雞尾酒了，留下我們，而且不論死活，大家都寧可跟謝爾登在一起，而不是崔西，儘管崔西長得比較漂亮，也比較活潑。才過了幾個小時，她就變老了，因爲要處理的案件太多了。
「拜託你們先放過我，」她連頭都沒抬起來，埋頭研究手裡的檔案。「我知道你們很急，但是除非你們想跟他們一樣，」她對著受害者點點頭，「先給我一點時間。」
「初步的印象就好。」施羅德盡力讓自己的口氣聽起來沒那麼煩人。
「當然，第一印象就是我的薪水太低了。第二印象則是謝爾登選對了度假的時間。你們想要的話，我也可以立刻變成壞脾氣法醫，頂撞攻擊一名警官和……」她看看我，「你他媽的現在是什麼角色？」
「妳演的發瘋法醫要攻擊兩名警察。」我說。
