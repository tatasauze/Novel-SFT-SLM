# 173 | THE LAUGHTERHOUSE
Paul Cleave

「應該在吧，等等……」他放下了電話，我聽見了腳步聲、講話聲、影印機的聲音。過了一分鐘，傑夫回來了，把電話拖過桌面，然後才拿起來。「呃，事實上，他剛離開了，有急事。」
「他一整天都在辦公室嗎？」
「對啊，你爲什麼要問呢？你是誰？」
我猜唐納德急著離開辦公室就是爲了回家。應該有鄰居打電話去他的辦公室，告訴他有人破門而入了。「泰奧多·泰特探長，」我告訴他。「我要你告訴我唐的手機號碼。」
「噢，可惡，發生了什麼事？他家人出事了嗎？」
「他們都很好，」我說，「不過我需要他的手機號碼。」
他告訴我號碼，我寫了下來，才想到可能就存在這支電話的記憶體裡。傑夫還在說話，一句話沒說完我就掛了，改撥手機號碼，響了第二聲就有個男人接聽。
「喂？」
「唐納德·史拉格斯？」
「你是警察嗎？」
「我是泰特探長——」
「你在我家嗎？」
「對。」
「你在那裡幹嘛？你闖進去了？他媽的誰准你闖進去？」
「先生，請你冷靜一點。」
「冷靜？你才他媽的給我冷靜。我馬上回去，也打電話給我的律師。老兄，你他媽的可有大麻煩了。」
