# 195 | THE LAUGHTERHOUSE
Paul Cleave

施羅德給了我一杯咖啡。我拿起醫生的檔案開始翻閱。裡面有很多醫學行話，都指出惠特比非常容易招惹麻煩，就他的情況而言，最好不要讓他在基督城自由活動。史丹頓非常了解他——檔案裡的筆記提到惠特比的童年，他成長的狀況，他和母親的關係。也有筆記提到惠特比攻擊塔比莎·詹金斯的過程。惠特比的思路非常混亂。他不知道該怎麼解釋他爲什麼要攻擊塔比莎。他只說，他受到她吸引，因爲她很漂亮。史丹頓在筆記中提到，十四歲時被母親用熨斗毒打後，詹姆士的人格可能有小部分鎖定在那個年紀，所以他才會受到十多歲或年紀更小的女孩吸引。當逼問他知不知道自己做錯了事的時候，惠特比說他不明白爲什麼他做錯了，不了解別人爲何要指責他。
「我還是不明白我們怎麼沒早點發現。」我對施羅德說。
「什麼？」
「監獄的紀錄。我是說，我們不是查了紀錄嗎？如果寇爾六個星期前出獄，我們早該發現了。」
「對啊，」他說完後聳聳肩。「我不知道該說什麼。」
「我們應該早就發現有關係了。我們就可以……」
「我懂，」他說。「我懂，好嗎？我們應該早就發現了，但我們沒發現。不過我們現在找到答案了，那才是重點，對不對？」
「對。」我看了看肯特警探，她正看著我，但面無表情。她輕輕聳聳肩，施羅德沒看到，然後她又低頭看著面前的檔案，跟我看的那份一模一樣。我低頭看看我的咖啡。杯緣的污漬應該怎麼洗都洗不掉了。
「咖啡的味道沒變嗎？跟我以前在這裡的時候一樣？」我用手指擦過一塊污漬。
