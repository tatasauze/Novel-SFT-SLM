# 017 | THE LAUGHTERHOUSE
Paul Cleave

會幾年後就退休了，還是現在就辭職。音響打開了，滾石合唱團的歌聲在酒吧裡響起，藍德里最喜歡的樂團——也是我的最愛。
「他一個人去出什麼勤啊？」我問。
他聳聳肩，接下來說出的話令我非常驚訝。「法醫說他得了癌症。」
「什麼？」
「他還沒來得及退休就要死了。我覺得他厭倦了這座城裡的情勢。」他拿起啤酒，一口氣喝了半杯。「他想要改變，結果害死了自己。」
我們走回酒吧。警探都在狂喝，喝到足以挺過冬眠。藍德里的哥哥看起來對費用不爽的程度遠超過對弟弟過世的哀傷。他看起來彷彿希望自己在早已稀釋的威士忌裡還要加更多水。施羅德又拿了一杯啤酒，我的果汁才喝了三分之一，他就把啤酒喝完了。聲音愈來愈響，四面八方都傳來破碎的故事片段，大家喝得愈多，愈少提起藍德里，愈來愈多人在談論基督城，談論天氣和犯罪率和飆車族，那些飆車族緊咬著這座城，不肯鬆口。到了晚上，他們堵住街道，用顏色鮮豔的車子賽車，車子的底盤都改低了，改裝得很酷炫很吵鬧。第一個小時過後，對話內容愈發陰鬱，說話聲音壓低了，你來我往討論要如何讓這座城變得更好，我們要去找誰才能達成目的。施羅德喝完了第三杯啤酒，我開始喝第二杯果汁。其他的警察過來跟我們聊天，很多人說「你們跟他是警校同期，對不對？」和「泰特，你應該回警隊來，」和「警隊最不需要的就是你回來。」我小口喝著果汁，一心只想離開這鬼地方，不知道我要是真的回去了，會惹惱多少人。
「梅莉莎·X的案子怎麼樣了？」我問施羅德。
他又拿了一杯啤酒，慢慢喝了幾秒才放回吧檯上。「好像在追捕鬼魂。」他說。
