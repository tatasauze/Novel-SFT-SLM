# 179 | THE LAUGHTERHOUSE
Paul Cleave

看著地上，再對著自己的手掌說話。「技術上，我告訴你這些事，並不違反我對他或者對上帝的承諾，」他說，「對，有個男人曾在晚上來過，他符合你剛才的描述。」他抬頭看著我，挪開了手掌。「五六個禮拜前吧，我幫他找到了他太太，」他說。「他說她十五年前過世了，他從沒看過她的墓。很奇怪，就是很……奇怪。」
「十五年前？」
「對。」
「不是十九年前？」
他聳聳肩。「有可能吧。我的記憶沒有從前好了，不過我認爲他說十五年。還有個孩子。他的女兒。他沒有提到她，但我看到了墳墓。」
「耶穌啊，」我說完又接著說，「抱歉——我沒有褻瀆的意思。」
雅各點點頭。「日期只差幾天。女兒先過世，然後是妻子。我記得順序，但不記得日期。可能差了一個禮拜吧。」
「你記得她們的名字嗎？」
他努力回憶，臉都皺成一團了。「我很想記起來，但是我不記得了，抱歉。」
「但你幫他找到了妻子的墳墓。你看到了兩座墓，你能帶我去嗎？」
「可以，我應該能找到。」
我跟著他從教堂後門出去，走進了墓園。除了死人外，整塊地也相當荒蕪。樹木比昨天更像地底的屍體，失去了生命的骨架。我們穿過橡樹間蜿蜒的小徑，來到第一排墳墓。我們更深入了墓園。我開始冒汗了。留戀夏末的昆蟲亂咬我的手臂，想在微小的身體裡儲存足夠的血液來度過未來的日子。雲層變得稀疏，等一下可能太陽就要出來了。
