# 027 | THE LAUGHTERHOUSE
Paul Cleave

4

「流行共識」外已經來了幾台廂型計程車。坐滿了警察後慢速開走。排水溝和馬路上的水反照著酒吧和街燈的光線。看不到月亮和星星，只有滿天烏雲。還好雨停了，不過已經降到地面上的雨水一有車子通過就從路面上濺起，感覺等一下又要下雨。大家似乎都沒辦法走一直線。我不知道發生了什麼事，除非那通電話是為了要制止附近的釀酒廠滿出來，要派警察去喝乾，不然這些人都不該插手。如果他們沒喝醉，就該明白這個道理。我懷疑他們根本醉到沒聽懂。問題是警力已經不足，也沒有其他選擇，不論發生了什麼事，都嚴重到這些不在當班的警官全都急忙上了來接他們的計程車。
「你會告訴我嗎？」我帶著施羅德回到停車場。
「天啊，我好想尿尿。」
「我在這裡等吧。」
「沒關係，我可以忍住。」
「要去哪裡？」
「我得再打一通電話，」他拿出了手機。我們搭電梯到頂層，一路上他一直靠著牆，每隔幾秒就把手機從耳朵旁拿開來檢查。「沒有信號，」他說。
我們上了我的車子。
「安全帶可以用嗎？」他拉拉安全帶。
「我不知道，我從來沒載過人。」
