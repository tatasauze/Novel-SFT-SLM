# 133 | THE LAUGHTERHOUSE
Paul Cleave

可是他做不到了。因爲醫生，因爲其他人，他的家人都死了。他還沒爲家人討回公道。
他尿完了，凱蒂也完事了。回到裡面以後，他翻了翻袋子，開了鮪魚罐頭。撲鼻的魚腥味讓他差點嘔出來，他把罐頭丟到另一個房間裡，側面落在地上，滾啊滾滾到不見了。如果老鼠忍受得了那股味道，就祝牠們吃得愉快吧。凱蒂又從座椅上抱起奧克塔維婭，走到梅蘭妮旁邊，她的手臂從後面環抱著奧克塔維婭的胸口。看起來就像大公主娃娃抱著小公主娃娃。她坐到姊姊旁邊，把小妹放在兩人中間。
「你餓了嗎？」他問醫生。
醫生從膠帶後咕噥了幾句，聽不懂是什麼，但從音調聽來，跟肚子餓不餓沒有關係。聽起來他說了好幾次幹你媽，混雜了經典的去死吧。
奧克塔維婭又眼睛骨碌碌看著他，吸吮著水杯，杯底掛了一絲口水，讓他覺得好噁心。凱蒂伸長了手，撕掉了梅蘭妮的膠帶。
「我要上廁所。」梅蘭妮說。
「OK，」他切斷了塑膠繩。「不要把她放下。」他對凱蒂說，又對著奧克塔維婭點點頭。「也別想幫妳爸爸鬆綁。妳沒有辦法解開他的繩索，妳敢試試看，我會大發雷霆。如果我生氣了，壞事就會跟著來，我也得處罰妳，還有梅蘭妮和奧克塔維婭。懂嗎？」
她點點頭，嘴角往下一撇。「懂。」她說。
他帶著梅蘭妮出去，她一直對他怒目而視。「你不懂怎麼照顧嬰兒，對不對？」
「我不會。」
「妳錯了。」
「我才不會錯。」
