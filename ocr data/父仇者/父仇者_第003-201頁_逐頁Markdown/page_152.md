# 父仇者 | 152

她望向施羅德，施羅德點點頭。「是眞的，」他伸出手，搭在她的手臂上。「崔西，聽我說，我知道我們要求太多了，但不這麼緊急，我也不會在這裡，拜託，先告訴我一些初步的觀察好嗎？」
她緩緩點了點頭，臉上短暫浮現了不怎麼明顯的微笑。「好，」她說，「到這邊來，」我們圍到維多利亞·布朗的遺體旁邊。「首先，你們說對了傷口的數目，」她看著施羅德。「正好十九刀，」她說。「有個傷口刺了三刀，每刀刺入身體的角度都不一樣。但布萊德·海沃德只有一刀。」她對著他點點頭，他聽到自己的名字也沒有反應。
「我確定凶刀只有一把，」她說，「二號受害者也有同樣數目的傷口。」
我的背脊感到一股寒意。三名受害者，各自中了十九刀。一定有什麼意義。
「一號受害者反正快死了——他得癌症好多年了，」她的口氣很有自信。「四號受害者還沒死，也不算活著。就像幾個小時前我說過了，三號受害者應該剛有過性行爲。他老婆最好去檢驗一下，」她補了一句。「看看自己有沒有梅毒。」
這段對話眞令人覺得不愉快。
她把刀身的印模遞過來，那把殺了這些人的刀。她挑了一個傷口，灌入濃稠的液體，液體凝固後，變成傷口的形狀。我們看了就知道刀子有多大。看起來像把廚房用的刀，主廚可能會拿來切洋蔥或其他的食材。希區考克則會交在狂人手中。知道了兇器的樣子，我們仍無從得知兇手是誰，而且這個世界上有無數把同樣的刀子，不過十九刀卻是很好的線索。但是十九刀是什麼意思，我們不知道——還不知道。
「有更多結果的時候，我會打電話給你，」她說。
