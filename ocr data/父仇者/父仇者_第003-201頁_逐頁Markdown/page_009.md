# 009 | THE LAUGHTERHOUSE
Paul Cleave

「但我不同意。你看，如果你是條子，你早就說了，會給我看證件。條子開來的車要拿去賣，賣的價錢應該會超過油箱裡的汽油，對我跟我的伙伴來說，」他把球棒拉高了一點，「我覺得你頂多只能穿過一扇門。會是哪一扇呢？」
我看向窗外的停車場。十多間並排的房間構成一個L形，南北向有六間，東西向有六間。四間房外面停了車。
「我沒有五十塊，」我告訴他。「你看到我的車了。」
「那我就不知道那女的在哪裡。」
「謝謝你寶貴的時間。」
我走到外面，清新的空氣讓我鬆了一口氣。快到午餐時間了，我的胃在翻騰，想讓我相信我不趕快吃東西就會死掉。我要有五十塊可以花，也會先拿去買吃的，不會交給一個乳頭長毛的男人。不過在走回車子的路上，我倒可以慢個五秒，我就用這五秒觸動了火災警鈴。
房間的窗簾拉開了，裡面的人把臉壓在窗戶上，東西向倒數過來第二間的窗戶上出現了露西·桑德斯的面孔。我從口袋裡拿出手機，打了個電話。房間裡的人聽到火災警報聲也沒跑出來，只有經理出來了，怒氣沖沖地看著我。他跟說服者手牽著手，正在打量要不要一棒揮在我的車子上，最後他覺得就算打爛我的車，球棒受到的損傷可能更嚴重。然後他又盤算了一下要不要用在我身上。我坐在車裡瞪著他，希望他回到裡面去，還好最後他還是進去了。
