# 003 | THE LAUGHTERHOUSE
Paul Cleave

序言

南半球的八月，宛若耶誕節。真正的冬之仙境。現場用黃色塑膠帶裝飾，好比金屬彩帶，已半個世紀空空如也。
這裡很冷，冷到呼吸的氣味在空氣中凝結成霜，冰凍著這棟建築物裡的一切。在現場鹵素燈的反射下，地面上的血跡與水漬顯得格外刺眼。
卡爾·施羅德警官和泰奧·泰特警探走進去，腳上踩著新鮮的融雪。他們不願意碰到任何東西，彷彿只要輕輕一碰，就會被吸進這個充滿死亡與暴力的黑暗深處。
現場是一座廢棄的屠宰場，荒廢了幾十年，混凝土的地基已經斑駁。幾天前，這裡發生了可怕的悲劇。一名年僅十歲的女孩遭到綁架，慘遭毒手。
女孩的屍體在建築物深處的房間裡被發現，現場慘不忍睹。牆壁和地板上到處都沾滿了噴濺的鮮血，還有兇手留下來的凌亂腳印。
在沾滿血跡的牆壁上，兇手用鮮血寫了歪斜的大字：「尸宰場」。似乎在嘲弄著這場慘劇，也嘲弄著到場的警察。
