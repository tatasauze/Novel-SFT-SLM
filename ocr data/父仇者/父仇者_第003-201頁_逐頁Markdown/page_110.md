# 父仇者 | 110

來到這裡後，過了半個小時，景物已經改變了。屠宰場沒那麼黑了，不同深淺灰色的迷濛晨光包圍了屠宰場，樹木看起來好冷，好像有壞事要發生了，彷彿樹上藏了千個夢魘中的怪物。然後他發覺，他也是怪物，他是史丹頓醫生做夢都沒想到的邪惡巫師。他伸手進去，抓住了醫生的鼻子，毫不猶豫地隨手一扯，噠的一聲，他的鼻子彈回原來的形狀。醫生渾身亂顫，鼻血洶湧流出。鼻血流過他的臉頰，再流過他的耳朵，不過他不會有事。說到被打斷的鼻子，迦勒可是經驗豐富，醫生的鼻子只是位移了，還沒斷。過了十秒，他已經不想看著他了。
「站起來。」迦勒說。
「你想怎樣？」他從行李廂裡抬起頭來，鼻血流個沒完，不過速度慢了不少。他哭了，臉上的淚痕也黏了灰塵。
「站起來。」迦勒重複了一次，秀出了他的刀子。
雙手被反綁在背後的史丹頓醫生想爬出來，最後卻只能滾出來，跌到地上，跌得他七葷八素。
「想逃也沒地方逃，你鬼叫也沒人聽到。」
「你是誰？」史丹頓吸了吸鼻子，吐出一大坨鼻涕和血。他站了起來，氣喘吁吁，搖晃了幾下。
「你還沒猜到嗎？」
「沒。」
「你記得詹姆士·惠特比嗎？」
「別傷害我的孩子。」
證明這個世界已經瘋了。
