# 父仇者 | 146

「我不知道。我沒有固定的時間表。」
「這很重要。」
「我不記得了。都有吧。都沒有吧。隨便啦。」她對我的問題失去了興趣。
「他看起來很內行嗎？他會緊張嗎？第一次召妓，還是經驗老到？」
她喝了口酒，含在嘴裡繞了幾秒才吞下去。「他不是第一次召妓，」她雙眼盯著冰塊。「應該也不是第二次或第三次。」
她吸了一口菸，把煙吐到冰冷的空氣中，煙霧在她面前繚繞不去，煙霧後的臉龐宛若面具。我覺得我可以過一個小時再來，而且面具還在那兒。我很想抓住她搖一搖。每隔幾秒，她會眨一下眼睛，眨過之後，眼睛似乎也要慢慢閉上了。
「妳在哪裡工作？」
「一般在曼徹斯特街和希爾佛德街的交叉口。」
「妳昨天晚上就在那裡嗎？」
「應該吧。」
「然後妳上了他的車。他載妳去哪裡？」
「差不多過了半條街。希爾佛德街再過去有條巷子。」
「正常情況下，妳都去那裡嗎？」
「你不知道在我這一行什麼叫作正常，」她說。「對啊，很多人會選那條巷子。他們根本就不想開太遠。」
「妳跟他在一起多久？」
「我不知道。這有什麼關係？」
