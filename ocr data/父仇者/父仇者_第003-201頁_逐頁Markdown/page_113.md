# 113 | THE LAUGHTERHOUSE
Paul Cleave

19

城裡有好事，也有壞事，今天早上就是很典型的例子。好事——雨完全停了，天空看起來相當清澈，太陽出來的時候，說不定往哪裡都能看到藍色的天空。現在大概四度，到了下午應該會上升到十五六度。昨日冰冷的風現在已經被吹到了南太平洋上，雖然還是很冷，卻沒有那麼透心寒。壞事——空氣感覺很潮濕。我又累了，剛喝咖啡的時候燙到了舌頭，舌頭麻掉了。天色愈來愈亮，我的車也看起來愈來愈爛，警局大門外面已經來了記者。他們晃來晃去，感覺很卑鄙很下流，有什麼資訊都不放過，裡面最不要臉的那個人則是基督城的靈媒，一頭抹了髮油的黑髮往後梳，牙齒白得發亮，名叫強納斯·瓊斯。他穿著細條紋西裝和絲質領帶，看起來像薪酬豐厚的律師。記者連珠炮般對我發問，強納斯跟著我進了大廳，我把手伸進口袋，深怕皮夾會不見。施羅德比我早到十分鐘，換了今天的第三件襯衫，想在簡報前把自己弄乾淨點。
好事——強納斯一開口就說笑。「我覺得你會幫我。」他對我說。
壞事——我正要大笑，才發覺他並不是在說笑。
瓊斯以前是二手車業務員，破產後又找到另一個壓榨別人的方法。他也混得不錯，常上實境靈媒節目，還把他跟死者的溝通寫成書。到目前爲止，他唯一成功解決的案子就是證實全國還活著的靈媒中衆人最討厭的是誰。我想，他跟我們這些人一樣，也常在家裡把鑰匙弄不見。這些年來，他對警局來說，就像眼中釘肉中刺。但是他的書賣得很好，觀衆也很多，這表示出版界和電視界跟社會大衆一樣沒道理。
我不理他，繼續往前走。
