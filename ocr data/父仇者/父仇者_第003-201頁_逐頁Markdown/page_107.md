# 107 | THE LAUGHTERHOUSE
Paul Cleave

之後就停不下來。我把第二片塞進嘴裡，配點蛋，配點蘑菇，不同的滋味讓我清醒過來。我伸手拿咖啡，還是燙到無法入口。
「我們應該在他的皮帶和車上找指紋。說不定能找到符合的。說不定她曾經順手牽羊或持有毒品，所以指紋已經建檔了。」我不想給所有的性工作者冠上刻板模式，但同時我知道她很有可能有前科。
「是啊，不錯的主意。」
「我問約翰·摩根他們把車子停在哪裡。他們在附近有個停車場，在那裡殺人更簡單，他也有時間寫下訊息。爲什麼不在那邊等就好了？跟他回到他家的車庫裡，然後從他家逃跑，眞他媽的不合理。」
「對啊，不合理，」施羅德說。「聽著，我還有一件事情要告訴你，」他把最後一片培根塞進嘴裡，往後一靠，把手伸進了口袋。「你的。」他拿出我的警徽和證件，三年前辭職時我就放棄了這兩樣東西。
「我可以回警隊了嗎？」我實在掩飾不住興奮之意。
「只是暫時的，」他開始吃雞蛋。「但是，如果你沒搞砸，就會變成正式的。不要違反規定，人家叫你做什麼就做什麼。」
「會配車嗎？」
「別得寸進尺了，」他說。「但是你可以拿回駕照，你一直在開車，現在終於合法了。」
我用拇指撫過金屬徽章。我記得最後一次看到它的樣子，我把它放在辦公桌上，人就走了。
