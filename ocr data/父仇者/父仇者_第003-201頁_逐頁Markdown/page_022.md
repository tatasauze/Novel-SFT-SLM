# 父仇者 | 022

他又敲了敲門。「亞伯特？」
沒人應門。他繞著房子走，從窗簾的隙縫往裡面偷看客廳的樣子。亞伯特背對著他，臉朝著電視，兩人都能看得到螢幕。原來現在有這麼多實境節目可以看。他不知道他的人生拍成實境節目好不好看，應該不怎麼樣。因爲，他的人生太真實了。亞伯特坐在花朵圖案的沙發上，旁邊有台看起來像除濕機的機器，不過有條透明管子連到亞伯特身上，給他氧氣。
迦勒敲了敲窗戶。
「有事嗎？」
亞伯特嚇了一跳，然後轉向聲音的來源。顯然他只看得到窗戶，看不見外面的東西，所以迦勒又敲了敲窗戶，然後移到門口，幾秒鐘後前門開了。
「亞伯特·麥克法蘭？」迦勒說。
「是，是我，」亞伯特回答。他的頭禿了，耳朵有點招風，因爲氧氣管繞到耳朵後面，再插入鼻孔，他的鼻子紅紅的，彷彿發炎了。他講話的時候會發出氣喘聲，並因此更氣喘吁吁。他用一根手指推推眼鏡，讓眼鏡更靠近眼球，近到都要碰在一起了。眼前所有的東西都放大了，他瞇起了眼睛對焦。
「我叫作迦勒·寇爾，」迦勒說，「你記得我嗎？」
「記得你？」亞伯特靠上去細看。「你是我的孫子嗎？」
迦勒搖搖頭。「不是，我可以進去嗎？」
「年輕人，你是不是來推銷的？」
他舉高了啤酒。「不，我只想擺擺龍門陣。」他覺得亞伯特應該會很喜歡老掉牙的說法。
