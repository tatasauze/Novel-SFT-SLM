# 177 | THE LAUGHTERHOUSE
Paul Cleave

27

過去一年來，我覺得我最常去的地方就是墓園。總有什麼召喚我回去，造訪次數如此頻繁，我應該能有個專屬的停車位。死在我手下的人有四個，第二個就意外死在墓園裡。我把他埋了，除了我們兩個人都不再相信的上帝，沒有其他人知道這件事。我殺的第三個人也在這裡，不過他的死倒不是意外。他們兩個都殺了人。在眞實生活中，其中一人給我的神父找了不少麻煩，另一人則害死了他。在此處死掉的人裡面，只有神父不是我殺的，但警方一度懷疑是我。教宗應該頒個獎章給我。
停車場裡一部車也沒有，毫無人跡。花園的顔色似乎比昨天褪了一點，樹上的葉子少了幾片，許多落下的葉子躺在教堂的石頭階梯上，門口積了不少葉片。有幾片葉子跟著我進了門。雅各神父正在佈道，他點點頭表示看到了我，但沒有停下來。我猜這就像單口相聲——表達的姿態最重要。我往前走，等我走到他面前，他才停止佈道。
「泰奧，」他從講台後走下來，對我伸出手，身上飄出微弱的菸味。「你需要我幫忙嗎？你來這裡，是否爲了卸下重擔？」
「重擔？」
「你上次告解是什麼時候？」他的眼神飄到了旁邊的告解室。
「我沒有什麼要告解的。」我說，當然是信口開河，而我絕對不會告解我說了謊。
「每個人都有要告解的事情。」
「神父，連你都有嗎？」
