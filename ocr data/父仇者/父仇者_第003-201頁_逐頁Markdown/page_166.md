# 父仇者 | 166

25

窗外的景色倏然消逝。施羅德的車前裝了警示燈，警笛一路響到醫生家去。駕駛人大多盡力讓路給我們，有些人不知所措，乾脆停了車，擋住我們的路。
「你怎麼想？」他問。
「心理醫生跟律師有什麼共通點？」我問他。
「除了收費太高以外，還有呢？」他一扭方向盤，閃開了從車道倒出來的車子。「兩者都有可能碰到非常病態的人。」
「正是。要是兇手是他們的客戶呢？覺得他的律師和心理醫生都有錯。」
「有什麼錯？」
「我不知道。因爲同樣的理由，他也責怪他的老師、會計師和離婚律師。因爲那個理由，他去坐牢了。他的生活一敗塗地，他覺得這些人是罪魁禍首。」
史丹頓住在很高階的住宅區，友善的鄰居伸長了脖子，想看清楚我們在幹什麼。巡邏車堵住了街道，媒體車造成交通堵塞。媒體直升機在空中盤旋，運氣好的話，說不定能看到記者和攝影師如雨點般降落。他的房子有兩層樓，前院的草皮蒼翠豐美，花園打理得很整齊。房子前方的灌木叢裡排了一列花園地精，有的對我眨眼，有的則專心工作，有個推著手推車，有個拿著盆栽，有個躺在地上，閉著眼睛，肚子上放了一本書——可能是工頭。
前門大開，一隊人進進出出。有人搜刮過冰箱和食物櫃，罐裝和袋裝食品被撞翻了，掉在地上。醫生的車不見了。難道他帶了小孩跑掉了？但他的皮夾還在這裡。跑路的人一定會帶皮夾。
