# 父仇者 | 114

「我想幫忙。」他對我一笑，從前他就是對顧客這麼燦爛一笑，然後把自己的事業給做倒了。
我只比瓊斯高個五公分，我好好利用這五公分，低頭看著他。「聽我說，瓊斯，滾吧，可以嗎？」
「他還會殺人。」
「你感覺到了嗎？」
強納斯的感應能力肯定很爛，因爲他感覺不到我要他滾蛋。他感覺不到我只想打斷他的腿。
「他刺了他們十九刀，」他說，「我知道爲什麼。」
我停下了腳步，回頭看他。「誰告訴你的？」我問。
「所以是眞的哦。」他說。
「無可奉告。」我說。
「啊，我明白了，你其實也不知道。好，你馬上就會聽到了。我只是比你早知道而已。」
「因爲你能通靈嗎？」
「這是天賦。」他對我說。
「能賺錢的天賦。」我按下了電梯的按鈕。我按了兩次，有人說一直按按鈕電梯也不會變快，希望那只是傳說。「爲什麼要刺十九刀？」
