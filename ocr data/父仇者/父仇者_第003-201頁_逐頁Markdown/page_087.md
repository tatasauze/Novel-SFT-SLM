# 087 | THE LAUGHTERHOUSE
Paul Cleave

15

不知道為什麼，又下起雨來了。我必須讓動得了的那支雨刷加快速度。雨刷發出奇怪的摩擦聲，我很擔心它會從窗戶上飛走，落在別人的前院裡，不過，雨來得快去得也快，攻擊持續了三十秒就結束。我很想超速，但我得小心駕駛，很怕時速一超過五十公里，車子就要解體。療養院外有巡邏車，也有很多媒體採訪車，旁邊站著一臉睏倦的記者，雖然我比施羅德早出發，他還是比我先到。
施羅德在門廳裡，旁邊是漢彌頓護士，她現在看起來一點也不像她，只是一個穿著漢彌頓護士衣服的女人，那套衣服似乎被塞在沙發下二十年了。她看到我想走過來，又改變了主意。施羅德帶我上了樓梯，他要去的方向不是布莉姬這一邊，我不能跟著他，起碼要先去看看我的妻子。我走到她的房間，走廊上的光線讓我看到她睡著了，看起來很平和。
「她沒事，」施羅德告訴我。「發生的事情跟她沒有關係。」
我不知道該對他說什麼。我想釐清我的思緒，安撫混亂的想法——————我想把布莉姬送去別的療養院。我要追捕到妨礙此處安寧的那個傢伙。
「來吧，泰奧，還有事情要做呢，」他把一個薄薄的資料夾舉到我面前。「聽著，我知道你很生氣，但是要把注意力放在正事上，正事就是布莉姬沒事，但有人被殺了，我們需要幫那個人討回公道，因為這就是我們的工作。」
我花了幾秒鐘聽他講話，想辦法聽進去。我發覺他說的有道理。
「泰奧，你的看法跟我一樣嗎？」
