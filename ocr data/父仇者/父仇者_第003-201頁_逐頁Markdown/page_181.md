# 181 | THE LAUGHTERHOUSE
Paul Cleave

我的腳快凍僵了，施羅德在，藍德里也在，還有一個死掉的小女孩躺在地上，渾身是血。一切都好清晰，我的血液一度變得跟那天的天氣一樣冷。死掉的地方有好有壞，屠宰場簡直是壞上加壞。我記得我們好害怕，怕無法爲嫌犯定罪，因爲警探用電話簿毆打嫌犯。
「我知道了。」施羅德說。
「知道什麼？」
「十九刀。我剛跟法醫通過電話。她檢查過了。我的意思是，可惡，我們早該想到了，對不對？但我們都沒想到。除了她以外。我們都在找以前的相關事件，對不對？所以她去找陳屍間是否來過其他中了十九刀的受害者，想說可能是最近的事，結果卻找到了十五年前的兩個名字。」
我放慢了腳步，才能開口說話。「潔西卡·寇爾，」我說。「其中一個是她，對不對？」
「對，另一個是詹姆士‧惠特比。我還在史丹頓的辦公室，」施羅德說。「等等，」他把手機放在堅實的平面上，我聽到砰的一聲，又聽到他拉開了檔案櫃的抽屜。他在翻資料，手指滑過了名字。我聽到他在自言自語，他說：「來啊來啊，在哪裡……」然後「有了！」
「找到了，」他拿起了電話。
「讓我猜猜看。你剛把詹姆士·惠特比的檔案拿出來？」
「答對了，」他說。「惠特比是史丹頓的病人。」
「寇爾覺得是他的錯？」
「等等，等我一下，」我可以想像他現在靠到檔案上，翻閱內容。「可惡，」他說。「潔西卡·寇爾被謀害的兩年前，史丹頓以醫生的身分出席惠特比的審判，」他說，我也記得很清楚。詹姆士·惠特比挾持了年輕女孩塔比莎·詹金斯。他把她關了兩天，然後被捕。接受審判後，他被判無罪，因爲他有精神病。他被送到精神病院關了兩年。
