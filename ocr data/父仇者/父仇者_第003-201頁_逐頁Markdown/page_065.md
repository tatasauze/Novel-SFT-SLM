# 065 | THE LAUGHTERHOUSE
Paul Cleave

「我想念她們，」他說。
「她聽得見，」她說。「她說她很想你。」
「妳能不能……」
「等等，」她抓緊了他的手。「等等，她有話告訴我。她得走了，但有件事她要我告訴你。對，好，」她邊點頭邊熱切聆聽，「好，我懂。我會告訴他。」
她睜開眼睛。「她走了。」她說。
「走了？」
「走了。不過她要我告訴你一些事情。她要你知道她已經不再痛苦了，她跟你們的女兒在一起，她們很愛你，她希望你能快樂。」
他把手拉開了。女人嚇了一跳，她睜大了眼睛，發覺自己說錯了話。「有時候訊息就是模稜兩可，」她說。「有時候可能要試好幾次。」
他們在電話上說好要八十塊，他把錢遞過去，鈔票消失在她的爪子裡。她陪他走到前門。進來的時候他沒發覺門邊有一組行李箱，現在才看到，上面有兩本護照和一疊機票。今晚或明天，她就要跟丈夫或伴侶出國，他想起了二十五年前跟妻子去度假的時候，一天到晚曬太陽，東西好吃酒好喝，九個月後女兒就出世了。
「我的妻子，」他說，「絕對不希望我快樂。她把發生過的事情都怪在我頭上———她永遠都會認爲是我的錯。」
她緩緩點頭，他猜當靈媒就是這樣吧—————從錯誤中學習。他期待她會為自己辯護，說他弄錯了，他的妻子的確要原諒他，要他快樂，不過她一句話也沒說，慢慢地關上門。
他早就應該知道。
