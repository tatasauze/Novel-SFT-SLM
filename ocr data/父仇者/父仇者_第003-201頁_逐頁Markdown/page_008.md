# 父仇者 | 008

常跟露西和她男友這種人背道而馳。我下了車，把報紙頂在頭上擋雨，衝過了永藍汽車旅館的寬闊玻璃門，你絕對不會想死在這樣的汽車旅館裡，要是你死了，表示皮條客很不爽你對待他家女孩的方法。櫃檯後的男人看起來生活只有兩個目標：漢堡和A片。他穿著沾有食物污漬的襯衫，沒扣釦子，露出下面的白色網洞內衣，從網眼裡探頭的毛髮好像畫筆的刷毛，還好我已經二十個小時沒吃東西了。室內有菸味，天花板覆滿了蒼蠅屎。
「有雙人床的兩人房————」
「天下沒有白吃的午餐。」
「是嗎？」
我把照片放在櫃檯上，他就住口了。「看過這個人嗎？」我問。
「老兄，你給我聽好，一天到晚都有條子啊老子啊拉皮條的來這裡找人，我只有一句話————」
「你真熱心助人，」我說。「真正的慈善家。」
「當慈善家就沒錢付帳單。」他說。
「也沒錢幫你買新襯衫。我才不要給你二十塊，只爲了讓你告訴我她不在這裡。」
「我也不要二十塊。我要五十塊，而且你會給我。」
「是啊，因爲我看過她，」他把手伸進襯衫，搔抓起他的乳頭，那副景象可以讓最根深蒂固的男同性戀轉變性向。「而且總跟同一個男的。這些我就不跟你收錢了，好表達我的善意，懂嗎？五十塊，我就告訴你更多消息。」
「如果你看過她，表示她在這裡，或者來過，」我說。「我可以把所有的門踹開，看一看就知道了。」
「說得好，」他伸手到櫃檯下面，把手放在球棒上。有人用麥克筆在球棒上面寫了說服者。
