# 父仇者 | 136

「什麼時候開始的？」
「媽走了以後她就開始了。」
「G、f、g。」凱蒂說。
「妳媽什麼時候走的？」他問。
「我爲什麼要告訴你？」她把凱蒂的泰迪熊拿給奧克塔維婭。奧克塔維婭笑了，緊緊抓住泰迪熊。凱蒂目光空洞，依然唱個不停，甜美的聲音在房間裡迴盪。
「因爲我的口氣很和善。如果妳要的話，我也可以不那麼和善。」
「六個月前。她是個賤貨。」
「什麼？」
「她是個賤貨，該死的賤貨。」
「喔噢，慢點慢點，」他舉起手掌對著她。「講話別那麼難聽。」
「爲什麼不行？你講話也不好聽。」
「因爲我是大人。」
她聳聳肩。「不管怎樣，我媽就是個賤貨，丟下了我們。該死的賤貨。爸以爲我們沒聽到時都這樣講她。」
史丹頓又發出聲音了。掙扎個不停。或許該把他再次弄暈。
「聽起來很難搞。」他對梅蘭妮說。
「難搞？不，你才難搞呢。你最難搞了，對不對？你一定很難搞，因爲你把我爸綁起來，拿著刀子走來走去。你爸媽一定很以你爲榮。」
奧克塔維婭爬開了，用指頭在地板上來回摸索。他想，或許他該封住凱蒂的嘴巴。歌聲眞擾
