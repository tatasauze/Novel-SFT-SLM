# 父仇者 | 192

觀護人把迦勒·寇爾的地址給了施羅德，循著地址我來到街上滿是坑洞、人行道已經龜裂的一區。三點半了，再過一個半小時，就要跟福斯特醫生會面。我轉動方向盤繞過死狗，到了下個街口又繞過另一條死狗；或許牠們選擇撞車自殺，就像要逃命的旅鼠。我第一個到，因爲我開了巡邏車，我選擇把車子停在街尾。我不認爲寇爾在家，但我決定先不要上門，因爲有時候現實與想法相反就糟了。幾分鐘後肯特警探來了，再過一分鐘，武裝應變小組到了，就是剛才那組人。他們或許已經回了警局，又聽說可能另有情況，最好不要離開。他們開始商量怎麼進門，選了演練過很多次的情景，能用來對付棘手的未知對象——這人可能挾持了三名孩童和她們的父親。他們稍早沒有開槍的機會，似乎有點失望，現在的狀況不一樣，又讓他們燃起了希望。
「你覺得呢？」肯特警探問。「你要賭他不在裡面嗎？」
我想到寇爾的鑰匙就掛在他買來的車子裡。「我們兩個都會賭他不在吧。」
寇爾住的那棟房子很大，至少有六十年的歷史了，分成四戶。在這一區，隨便丟塊石頭，打到的人一定坐過牢。罪犯一出獄，就會到這種地區來找房子，你若沒受過作戰訓練、沒有前科、沒有火力強大的槍枝，就會盡力避開這種區域。武裝小組分成幾隊，從不同的入口進去。當媒體採訪車出現時，才過了不到兩分鐘，現場已經被他們掃過一遍了。
附近的人都走到前院來看熱鬧。他們一開口就滿嘴詛咒，叫我們快點滾去死。有幾個人我在監獄裡看過，幾個則是當警察的時候碰過。我跟肯特警探進了寇爾家。門被踢開了，門閂掛在門框上，旁邊裂開的地方彷彿插了好多牙籤。裡面沒什麼東西。一張餐桌，一張破爛的沙發。
