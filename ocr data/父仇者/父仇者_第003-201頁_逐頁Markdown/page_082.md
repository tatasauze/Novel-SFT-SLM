# 父仇者 | 082

她睜大了眼睛，臉色蒼白。他慢慢走近她。
「你是誰？」她問。
他瞥了一眼玄關裡的史丹頓，小女孩從這裡應該看不見她父親。
「沒事，」他盡量讓自己聽起來很平靜，不過看得出她不認為沒事。他覺得她要開口尖叫了。「真的，沒事的。」他說，她當然還是張開了嘴巴，不過當她想尖叫的時候，卻啜泣了起來，哽住了尖叫聲。他慢慢走過去，蹲下身子，好跟她面對面，一隻手按住她的嘴，一隻手按住胸口，把她壓在牆上，泰迪熊也被壓扁了。她不斷掙扎，眼淚都流在他的手上，他很小心，不讓刀子劃到她。看著她的時候，他覺得很困惑。他需要鐵石心腸，不然就不成功了，但他覺得心軟了。
「我不會傷害妳，我保證。我是妳爸爸的老朋友。妳媽媽呢？」
小女孩搖搖頭。
「我需要妳幫忙，因爲我想幫妳爸媽，」他說。「如果我把手拿開，妳可不可以答應我不要尖叫，像大女孩一樣跟我講話？」
她點點頭。他把搗在她嘴上的手拿開，隨時準備她一尖叫就放回去，不過她做到了。她一句話也不說，不點頭也不搖頭。
「妳的名字叫凱蒂，對不對？」
「草字頭的蒂。」她說。
「凱蒂，妳幾歲了？」
「我下星期就九歲了。」
「哇，那妳真是個大女孩了。」
