# 父仇者 | 094

繩。把她們綁起來前，他要她們換上比較保暖的衣服，兩人都選了牛仔褲、襯衫和外套。比凱蒂大兩歲多的梅蘭妮抱怨個不停。她的髮色和眼睛跟妹妹一樣，不過臉比較圓，個性也比較差。
「太蠢了，」梅蘭妮說。「我的手好痛，警察會來抓你。我好想睡。」
「妳等一下就可以睡了，」他對她說。「但警察不會來。」
「我現在就要睡，他們一定會來。你是誰啊？你沒說你是誰。」
「他叫作迦勒。」凱蒂說。
「別傻了，」梅蘭妮看著妹妹。「我不是要問他的名字。我的意思是說，他是什麼人。」
「我不會傷害妳們。」他對她們說。
「你已經傷害了，」梅蘭妮說。「我爸會說你有妄想症。他一定會用那一類的詞來描述你們這種人。」
「閉嘴。」
「妄想症，」她重複了一次。「凱蒂，看到了嗎？我激怒他了。」
「不要惹他生氣，」凱蒂說著哭了起來。「拜託，不要傷害我們。」
他拿出了膠帶。
他撕下了一段膠帶，貼在梅蘭妮嘴上，她把頭搖來搖去，想要躲開。他也貼住了凱蒂的嘴，免得還沒到車上她就尖叫出聲。他把她們一次一個抱到樓下，然後放進後座。
接著他去找奧克塔維婭。
