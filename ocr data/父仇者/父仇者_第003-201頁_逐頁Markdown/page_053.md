# 053 | THE LAUGHTERHOUSE
Paul Cleave

到他前面，在下一個街角右轉。
他發動車子，跟了上去。
他跟了上去。
車程很短。里程表上的數字還來不及轉動。往東開了半條街，那台車就停進巷子裡。燈關了，沒有人下車。巷子裡很黑，黑到容不下陰影，車子跟裡面的人也融入了黑暗。他把車停到對面，緊緊抓住方向盤，快速地用力呼吸，呼吸到他頭暈目眩，雙手發疼——————右手特別痛。他把額頭靠在方向盤上。他很想一頭撞下去，他想讓自己覺得痛。他深呼吸了幾次，想遏止噁心想吐的感覺。擋風玻璃內側起了霧，他用袖子擦了擦。他在方向盤上張大了嘴巴又闔上，一口咬住了方向盤。他想尖叫。
他拿起了刀子。當然，附近有人，不過不多—————一條街外有個妓女，偶爾有車子經過，有兩名行人———————但他或許可以直接走到那台車旁邊，血濺四方，沒有人來得及報警。
他放下了刀子。太蠢了。計畫一半都還沒完成，他可不想被捕。方向盤上留下了齒痕。他瞪著車前面的一大塊廣告牌。旅行社的廣告，有島嶼和海水的照片，還有歡笑的人兒，正是他想要的生活。他專心看著廣告牌，看著那些他永遠無法擁有的東西。他只覺得更加怒火中燒。
車子從小巷裡倒出來，又停下來。副駕駛座的門開了，裡面的燈亮起來，艾瑞兒下了車。她關上車門，頭也不回，走回剛才的路口。車頭燈亮了，往相反的方向開走。艾瑞兒把手伸到提袋裡，又拿出一根香菸，邊走邊把菸點了起來。他仍能看到她剛下的那台車子，停在交通號誌前面。
他忍不住。他看看手錶，十點四十分。跟上去，他的計畫就打亂了，不過他還有一整晚的時間。他應該繼續按著計畫走，晚點再回去找艾瑞兒，說不定正好能配合她下班的時間。
