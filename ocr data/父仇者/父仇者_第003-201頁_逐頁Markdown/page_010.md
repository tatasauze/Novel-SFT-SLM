# 父仇者 | 010

消防隊談話，接著施羅德坐上了我的副駕駛座，弄得座椅上都是水。我們一起看著此處的妓女跟消防員聊了起來。
「幹得好，」施羅德說。「你只惹惱了汽車旅館的櫃檯和整個消防隊，我不得不說算是不錯了。」
「謝謝你的誇讚。」
「媽的，你不殺人我就很感恩了。」
「在生命中總是得學習。」我說。
「下午你還是會來吧？」
「我說過我會去。」
「你知道的，也沒那個必要。你又沒有跟他特別好，他也絕對沒說過你什麼好話。」
「我知道，」我說。「太慘了。」我想起上次見到比爾·藍德里已經是去年了。他控訴我殺了兩個人。他只對了一半。一個星期前，藍德里那時在追查一些些線索，很爛的線索，他做出很爛的結論，付出了終極的代價。現在，因公殉職的警員又多了一個，負面統計數字又多了一筆資料。
「你沒事吧？」他問。
「什麼？」
「你在揉你的頭。」
我把手從頭上拿下來，這一側的頭髮下凹了一塊，也有一條疤。我沒意識到我在揉那個地方。六個星期前，有人想殺我，用玻璃罐打在我頭上，當時罐子裡還有一根切下來的拇指。從那以後，我就常常頭痛得很厲害。還好現在快痛完了。
