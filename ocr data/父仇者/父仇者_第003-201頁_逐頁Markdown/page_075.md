# 075 | THE LAUGHTERHOUSE
Paul Cleave

13

對手不是連續殺人犯，而是狂魔殺人犯，不論是我，還是施羅德或局裡的人，都沒碰過這種對手。連續殺人犯好整以暇，不慌不忙。狂魔殺人犯到處亂跑，見人就殺。正在處理一名受害者的時候，加害人又製造出另一名。
凌晨三點，我們離開醫院和基督城裡的新任寡婦，各自開車前往犯罪現場。路上看到了像吸血鬼般從來不睡覺的記者，他們也跟吸血鬼一樣專門吸別人的血。如果世界上有吸血鬼，但沒有記者，我們或許會活得更快樂。
從這一區的環境看來，會計師的收入不錯，也應該住了不止一名會計師。或許他們每隔幾個月就會開個會計師派對，交換最新的律師笑話，所有的花費都可以報帳。記者對著我們大吼問問題，我感覺到幾十個鏡頭靠近了我的臉。我們把車停在巡邏車後面，巡邏車的後座鎖了一個人，脖子上掛著記者證，手腕被銬了起來。車頂上有台昂貴的相機，應該摔過了，有一側已經刮花，還凹了個洞。
他們家是平房，有四間臥室，前面的草皮很小。裡面留著晚餐的味道。有幾名警探已經到了，肯特警探也在，正在跟鄰居講話。我們走過去的時候，她對我們點點頭，感覺非常和善。車庫的地板和車子的半邊濺滿了血，布萊德往後倒，踩到血滑倒了。水泥地上有手印和血痕。似乎布萊德在動彈不得前會努力把自己往前拉。兇手沒關上車庫門，但可憐的布萊德躺在那裡等妻子或鄰居來解救他的時候，沒有人看到他。不過，鄰居現在都來了——————挺多的。他們都站在自己家門外看熱鬧，對著死亡事件嘖嘖稱奇，看這齣戲看得入迷了。他們無法轉開視線。流了這麼多
