# 父仇者 | 018

逃————繼續殺人。我在二月出獄，施羅德到監獄的停車場等我，帶來了梅莉莎·X的資料，要我助一臂之力。我們找出了她的真實身分。她本名娜塔莉·福勞爾斯——————三年前她被大學教授強暴後，就自稱梅莉莎。從那時候起，她折磨殺害了至少六個男人，最後一次犯案是在七個星期前。
「沒有新消息嗎？」
「我們跟她所有的家人朋友談過了。什麼也沒有，」他說。「我們也追蹤了外科醫生和醫美診所，查她有沒有整型，也是什麼都沒有。她似乎離開了地球，當你真的覺得她銷聲匿跡了，她又殺了一個人。」
「似乎就是那樣。」我手上也有資料，我每天都看，跟施羅德一樣，只是看資料沒辦法賺錢。
「我們會抓到她，」他說。「我可以向你保證。」
喪禮中坐在我旁邊的女子看到我們，走了過來。施羅德站起來對她微笑，我也如法炮製。
「泰奧多·泰特，這位是肯特警探，」他幫我們介紹。
「叫我蕾貝卡就好。」她伸手跟我握了一下。
蕾貝卡比我矮幾吋，也輕幾磅，或許在這世界上的煩惱也比較少。陽光外型，充滿魅力。我跟施羅德對著她，都忍不住一直微笑。她輕輕把及肩的黑髮攏到肩膀後面。
「妳跟施羅德一起行動嗎？」我問。
「肯特警探剛從奧克蘭調過來，」他說。「她才來一個星期。她是奧克蘭最棒的警官，能來是我們的運氣。」
她微微一笑。「我運氣好才能回來，」她說。「我在基督城出生，也在這裡長大。」
「真的呀，」我說。「妳什麼時候離開的？」
