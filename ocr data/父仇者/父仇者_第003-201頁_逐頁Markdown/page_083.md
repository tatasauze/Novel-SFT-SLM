# 083 | THE LAUGHTERHOUSE
Paul Cleave

「沒錯，」她說。「你是誰？」
「我的名字叫作迦勒，」他說。「我認識妳爸爸。」
「我爸爸在哪裡？」
「他在樓下等我們。妳媽媽呢？她去睡了嗎？」
「我不知道。她不住在這裡了。」
「什麼意思？」
「媽媽不愛爸爸了，爸爸也不愛媽媽，媽媽搬出去跟別人住在一起了，她愛那個人。」
「但是妳說她去睡了。」
「很晚了，」她說。「很晚的時候大家都去睡了。」
「妳一直都住在這裡嗎？」他問。
她點點頭。
「妳不跟妳媽住？」
她搖搖頭。
「好，好，很好。聽我說。我要跟妳爸爸出去一趟，」他說，「我們把小孩留在這裡的話，就很不負責任，所以妳們兩個也要跟我們一起去。妳帶我去找妳姊姊，好嗎？女孩子乖乖的，就不會受傷，」他告訴她，不過他當然滿口謊話。「妳不想受傷吧，難道妳想嗎？」
她緩緩搖頭。
「OK，凱蒂，草字頭的蒂，帶我去找妳姊姊，好嗎？」
