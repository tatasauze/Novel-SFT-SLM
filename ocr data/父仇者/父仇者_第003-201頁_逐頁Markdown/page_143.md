# 143 | THE LAUGHTERHOUSE
Paul Cleave

「你沒有，你也從來沒說過他去坐牢的話我們都會過得更好。你反而說他需要幫助，醫療可以改善他的情況。你說他可以治好，陪審團和法官都相信你的話。」
「我……我眞的很抱歉，我……噢，老天啊，不要傷害我的孩子。」
迦勒靠過去，用盡全身力氣打了他一巴掌。聲音比女孩的哭聲還響。在房間裡激起了回聲，傳到門外，深入屠宰場的核心，越過了鮪魚罐頭和正在享用罐頭的老鼠，越過了裝滿糞便的塑膠袋和引擎蓋上撒了尿的車子。有那麼一刻，房間裡就只有巴掌聲，女孩的哭聲停了，然後她們又哭了起來，最小的用手掌拍打地板。
「想一想你有什麼話要對她們說，」迦勒的聲音依然很低，但更帶威脅感了。「你有一天的時間可以決定，因爲今晚我就要報仇，我的家人經歷了什麼，你的家人也要經歷。」
「求求你——」
「你這個不要臉的王八蛋，我還給你機會去安撫她們。我女兒可沒有這麼好的待遇。你女兒不用孤孤單單地死在這裡。」
「求求你不要這樣。」
「醫生，你有宗教信仰嗎？」
「什麼？沒有，沒有……你爲什麼要問？」
「因爲現在，你最好開始祈禱了。醫生，以眼還眼。聖經說的。從象徵意義來說，跟我們眼前的情況一樣。」
「你不需要——」
「別浪費唇舌了，」迦勒拿出新的塑膠繩來綁住孩子。「說什麼都沒有用。對你的女兒說吧。跟她們講話，陪陪她們，跟她們道別，但別搞錯了，今天晚上，在這個鬼地方，我要動手殺掉你的家人，你他媽的一點辦法也沒有。」
