# 117 | THE LAUGHTERHOUSE
Paul Cleave

「好，我不想衝進來對你們發脾氣，搞得自己跟個混蛋一樣，不過這是爲了你們好，你們就是欠罵。我告訴你們，我他媽的從來沒想過要跟這麽一群會做事的人解釋，最好不要醉醺醺地來工作，不過，或許是我的錯吧，我高估你們了。」
簡報室裡的人都避開了他的目光。有些人覺得眼前的桌子實在太有趣了，有些人死盯著自己的鞋子或窗戶，有些人則凝望史蒂文斯右邊距離他兩公尺的某個點。
「OK，看來大家都明白我的意思了，」他說。「好，我知道你們都累了。沒有人經歷過這種事，但有個變態王八蛋正在濫殺我們的市民，我們今天就要抓到這個畜生，抓到他以後，你們就可以回家，好好睡一覺。好了，我本來不想來這裡搞什麼精神訓話，不過你們需要聽我唸一唸。」然後他開始精神訓話了，並不照程序來，強調我們絕不能搞砸了，細細講解所有的細節。快講完的時候，他看著我，說我們絕不能丟警察局的臉，現在正是基督城最需要我們的時候。我完全同意。
「我知道大家都很激動，」他說。「昨天，我們的同事下葬了，大家心情都不好，」他看著簡報室前面的一張空椅子，應該以前是藍德里習慣坐的位子。我們一起看著那張椅子，不知道史蒂文斯昨晚有沒有看最新的警察影集來汲取今天精神訓話的靈感。「我們人手不夠，只知道明天此時，可能又多了四具屍體。」
簡報室裡響起了一片嗡嗡聲，我也開口了。今天多了四具屍體，明天還有更多。有什麼東西正在成形，你卻看不出來是什麼，實在很難保持樂觀。
