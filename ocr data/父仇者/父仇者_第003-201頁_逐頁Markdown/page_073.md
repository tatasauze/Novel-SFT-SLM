# 073 | THE LAUGHTERHOUSE
Paul Cleave

「就那樣？」
「我已經說了。」
「如果有人威脅他，他會告訴妳嗎？」我問。
「布萊德什麼都會告訴我。」
我從來不知道女友和妻子是否真的相信這種說法。
「我知道你在想什麼。」她說。
不需要鼓勵，她就繼續說下去了。
「你以爲，一天到晚加班，表示布萊德有外遇。可是，他才沒有。」
我心裡沒那麼想—————起碼沒認真想，不過現在我倒認真起來了。「聽我說，海沃德太太，有人懷疑妳丈夫有外遇嗎？我需要知道所有的細節。妳如果不說，說不定就完了，妳知道什麼都告訴我們，可以幫我們找出誰是兇手。」
「我沒有隱瞞什麼。」
「他爲什麼離開國稅局？」
「我說了，他想換個環境，」這次她直視著我，幾秒後才轉開眼神，再加上剛才她說過她丈夫沒有外遇，我知道她說謊了。我在這一行很久了，久到像海沃德太太這樣的人騙不了我。「薪水比較高，環境比較好，而且沒有人想在稅務部上班。」她說。
我點點頭，那倒是。「我一早就會打電話給他們，跟他老闆聊聊，到時候就知道了，」我說，「不如妳現在就告訴我。」
