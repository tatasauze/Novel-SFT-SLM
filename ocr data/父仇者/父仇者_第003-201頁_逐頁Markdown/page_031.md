# 031 | THE LAUGHTERHOUSE
Paul Cleave

「死者叫赫伯特·普爾，八十四歲，」警員說，聲音有點發抖。「現場很慘，非常慘。我當警察三年了，從沒看過這種場面。」
「有目擊證人嗎？」
「還沒有。是養老院的經理報警的。通常這個時候老人都在房間看電視或睡覺，但經理巡邏時發現普爾先生的門沒鎖，燈也開著。他走進去，然後就……」
「兇手留下了什麼？」
「很多血，還有兇器——應該是把大刀。而且兇手在死者頭上留了字。」警員吞了吞口水，「用麥克筆寫的。」
「寫了什麼？」
「『你不夠關心』。」
施羅德這時走過來，抹了抹嘴巴，試圖掩飾臉上的酒意。「情況如何？」
「老人家被捅了很多刀，頭上寫了字，」我告訴他。
