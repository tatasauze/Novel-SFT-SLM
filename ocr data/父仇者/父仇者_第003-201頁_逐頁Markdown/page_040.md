# 父仇者 | 040

「什麼？什麼也不做，我們都沒有工作。」
「我是說他退休前。」
「喔，對了，你當然是這個意思，」他又苦笑了一下。「他是律師。」
「什麼樣的律師？」
「其實我不知道。他很少提起當律師的事。在我聽來，沒什麼特別，你也知道，合約法，處理地產買賣，那些世俗的東西，一個小時就要收我們四百塊。」
「他什麼時候退休的？」
他聳聳肩，然後開始在心裡算數。他一開始想，全身似乎都停止運作，變成了一座雕像，五秒鐘後才活過來。或許他仍能跟赫伯的妻子通靈，或許他跟本人詢問，等他回神後，他就有了答案。
「他妻子過世前幾年，」他說。「他不想退休，但他病了。你知道，他以前是個老菸槍，所以肺很不好。他放棄工作的同時也戒菸了。那時候醫生說他大概還能活兩年，他妻子卻先死了。五年後，醫生說他還有六個月。之後他們每年都講三四次，他只能活兩個月，結果他又撐了幾年……」
「你會抓到那個壞人吧，對不對？」
「對。」
「他會怎麼樣？」
「他會去坐牢。」
