# 081 | THE LAUGHTERHOUSE
Paul Cleave

用左手的，克制不了本能，就要付出代價。他的手捏成了拳頭，過了一下子才能伸直。他用腳往醫生的肚子踩下去，再把不痛的那隻手伸進褲腰裡拉出刀子，這時醫生也倒在地上了。他環顧四周，他們在玄關裡，左邊通往起居室，再過去應該是客廳，右邊則是樓梯。沒有其他人了。
「看到了嗎？」
「什麼？」
「你斷我鼻(你弄斷了我的鼻子)—————」史丹頓用手蒙著臉，從指縫裡看他。
「你再抱怨，我還要弄斷更多地方。你老婆呢？」
「喔。」
「你老婆，她睡了嗎？」
「什麼？」
「你是隨(你是誰)？」
「翻過去，」迦勒很困擾，情況變得太複雜了。「如果你不聽話，我就把刀子插進你胸口，然後一樣把你的小孩殺了。」
「別桑我害子(別傷害我的孩子)。」
幹。他沒時間搞這些。他老婆可能已經打電話報警了。他使盡全力，把刀子往下一插，醫生縮了縮身子，但避不開接下來發生的事————刀把砸在他頭上，讓他安靜了下來，應該可以安靜一陣子。
聲音從樓上傳來。他把刀子塞回褲子後面，走上了樓梯。有個小女孩站在樓梯頂上，一頭亂糟糟的褐髮長及肩膀。她穿著粉紅色的睡衣，手裡抱著泰迪熊，另一隻手的手指則咬在牙齒間。
