# 父仇者 | 074

他騷擾她，可是他沒有。很蠢。她不喜歡布萊德，就亂捏造謠言。換個環境比較好，不需要跟她鬥。就這樣，警察先生，你以爲布萊德有外遇，可是他沒有，他不會有外遇，他不是那種愛偷吃的人。」她說，不過我覺得他會偷吃，她也覺得他有可能偷吃。半夜才回家，加班到很晚————不是會計師，也能算出結果。
我謝過她告訴我的訊息，祝她丈夫好運。施羅德也講完了電話。
「有什麼消息嗎？」他問。「看起來你在找她麻煩。」
「她丈夫有外遇，或許這就是為什麼他這麼晚才回家。或許他跟不正派的女人亂搞。或許那就是關聯所在。」
「她告訴你的嗎？」
「她沒說得這麼清楚。」我說。
就在此刻，醫生出來了，垂頭喪氣，他還沒開口，我們都知道他要說什麼了，兩個女人崩潰大哭，基督城的殺人案又多了一樁。
