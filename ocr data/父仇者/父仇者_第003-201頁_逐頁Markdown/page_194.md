# 父仇者 | 194

「你剛剛要說什麼？」掛掉電話後，我問肯特警探。
她微微一笑，緩緩搖頭。「沒事，不重要，」她說。「該回去了。」
回到警局時，施羅德已經印出了詹姆士·惠特比的犯罪紀錄跟心理治療紀錄。我坐在會議室裡看紀錄，施羅德則撥弄著咖啡機，想再來一杯。法庭發現惠特比缺乏意識能力，不明白自己對塔比莎·詹金斯做了什麼，因爲他確實沒有意識能力。惠特比從小就常被母親狠揍——最後一次，她用熨斗砸他的頭，從此失去監護權，詹姆士則住院三個禮拜。他受傷很重，一直無法完全痊癒；事實上，頭幾天醫生認爲他活不了了，重擊在他頭上留下了永久的凹痕。母親很氣詹姆士不肯醒來。她踢他，他卻沒有反應。她以爲他在假裝。那時候熨斗還沒冷下來。她想，把熨斗放到他胸口好了，以爲這樣就可以弄醒他。她錯了。她用熨斗紮紮實實熨了他的胸口，然後再從胸口移到腹部，然後兩條大腿。過了一個小時，她終於叫了救護車，醫務員到的時候，她喝醉了，坐在電視機前面對著肥皂劇大罵。然後她也吼了醫務員，因爲他們不把她兒子弄醒，好讓他把碗洗乾淨。
有些人「贊成」連續殺人犯是後天因素造成，不是天生的，就會拿這種案例來爭論。到了醫院，他們發現之前詹姆士被揍得有多嚴重——手臂骨折、手指斷了、手臂上都是香菸燙傷的痕跡，惠特比還是活下來了，他母親則接受心理諮詢，去上憤怒管理課程，被迫繳付一連串的罰鍰，也被關進牢房裡——她被判刑十五個月，但八個月後就出獄了。出院後，詹姆士被送到寄養家庭，他在臥房放火，弄死了他們家的貓，對自己的新姊姊赤身露體。他又被送到另一個家庭，最後則到了政府經營的問題孩童收容所。他在學校裡需要特殊教育。他最常惹的麻煩就是躲在女廁裡看女生上廁所。十七歲從學校畢業後，他離開政府的收容所，搬進有一間臥室的公寓。不到一個月，他就纏上了塔比莎·詹金斯。
