# 109 | THE LAUGHTERHOUSE
Paul Cleave

18

史丹頓醫生醒來了。迦勒打開行李廂的時候，他還想往更裡面縮。迦勒從來沒看過一個人可以驚慌至此。他的神色流露出他不知道孩子們是死是活。他應該警告他，現在還算簡單，接下來要發生的事才可怕，到那時候才應該要覺得害怕。
他頭上腫了一個包，有高爾夫球大小——他可要頭疼了，但是死不了。他的雙臂綁在背後，睡衣皺到不能再皺了，腳踝也綁在一起。
「你女兒沒事，」迦勒告訴他。「但你如果不聽我的話，我就對付她們。我要把她們的臉割下來攪在一起，你就分不清楚他媽的誰是誰了。你信不信？」
醫生點點頭，但沒說話。迦勒看得出來他聽進去了。
「醫生，你看，問題就出在這裡，以前你信錯人，但很好，你從錯誤中學習。你知道我是誰嗎？」
醫生點點頭，但沒說話。迦勒看得出來他聽進去了。
「你應該不知道我是誰。好多年了，我想我也跟那時候報紙上的照片長得不一樣。但我們沒見過。過去這幾個禮拜，我都在觀察你，多年來，我已經找到很多你的資料，但是有些事情我不太明白。我發現你太太離開了。眞可惜，」他說，「因爲，能當著你的面殺死她，一定很好玩。坐牢的時候要找資料很難，不過有時候我們可以去圖書館，可以上網。網路上亂七八糟的狗屁眞多。」是眞的。出獄後這件事頻頻令他稱奇——隱私的界限就這麼蕩然無存，大家都把人生故事發布在網路上，他們會把自己的感覺告訴朋友。他的更新狀態應該是迦勒生氣了。頭搖了一下。
