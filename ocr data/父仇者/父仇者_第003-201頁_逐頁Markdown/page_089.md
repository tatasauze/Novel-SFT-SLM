# 089 | THE LAUGHTERHOUSE
Paul Cleave

我看了看走廊。「沒有人聽到聲音或看見什麼嗎？」
「沒有，受害者當然不會吭聲。」
「你跟她丈夫談過了嗎？」
「他死了。兩年前自殺了，上吊自殺。」
基督城裡的故事一定要有悲慘的結局嗎？每個人都有傷心的故事嗎？
門內門外都有鑑識專家。地板上的血滴旁貼了塑膠標籤，屍體旁的血腳印顏色很深，但走遠後顏色就慢慢變淺，最後消失在樓梯附近。死者的手臂仍擺在身體兩旁，臉上毫無驚懼之色。她閉著眼睛，臉龐非常放鬆。我跟施羅德都是第一次看到昏迷的人被謀殺。或許對大家來說都是第一次。我們看過懷孕和得了病的受害者，昏迷卻是前所未見。
「你沒事吧？」施羅德問。
「我不確定。」我說。
「看起來你最好去呼吸一下新鮮空氣。」
死者額頭上的筆跡跟一號二號的一樣。
「兩個律師，一個老師，一個會計師。」施羅德重複了一次。
「看起來不像笑話的開頭了。」我說。
「不像，不過一直都不像。」他用兩隻手推推背，伸展了一下，脊椎發出輕微的嘎聲。我看過別人這樣做，結果閃到腰了。「職員說你稍早來過，」他說。「你什麼都沒看到？」
「我確實看到有人拿著血淋淋的刀子走路，但不覺得有什麼好說的。」
「喂，我不過是問一下。」
「我看到什麼當然會告訴你。誰發現的？」
