# 父仇者 | 162

「又有新的發展了，」一名警探走進會議室告訴我們，就是臉蛋被藍德里黏在桌上的華茲警探。「有個醫生失蹤了，」他對著大家說，基本上還是對著施羅德報告。「心理醫生，尼可拉斯·史丹頓。保母早上過去的時候發現打鬥的痕跡。過去調查的警官證實，史丹頓可能被攻擊了。」
施羅德的目光已經離開了華茲，他看著我，我們都在想同一件事情。然後，華茲還是繼續說下去，幫我們說出心裡的想法。「死了兩個律師、一個會計師和一個學校老師。現在有個醫生失蹤了。很可能有關聯吧？」
施羅德仍盯著我看。會議室裡的人都看著我，彷彿在做出反應前，要先等我提出意見，不過他們其實不是在等我。他們都在想這件事情到底有什麼含意。
「保母，所以有小孩，」我說。「幾個？」
「三個，」華茲說。「史丹頓跟老婆分居了，但三個孩子的監護權都歸他。大的那兩個今天沒去學校。女孩子，十一歲跟八歲。一歲大的那個平日由保母照顧。」
「走吧。」施羅德站起來，我跟在他後面。
