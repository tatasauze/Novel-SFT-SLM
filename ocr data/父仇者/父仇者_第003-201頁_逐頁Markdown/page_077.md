# 077 | THE LAUGHTERHOUSE
Paul Cleave

「我想讓自己聞起來香香的，不行嗎？」
「你在幹嘛？」
我告訴他車子裡的味道。
「然後呢？」
「這些味道都不一樣。加上我找到的頭髮，所以———」
「所以車子裡還有另一個人。」
「香水味仍然很濃，一定是今天晚上。」
「說不定他送同事回家。」施羅德說。
「你跟他老闆談過了嗎？」
「還沒。聽我說，泰特，太瘋狂了，他媽的瘋狂到不行，但是……但是第四具屍體剛剛出現了。」他搖晃手機，彷彿想把壞消息搖掉。
我很想把香水往後一丟，振動手臂拍打身體，說好呀，我猜遊戲真的開始了，因爲我們只能滿城追逐一個心理變態的兇手，還有好幾個小時才會天亮，我們根本不知道天亮前兇手是否會住手。明天這個時候，我們說不定要被屍體淹沒了。
「不。」我搖搖頭，想要反駁他。
「四具屍體，」他說。「就像……可惡，我連像什麼都不知道。」
「就像天翻地覆了。」我放下了香水，覺得肚子裡有什麼在翻騰。「天啊，」我的聲音聽起來很微弱。四個人。至少四個家庭。牽連到幾十個人，他們的生活要天翻地覆了，父親母親、朋友、親戚————好痛苦，好傷心。
「如果老天來辦案，那就容易多了。」他說。
