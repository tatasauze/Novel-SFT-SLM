# 171 | THE LAUGHTERHOUSE
Paul Cleave

「把車子留在這裡的人不需要鑰匙了，家裡的也是。」我說。
「如果他有鑰匙，車子應該不是偷來的。」
昨晚在墓地的男人，就是我們要找的人？他是唐納德·史拉格斯嗎？他被揍成那樣，所以才怨恨這個世界？兩名記者發覺車子很重要，像病毒傳播一樣，別人也發覺了。不到幾秒，就有幾十支鏡頭對著我們的臉。
「退後，退後，」警官舉高了手，用手掌對著所有人。「全都給我退後。」
其他的警官也過來，幫忙把記者往後退。一塊空間清出來了，我們才能細看這台車。儀表板上跟座椅後面都沒有東西，置物盒裡只有一張地圖。我看了菸灰缸，空的。副駕駛座上血跡斑斑，已經乾了。可能是放在上面的武器留下來的，看起來像支刀。我看了座椅下方，什麼也沒有。
卡車可能本來就在附近，不到五分鐘就到了。穿著灰色連身服的魁梧男人下了車，走到嫌犯的車子旁邊，邊玩著手把形狀的鬍鬚邊端詳這輛車。感覺他應該不愛說話。卡車的平台朝下移動，變成了斜坡，他把嫌犯的車子拉了上去。然後放平平台，車子則用鉤子和棘輪固定帶卡住。
我對著警官招手，一名跟我差不多年紀的人過來了，最近我在犯罪現場常看到他。「跟他一起走，」我指著拖吊車的司機。「好好看著這台車子。」
「是，長官。」他跳進了卡車的副駕駛座。
「你拿到了史拉格斯的地址嗎？」我問跟我走過來的警官。
「拿到了。」
「很好，」我對他說，「那我們去兜風吧。」
