# 父仇者 | 168

兩個女孩的照片。年紀比較小的咧嘴大笑，彷彿她是全世界最快樂的女孩。照片裡的她應該是六七歲，是凱蒂吧。我感受到內心的怒氣愈來愈強烈。我要把這個綁走小孩的男人揪出來，讓他付出代價。
「你發現了嗎？沒有嬰兒的照片。」我對施羅德說。
「對啊。你覺得是什麼原因？」
我聳聳肩。「或許他沒時間放上去吧。」
我聽了福斯特醫生給我的留言。他說接到了我的留言，但一整個下午都約了病人，五點的時候他會去看我妻子。我看看手錶，還有四個多小時。他找過漢彌頓護士，他們能了解我爲什麼興奮，但也要我別抱太高的希望。他希望能跟我在療養院碰個面。
我們在醫生家裡四處翻查，但我無法專心，無法把全副心思放在案情上，我一直想到布莉姬的情況可能好轉，雖然其他人都不贊成我的看法。四十分鐘後施羅德接到了電話，搜查令下來了。
正當他掛上電話的時候，肯特警探抵達。她對我們兩人微笑，點點頭，「我查到一些資料。保母滿愛講話。六個月前，艾琳·史丹頓走了。拋夫棄女。看來嬰兒惹了不少麻煩。比我們一般聽說的產後憂鬱症還嚴重。史丹頓幫她開過藥，但她不肯吃。他一直要她去跟別人諮商，但她聽不進去。她倒是自己找到了方法，在網路上認識了比她年輕十歲的男人，離開這段生活。史丹頓提到她的時候依然很怨憤。保母說她沒看過史丹頓對老么展現過一絲父愛。她說他很愛老大跟老二，什麼都願意爲她們做，但他看到嬰兒的時候，眼神很像看到了一塊他不知道自己想不想吃的披薩。保母在這裡工作六個月了，」肯特說。「他太太走後一個星期，她就來上班。她說那時候這裡一團亂。還說要是沒有保母，這個家就完了。不知道你們注意到了沒，家裡沒有奧克塔維婭
