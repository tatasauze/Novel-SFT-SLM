# 父仇者 | 028

「你打賭輸了嗎？」他問。
「什麼？」
「你為什麼要開這台爛車？」
「你要走過去的話請便。」
「或許比較安全，也比較快。」
「還會淋濕。告訴我要去哪裡吧。」
「養老院。」
「哪一間？」我把車開下斜坡，朝著底層前進。
「什麼哪一間？喔，幹……等等，我想想看。哪一間……啊，等等。」簡訊打到一半，他就想起來了。「湖景養老院，你知道在哪裡嗎？」
「聽著，卡爾，我真的覺得你不該過去。」
「泰奧，我只喝了兩杯啤酒。」
「你正要開始喝第四杯，四杯真的太多了。」
「天啊，我應該跟其他人一起走才對。」
「然後呢？跟其他人一起丟掉飯碗？」
「不可能。他媽的有誰能填補我們的空缺？」
算他有理。我上了路，一台裝滿警察的計程車超到我前面，差點把我車子的側邊削掉了。我想按喇叭，但喇叭壞了。又開始下起毛毛雨。我打開雨刷，施羅德那邊的雨刷一抖一抖爬到最高點，抖了幾下後死在那裡。施羅德敲了敲擋風玻璃。
「天啊，泰特，你找不到好一點的車了嗎？」
