# 167 | THE LAUGHTERHOUSE
Paul Cleave

客廳的一角有台嬰兒車。他爲什麼不帶走？地板上有血滴，還用用過剪斷的塑膠繩。旁邊已經放了證物標籤，攝影師一一拍攝下來。女孩的床有睡過的痕跡，睡衣都丟在地上。
我的電話響了，顯示剛才我找的人打電話來了。福斯特醫生。我把電話放回口袋裡，沒接。現在不適合講電話。
「幹這事的人把醫生的車開走了，」我說，「我們可能要找兩個人，一個開走醫生的車子，一個開走他們開來的車子。」
施羅德搖搖頭。「還有其他可能。或許嫌犯帶走了女孩，強迫醫生開自己的車跟著他，有可能他走路或搭計程車來，或把車停在轉角。我派幾個警官去街上好好查一查。敲鄰居的門問問看附近有沒有陌生的車子亂停，」施羅德說。
「他的病歷裡一定有個名字跟這些人都有關係。」
「史丹頓在城裡有間辦公室。我派人去申請搜查令。就算史丹頓自己開了診所，也需要搜查令。如果破門而入，亂翻病歷，發現一切都是誤會，警局會被告，你跟我都要丟飯碗了。就算不是誤會，結果也一樣。天啊，這比律師事務所的搜查令還難申請。這種東西……媽的，心理醫生的病歷要拿到手比登天還難。」
他打了個電話，叫人準備登天，然後我們翻了書房，希望能找到病人的資料，但什麼也沒有。史丹頓不會把工作帶回家。牆上有家人的照片，不過裡面都沒有他太太。
「你注意到了嗎？」我指著照片問施羅德。
「是啊，看來分手不太愉快。如果保母不知道詳情，有些鄰居可能知道，感覺這條街上的人應該聽過很多傳聞。肯特正在跟保母談話。」
