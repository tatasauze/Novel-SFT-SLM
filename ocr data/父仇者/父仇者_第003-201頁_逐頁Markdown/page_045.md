# 045 | THE LAUGHTERHOUSE
Paul Cleave

他出了淋浴間。浴室的鏡子蓋滿了霧氣，沒關係—————他不想看到自己。他的倒影看了就讓人難受。他把自己擦乾，到臥室穿好衣服。然後他把玩了一下手機。他用手機開了新聞網站，到目前為止還沒有兩名死者的報導。
手機轉成鎖定的螢幕，他必須把手指滑過去，才能繼續使用。他這輩子從來沒用過這種手機。很多年以前，手機都大多了，也重多了，如果不從正確的角度看螢幕，什麼也看不到。現在跟他的手掌一樣薄一樣輕，有好多功能。人類再過幾年就可以過著《星艦迷航記》中寇克艦長的高科技生活。
快要十點十五分了。他抓起鑰匙、外套、刀子和剛才買的花。他在門口停下來，對著公寓看了幾秒。以後不會再回來了，這裡不是家，不會讓他想念。
夜晚的基督城過了這麼多年，看起來還是一樣，不過感覺不一樣了。他有機會就會看新聞——他知道犯罪率節節上升——————不過現在他可以感覺得到。城裡的人變了。更多剃光了頭髮、滿身刺青的人，有人邊走邊吐口水，撞到別人後便起了爭執。很多人開著引擎轟隆作響的跑車。很久了，但當他還屬於這個世界時，車子跟現在不一樣，不過它們代表的地位沒變，都是雞雞小卻很自大的男人，他懷疑現在還是這樣。最糟糕的是青少年。十五年前，會有人在兩條主要街道上開來開去，巨大的車子看起來快要進垃圾堆了。現在的車子更吵，顏色更刺眼，在街上巡航的男孩車窗上掛著骰子外型的絨毛吊飾，車身裝了霓虹燈，他不懂，就是不懂。感覺好像進入了色彩更鮮豔的卡通世界，開著閃亮汽車的青少年都瘋了。
街上的人似乎都沒看到他。他把車子停在半條街外。車齡已經超過四分之一個世紀，他只知道引擎蓋下有個東西每幾分鐘就會咳嗽噴氣，不過仍能帶他去想要去的地方。賣車給他的人把音響拔掉了，用一塊漆成黑色的夾板蓋在上面。他從城裡治安不怎麼好的區域進入治安稍微沒那麼
