# 157 | THE LAUGHTERHOUSE
Paul Cleave

23

離開醫院後，我轉開了收音機。過去幾個月來，媒體和政客都在討論死刑的問題。死刑早在一九六一年廢除，有人主張恢復，是否要恢復當然會引起爭論。有些人很討厭這個想法——他們說死刑等同謀殺，絕對找不出正當的理由。每當警方在調查兇殺案時，辯論最爲激烈，雙方都有支持者，然後可能就平息下去——這種辯論沒有中立方，每個人都有意見。如果他們問我，我會說死刑可以保證路上沒有殺人犯。實際上也只有這個辦法。大衆要求公投——希望自己的聲音被聽見。但在這個世界裡，受害者活不過來，兇手逍遙法外，群衆的意見沒有人聽。我不覺得情況會有所改變。好吧，如果地球眞的由猩猩統治，或許能看到轉變。
我在咖啡店外停了車，胡亂買了杯咖啡跟貝果。櫃檯後的女人大約二十五六歲，她笑容滿面，問我今天過得好不好。我說還不錯，沒告訴她我剛才看了幾具屍體，也沒說我的今天已經過了快三十個小時了。我問她好不好，她也說不錯，但跟我一樣不透露細節，希望她的原因跟我不一樣。咖啡店的後面很安靜，我找了個雅座坐下。桌上有份報紙，頭條是爺爺開膛手，但報紙有個問題，墨水還沒乾，新聞就變成舊聞了。我把報紙翻了個面，不想看到頭條，背面是體育版，身穿比基尼的女人站在衝浪板旁邊，身形跟板子一樣瘦。有人用藍筆加上了鬍子跟陰莖，還加了一個對話框，裡面的字寫得太亂了，看不出來在寫什麼。我覺得這些東西應該加在女人身上，而不是衝浪板。我把報紙推到旁邊，拿出手機。
我撥了個電話到妻子的療養院。等了一分鐘，接線生才找來漢彌頓護士。
