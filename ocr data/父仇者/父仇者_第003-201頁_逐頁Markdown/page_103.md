# 103 | THE LAUGHTERHOUSE
Paul Cleave

17

約翰·摩根已經起床了，泡好了咖啡在客廳裡等我。聞到咖啡香，我覺得振作了點，自己也有點驚訝，因爲我沒發現我有點倦了。這麼早就來找他談話，我覺得很不好意思，不過他似乎不在意。我們面對面坐下，中間的咖啡桌中央堆了一疊雜誌，有時尚雜誌，也有建築雜誌，最上面則是一本印了杯痕的電視節目指南。他的太太還沒起床，可能還在睡，或者想讓自己睡著。咖啡很燙，味道也不錯，令我滿懷感激。摩根黑白夾雜的頭髮在枕頭上壓了好幾個小時，翹了起來，右側的鬢角比左邊濃密，應該也是側睡的關係。他穿著睡衣，外面罩了件睡袍。
「布萊德，嗯，是很優秀的會計師，」約翰說，「要找人來取代他可不容易。你知道艾德華・杭特是誰嗎？」
艾德華·杭特也是會計師，家人受害後，他不肯等警察伸張正義，自己想辦法找到兇手，結果去坐牢了。布萊德的妻子剛剛說的就是他。
「我見過他。」我說。
「他人很好，真的很好，」他說，「但是你知道，瘋子總有方法掩飾，讓別人看不出來。」
說得真好，我還是第一次聽到。
「我覺得，他總有點 有點怪怪的。」摩根說。
「艾德華的工作就交給了布萊德嗎？」
「沒有全給他。我們分給幾個人，不過布萊德分擔的確實不少。」
「所以他要加班。」
「我們都要加班。」他說。
「就你所知，布萊德在事務所裡常跟誰見面嗎？」
「見面？他每天都跟其他人見面。」
「我不是這個意思。」
他疑惑了兩秒，然後他緩緩搖頭，沒想到自己居然不能馬上了解我的意思。「你是說，他跟誰有染嗎？」
「對，這就是我的問題。」
「就我所知，沒有。」
「他今天晚上加班到很晚？」
「是啊，我們都在加班，一起離開辦公室。」
「大概幾點？」
「大概十點半吧。」
「有人搭他的便車嗎？」
「沒有，我們兩個最後走。」
「你雇用他的時候，是否也聽說了他在前一份工作上有點麻煩？」
他吹了吹咖啡，然後小口喝了起來，花了幾秒想他的答案。「我聽說了，」他說。「但是都沒有得到證實，布萊德是很優秀的會計師，我們不該聽信謠言來判定他的品格。到我們這邊上班後，他向來循規蹈矩。我在這一行很久了，探長，辦公室裡的人總喜歡胡說八道，陷害同事。這也不是第一次了。可是我知道，在我們事務所裡，不會有人隨便傳那種謠言。」
「有可能是別的——」
