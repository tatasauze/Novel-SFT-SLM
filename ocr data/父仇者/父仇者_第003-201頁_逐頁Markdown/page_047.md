# 047 | THE LAUGHTERHOUSE
Paul Cleave

6

施羅德把副駕駛座的車窗搖下來，用一把小刀刮下鞋子上的泥巴，然後彈到窗外。雨似乎不會再下大了。離開現場大約三百公尺後，車流量又增加了。媒體採訪車彼此競速，想要拔得頭籌，把影像傳出去。我們無法行使職權，因為我開的不是警車，不能拉起警笛或按喇叭要別人讓路。我們牛步前進，兩人都罵了不少次髒話。車子裡很冷，座椅濕濕的，腿後側很癢。遠處，一台客機往空中呼嘯而去，機上的人都有更好的去處。我們到了一處由四名警員看守的封鎖線。施羅德秀了警徽，我們就進去了。
十點一刻，感覺像生命倒回了幾個小時，類似的建築，類似的看熱鬧人群，類似的死人，類似的死法。不同的地方只有人名地點不一樣，也少了跑到樹後撒尿的警探。替代的死人是亞伯特·麥克法蘭，伯尼的角色則由外型相似的男人扮演，他也穿了類似的西服，只是沒有釘徽章。更多的燈光裝好了，圍觀的人換了一群，這裡的人不一樣，不過他們仍想著同一個問題—————到底發生了什麼事？
我們走進了夜色，溫度每個小時就下降一兩度。空氣凝滯不動，一隻鳥也沒有。大家都輕聲細語，跟在圖書館裡一樣。我們從兩名警員前方走過，他們很嚴肅地對我們點點頭。我們上了門廊，腳下的露台發出輕微的嘎吱聲。漆成亮藍色的前門大開。裡面的空氣跟外面一樣冷。景象不比前一棟房子裡的好看。事實上，應該說更糟糕。這次，血飛濺到了天花板的吊扇上。還在旋轉的吊扇把血滴從扇片上甩下來，在牆中間畫出了一條線，就像浴缸邊緣上的圖案。看起來很像摩斯電碼，點跟線的組合，簡直在呼求救助。死人被捅了好多刀，刀刃拋上吊扇的血愈來愈多，重
