# 085 | THE LAUGHTERHOUSE
Paul Cleave

「她只有一歲。」她說。
所以他要應付十一歲、八歲跟一歲的女孩。他思索計畫會受到什麼影響，又發覺其實沒關係。或許做事的方法會受到影響，但他要對付醫生的籌碼也多了，最終的結局也不會改變。
「她叫什麼名字？」
「奧克塔維婭。那爸爸呢？你會傷害他嗎？」
「妳爸爸做了壞事。」他告訴她。
「我爸爸會幫助別人。」
「有時候他幫錯了人。」
「他做了什麼壞事？」
「這是大人的事，凱蒂。妳不懂。」
「我是大人了，」她說。「你忘了嗎？我現在像個大人一樣回答你的問題。」
面對這樣的情況，想到被綁在地上的男人，想到他讓人流的血跟坐牢的那些年，他還是忍不住微笑了。感覺很不錯，他終於有了感覺，太危險了。
「或許爸爸可以幫你，」她說。「你是他的病人嗎？你是瘋子嗎？」
他的笑容消失了。「不是，」他說。「我是好人，很友善。」
她瞪著他，眼神凌厲。「我不相信你。」
「好吧，凱蒂，問題在於，妳相不相信我都沒關係，因為妳要照我的話去做。如果妳不聽話，妳就有麻煩了，我可不希望看到妳或妳姊姊妹妹受傷，就因爲妳不聽話，」他伸手到口袋裡拿出膠帶。「現在，帶我去找她們，」他對她說，「不然我就要發火了，」他補了一句，她照做了，不發一語。
