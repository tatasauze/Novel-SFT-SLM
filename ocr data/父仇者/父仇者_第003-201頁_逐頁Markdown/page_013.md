# 013 | THE LAUGHTERHOUSE
Paul Cleave

2

很糟糕的喪禮天氣。
家裡有女兒跟貓的鬼魂，但最困擾我的還是真實存在的貸款。我本是警察，轉爲私家偵探，又變成罪犯，現在再度成為私家偵探，希望能回到警隊效力。這就是生命的循環。不過還不夠。我不想一天到晚跟蹤偷腥的丈夫。我什麼都不會，只會查案。除此之外，還會殺人。
我花了一小時吃午餐，然後穿上我唯一一套西裝。穿起來太鬆了。下午兩點半，我開車上路。雨勢未曾稍歇，路面水淋淋，標線都看不見了。公車站有穿著大外套的女士和穿制服的小孩，他們揹著書包在講手機。我開了三十分鐘後到了墓地，我女兒埋在這裡，我的神父以前也在這裡工作，直到他跟藍德里警探一樣，也變成了統計數字。停車場已經停滿了，裡面的車子呈現出社會的剖面。我到兩個街口外才找到車位，然後走回來。排水溝已經塞滿樹葉。紅色的很新鮮，褐色的比較陳舊，快變成爛泥了。輕風掀開了我的衣服。在停車場裡打轉的樹葉更多，多半落在石頭上，有些則卡在車子擋風玻璃的底緣。雨還是下個不停。
警察的喪禮總是大事。媒體採訪車已經來了，記者比其他人都早到。他們用照相機指著我，過了幾秒又轉開。警官死亡仍有人要報導，應該算是好事吧。不過他們的動機可議，或許會捏造故事——那就是記者跟猴子不一樣的地方。我爬上通往前門的階梯，甩了甩雨傘，把傘跟外套掛起來。教堂已經有百年歷史，巨大的灰色岩石搭配白色灰泥，窗戶上的染色玻璃色彩繽紛，也積了厚厚的灰塵。裡面已經半滿了，不過在我之後仍一直有人進來，外面有人三三兩兩站著，想在儀式開始前把菸抽完。施羅德在跟一名美女講話，她大概三十五六歲。他看見我便走過來，留下
