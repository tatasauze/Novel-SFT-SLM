# 父仇者 | 200

期，他試了兩次要自殺，然後被嚴密監控了三個月，等監控一結束，他又想辦法自殺。之後他放棄了，不過其他人倒想弄死他。
「二號受害者是老師，有沒有可能他教過惠特比？」我問。
「我們馬上就會查到了，」施羅德說。「跟一號受害者一起。」
「三號受害者，海沃德。應該跟艾瑞兒·錢瑟勒有關係吧。他就是選錯了召妓的時機。我也在想，如果寇爾認爲惠特比的律師有錯，應該也會責怪法官。那法官就有可能是下一個目標，也有可能給我們抓到寇爾的機會。」
「很好，」施羅德說。「我們這就把法官帶走，讓武裝警員進駐他家。或許走運，寇爾闖進去的時候正好抓到他。」
「還有惠特比太太，」我低頭看著她的大頭照，當她兒子在醫院病房裡掙扎求生時她被拍下了這張照片。她後腦勺的頭髮豎起，因爲她攤在沙發上看了好幾個小時的電視。她的眼睛半開半闔，又醉又累，看起來什麼都不在乎。「就像我剛才說過的，這一切都因她而起。」
「你應該再去找一次艾瑞兒·錢瑟勒，」他說。「帶肯特一起去。現在，你要問她的問題跟早上又不一樣了。或許他們一直保持聯絡。或許錢瑟勒可以給點資訊，給我們找到他的線索。」
「當然。」我朝著門口走去。
他把手伸進口袋，拿出那包起床咖啡因錠。
「你記得我們找到潔西卡·寇爾的時候嗎？」他問。
我停在門口，轉過身。「記得。」
「藍德里也在，」他說。「十五年怎麼就這麼他媽的過去了？」他問。
「我不知道。」
