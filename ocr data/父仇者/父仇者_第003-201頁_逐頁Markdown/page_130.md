# 父仇者 | 130

21

迦勒·寇爾動也動不了。舉起手臂時，胸口也發疼，手肘和肩膀的關節感覺像著了火。他把手指深深嵌入脖子按了按，好轉頭看看。或許睡在車裡會比較舒服，可是他不想離史丹頓太遠，免得他耍什麼花樣。他睡了——他看看手錶——可惡，才九十分鐘。他不敢相信他只睡了一個半小時。才九十分鐘，嬰兒又在哭了。她不知道怎地撕掉了嘴上的膠帶，讓膠帶掛在下巴上。
他覺得很冷。屠宰場這種建築物，就算著了火，溫度也只會上升到十度左右。他恨死這個地方了。他得等到今晚來完結昨晚預定要完成的工作，但要在這裡待一整天實在很難熬。
他把手放在髖關節上，伸展了一下背部。他一瘸一拐走了幾步，雙腿才恢復知覺。這一切現在早就該結束了。
「安靜。」他對奧克塔維婭說，不過她沒閉嘴，反而哭得更大聲。他解開釘子，用雙手抱起她，舉得離身體遠遠的。他想，不如把她搖一搖吧，說不定有用。搞什麼鬼，另外兩個孩子居然還沒醒？她們一定很習慣吵鬧，就跟住在機場附近的人不怕噪音一樣。他把奧克塔維婭上下晃動了幾下，拉掉了膠帶，她的哭聲稍微平息一些，但依然讓他覺得很煩躁。
「餓了嗎？」
她不哭了，連打了好幾個嗝，茫然地看著他，然後才點點頭。「餓。」她的嘴形勾勒出餓這個字，聽起來就像餓餓餓餓餓餓。
「我拿東西給妳吃。」
「餓餓餓餓餓。」
