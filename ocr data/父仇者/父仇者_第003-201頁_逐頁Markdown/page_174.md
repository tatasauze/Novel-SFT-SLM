# 父仇者 | 174

「先生，聽我說，你得冷靜下來，不然情況會更糟糕。」
「幹你娘。」他掛了電話。
我出了房子，站在巡邏車旁邊等。五分鐘後，有台車直衝而來。車子停在巡邏車旁，門颼一聲打開，起碼有六名警官舉槍對著他，他的身體似乎也發出了六種聲音，喉嚨中傳出了高亢的哀鳴聲。他的怒氣煙消雲散，往後退了一步。
「趴在地上。」其中一人對他說，他立刻照做了。另一人幫他戴上手銬，然後把他拉起來。有人伸手到他的後褲帶，掏出皮夾。他翻開皮夾，拿出駕照後遞給我。
「唐納德，我叫你冷靜點。」我比對著駕照跟唐納德本人，不是昨天晚上我幫過的那個人。唐納德體型肥胖，快五十歲了，剃光了頭髮，右耳戴著鑽石耳環，鼻子太小了，跟其他的器官不成比例。
「你在我家幹什麼？」
「你有台Toyota Corolla？」我問他。
「你們沒有權利這樣對我！」他怒聲大喊，槍放下了，他的憤怒也回來了。
「唐納德，那台車。」
「怎麼了？」
「車子在凶殺現場被發現。」
「什麼？沒有，不對，我……」然後他住嘴了，想到了什麼。
「可惡，」他說。「聽我說，那不是我，」他說。「不論你們以爲我幹了什麼，都不是我。我三天前把車賣了。那台車很舊了，備而不用，我們不需要了。我在報紙上登了廣告，有人來買走它。文書工作還在跑，老兄，但是那台車我賣了。我保證那不是我。」
「你知道他的名字嗎？身分證件呢？」
