# 父仇者 | 100

「有什麼好笑的？」他問。
「哈囉。」她說。
「妳笑什麼？」
「哈囉，哈囉。」她說。
「哈囉，」他回答。「奧克塔維婭，妳懂得什麼叫作閉嘴嗎？」
「哈囉吱吱。」
他把她放在地板上，回去拿汽車座椅，等他回來的時候，她已經用屁股把自己蹬到房間另一邊，拿起生鏽的釘子當玩具。他一把搶過釘子，丟到屠宰場更裡面的地方。
「幹他媽的，」他對兩個姊姊說。「妳們他媽的怎麼讓她玩那種東西？」
她們無法回答，當然也不是她們的錯。她們無法阻止奧克塔維婭。他應該解開一個女孩，讓她來照顧嬰兒。他低頭看看嬰兒，她又哭了起來。
「不要哭，」他對她說，但是當然沒有效。「很好。」他讓她躺在毛毯上。
天啊，上次照顧嬰兒已經是幾百年前的事了。
他屏住呼吸，轉開頭，解開她的尿布。幫自己女兒換尿布就夠糟了，幫別人的女兒換尿布則……他看到尿布的內容，一陣噁心，又轉開了頭。他又想吐了，然後不得不站起來。他跑到了辦公室門口，把頭伸出去，乾嘔了一次，再一次，然後吐在黑暗裡。他應該讓她姊姊來換。下次一定要記住。回到原地的時候，他無法直視奧克塔維婭的臉蛋。他拉開了尿布，塞進塑膠袋，然後用濕紙巾幫她擦拭，依舊看著另一個方向。她停止了哭泣。
「我應該留在牢裡不要出來。」他把濕紙巾塞進放了尿布的塑膠袋，把袋子一甩，綁了起來，然後朝著丟釘子的方向丟過去，又覺得不夠遠，走過去拿回來。最後放到了外面。
