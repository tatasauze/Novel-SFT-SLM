# 029 | THE LAUGHTERHOUSE
Paul Cleave

「卡爾……」
「你要告訴我到底發生了什麼事情嗎？」
「你早就知道了，」他說。「我們這麼多人都接到電話。」
沒錯，我的確知道了。「受害者是誰？」
「一個叫作赫伯特·普爾的傢伙，看來他被砍爛了。」
開過了「流行共識」後，車子就少了一點，不過剛下過雨，車速仍比較慢。十字路口的紅綠燈已經失靈，有一半的駕駛把十字路口當成圓環，另一半則急著趕路，不願意讓別人。排水溝裡的水滿到了街上。要到湖景養老院，還要開二十分鐘，路上施羅德幾乎都把頭靠在椅背上，用一隻手蓋著臉，他偶爾會打嗝，讓我知道他還沒睡著。雨又停了，依然看不到星星。
湖景養老院一側俯瞰草地和山林，蔓延到一片黑暗中。再過去有個高爾夫球場，到了晚上已經空無一人，打一次球要兩百塊。樹林這一側則是郊區，有條很長的車道連到主要道路。雖然名爲湖景，養老院附近卻沒有湖。最近的水域是六條街外附泳池的健身房。現場已經有五六台巡邏車和一輛計程車。警探們排成一列朝著野外走去，走到大樹後排空自己的膀胱，車頭燈幫他們照亮了道路。
「我的天，」我說，施羅德坐起來看外面。「警隊所有的警探都來了，也都喝醉了。」
「也不算我們的錯。我們怎麼知道今天會發生這種事？」
「就統計學來說，隨時都有可能。你沒派人留守嗎？」
「天啊，泰特，或許你跟藍德里處不好，我們其他人跟他還算不錯。」
「別擔心，」他往我肩膀上打了一巴掌。「這裡我是老大，我告訴你，看到死人後，大家就會清醒了。」
